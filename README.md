# UltramanGame · 迪迦体感训练场

给 4 岁孩子玩的家庭体感游戏。Mac 前置摄像头识别身体动作，Unity 显示英雄与怪兽，小米电视作为外接屏幕。孩子挥拳、双手防御、摆姿势发射光线；怪兽会提前预警，受击后恢复，首版没有失败。

## 当前进度

这是 **M0 可运行开发原型**。迪迦与哥尔赞均已接入带蒙皮骨骼的 3D 模型；迪迦有待机、左右拳、防御、L 形光线、受击、变身和胜利，哥尔赞有蓄力、跨步挥爪、受击和退场。摄像头触发对应动画，当前不做逐关节身体跟随。新增较短的近身前冲、配合根位移的脚步和落地阴影，挥爪与光线特效跟随实际骨骼。城市背景、固定配音、音乐导入和胜利合照保留。按 F5 查看角色姿势，按 F6 导入本机音乐。模型来源与实战接入记录见 [双角色实战接入](docs/双角色实战接入.md)。

2026-09-09 儿童实玩反馈：孩子满意，家长认为普通动作识别已较准确。此前已放宽大招容差、补上普攻收尾时的大招缓冲，并在引导语音结束后留 3 秒；本轮视觉接入保留这些规则。哥尔赞使用用户下载的老模型，纹理分辨率较低；动作的力量感和场景融合仍需继续打磨，尚未达到参考视频的整体品质。新版仍需孩子实际试玩确认。

战斗采用斜向 45° 站位：迪迦在左前景，能看到背侧和双臂；哥尔赞在右后景，能看清正面。出拳沿两人连线前冲，护盾和光线面向怪兽。变身完成后镜头平滑拉近，角色比准备画面约大三成；战斗标题、提示和底部操作条同步缩小，右下角仍保留较小的实时取景。怪兽先蓄力，再沿两人连线前冲挥爪，接触时结算护盾或受击，随后退回原位；配有冲刺拖尾、爪痕、冲击光圈及音效。

动作在本机识别：使用手腕相对肩膀的连续前推和侧前移动，减少二维手肘角度对朝镜头挥拳的限制。能量满后，宽松 L 形和“双手前推、停一下”都可发射光线。取景小窗会显示刚识别的动作。怪兽默认承受 50 次普攻；每命中 15 次普攻攒满一次大招，成功防御不增加能量。光线伤害相当于 9 次普攻。

Python、C# 规则和回环通信共 201 项自动检查通过，包括前推、上下误触、遮挡、深度抖动、招式冲突、语音反应时间和大招缓冲回归。中文字体随游戏内置。孩子已试玩并给出满意反馈；新的大招容差仍需下次真人试玩确认，电视延迟也尚无量化结果，详见 [验证记录](docs/验证记录.md)。

## 本机启动

需要 Python 3.12（使用 uv 管理）、Unity 6 编辑器；合照人像分割需要 macOS 12 或更新版本；音乐选择器构建还需要 macOS Command Line Tools（clang++）。工程已使用 `6000.6.0f1` 导入和构建，版本及包依赖锁已提交。自动测试另外使用 .NET 8 SDK。

### 本机已经准备好：直接试玩

双击项目根目录的 **`启动游戏.command`**。它会一起启动游戏和前置摄像头服务；关闭游戏窗口会停止本次相机服务。首次从终端启动时，macOS 可能需要为终端单独允许相机访问。

站到肩膀、手肘、双手都能入镜的位置，双手举高并保持片刻完成变身，左侧图示和进度条会引导动作。挥拳前先收手，手臂略弯也可以；出拳回收阶段支持短暂的下一拳缓冲。按 `F11` 切换全屏，按 `Esc` 暂停，按 `R` 重来。摄像头模式与键盘练习可用 `F2` 切换。按 `F4` 打开游戏设置：战斗页可调整怪兽血量（10–200 次普攻，默认 50），支持左右键调整、回车应用，应用后重新开局并记住选择；声音与音乐页可调整音量、开关背景音乐；语音播放时音乐会自动降低。按 `F6` 或“导入音乐”选择 MP3、WAV、OGG、AIFF，导入后循环播放并记住文件。

游戏右下角显示镜像实时取景，绿点表示关节看清、橙点表示暂时不可靠；肩膀、手肘、手腕与画面同步标记。底部会提示双肩未入镜或手臂没看清。点击“收起”或按 `F3` 隐藏/显示小窗口；超过约 0.75 秒没有新画面时清空旧图并提示。

胜利后点击左侧相机图标 **合照**（也可按 `F7`），先进入**实时镂空取景**，可以照着画面摆姿势；准备好后点击“拍照 · 5 秒倒计时”（或按空格 / 回车）才开始倒计时。人物自动抠图、镜像显示在右侧，迪迦正面胜利姿势位于左侧，共用城市背景。照片以 **1920×1080 PNG** 保存到当前用户的 `~/Downloads`（本机为 `/Users/fankaibo/Downloads`），拍完进入明确标为“照片预览 · 已定格”的大图预览，持续显示刚拍好的照片与保存结果，直到选择“再拍一张”或“完成”。倒计时中按 Esc 返回实时取景继续摆姿势；预览中按回车重新取景，每张使用独立文件名。保存失败时保留照片供重试，无须重新摆姿势。请退后到身体能尽量入镜的位置，未拍到人或相机断流时不会保存空照片。默认不录制视频，只有主动合照才保存照片。合成测试使用明显的 TEST 人物和文件名前缀；纯键盘启动没有相机，合照按钮不可用。

手肘或手腕偶尔没看清时，游戏会继续，另一只看清的手仍可操作。身体离开画面或相机消息中断超过约 0.6 秒才自动暂停；回来后稳定片刻即可继续。

```bash
# 仅键盘练习，不打开相机
./启动游戏.command --keyboard

# 自动合成动作试玩；游戏明确显示“合成动作测试”，不打开相机
./启动游戏.command --demo
```

仓库不附带《奇迹再现》音频。本机已使用用户下载的毛华锋原唱 MP3 完成导入、整局战斗和音量压低验证；其他电脑可在游戏里选择自己的普通音频文件，不会上传或复制进仓库。文件保持在原位置，移动或删除后需要重新选择。支持 1 秒至 15 分钟、小于 80 MB 的音频；失败时保留当前配乐。也可以启动时传入 `--music "/完整路径/奇迹再现.mp3"`。音乐账户的加密下载文件不能直接导入。

本机游戏包位于 `unity/Builds/TigaTraining.app`，构建产物不纳入 Git。直接打开 app 不会启动相机服务，日常使用请用上述启动入口。

### 1. 准备本地识别环境

```bash
./scripts/setup.sh
```

脚本在项目内创建 `.venv`，安装固定依赖，从 Google 官方下载姿态模型并校验 SHA-256。首次准备需要联网；后续相机识别在本机执行。uv 安装方式见 [uv 官方文档](https://docs.astral.sh/uv/getting-started/installation/)。

### 2. 启动相机

```bash
./scripts/camera.sh --game-preview
```

macOS 首次使用时需要为实际启动 Python 的应用允许相机访问。预览窗口显示镜像画面和手臂关键点，按 `Q` 或 `Esc` 结束。确保肩膀、手肘、双手进入画面，先让一个人在镜头前试玩。

日常启动入口默认在 Unity 右下角显示预览，关闭独立调试窗口，并自动分配三个空闲的本机端口。手动启动服务时，默认姿态端口为 `127.0.0.1:8765`，`--game-preview` 另外启用 `127.0.0.1:8766` 的预览和 `127.0.0.1:8767` 的按需合照；可用 `--port`、`--preview-port`、`--photo-port` 指定端口，并给独立游戏传入对应的 `--pose-port`、`--preview-port`、`--photo-port`。预览图像只通过本机回环连接进入 Unity，不上传、不录制；仅主动合照后保存成品照片到 Downloads。

### 3. 打开 Unity 工程

在 Unity Hub 中添加本仓库的 `unity` 文件夹。打开工程后，选择 **UltramanGame → Open Arena**，再按 Play。场景在运行时创建，不需要手动绑定对象。

默认使用摄像头输入：先保持肩膀和手臂可见，再双手举高触发变身。挥拳前收手；防御时双手靠近胸前；能量满后，一只前臂竖起、另一只前臂横在胸前，保持片刻释放光线。

摄像头暂时不可用时，可以点击游戏底部的 **键盘练习**，明确切换到键盘模式：

| 按键 | 操作 |
| --- | --- |
| 空格 | 变身 |
| A / D | 左拳 / 右拳 |
| 按住 S | 防御 |
| J | 能量充足时释放光线 |
| Esc | 暂停 / 继续 |
| R | 重新开始 |
| F2 | 切换摄像头与键盘模式，并重新开始 |
| F3 | 隐藏 / 显示右下角取景窗口（不停止动作识别） |
| F4 | 游戏设置：怪兽血量、总音量、音乐音量、静音 |
| F5 | 角色动作展示：左右方向键切换 8 个姿势，F5 / Esc 返回游戏 |
| F6 | 选择本机背景音乐；取消选择不会更换当前音乐 |
| F7 | 胜利后打开实时镂空取景；空格 / 回车开始 5 秒倒计时；Esc 取消倒计时或退出；成片预览中回车重新取景 |
| F11 | 全屏 / 窗口 |

### 4. 安装固定中文英雄配音（macOS）

```bash
.venv/bin/python scripts/generate_voice.py
```

默认安装用户试听选择的「热血青年英雄」中文配音，共 12 条固定台词。它是新设计的合成角色声音，并非某位角色演员的影视原声。WAV 语音包及台词清单随源码保存在 `voice-packs/anime-hero`；构建脚本离线校验台词、文件哈希和音频内容，再转换到 `unity/Assets/Resources/Voice`。转换产物不纳入 Git，重新克隆后也无需下载语音模型。需要系统声音时可显式运行 `.venv/bin/python scripts/generate_voice.py --voice Tingting`；下次常规构建会恢复英雄配音。2 首循环音乐与 8 种音效已随源码保存，可用 `.venv/bin/python scripts/generate_audio.py` 重建。

大招先进入约 1 秒的迪迦专属特写，放大 L 形光线姿势，配合战吼、手部聚光和招式字幕；镜头回到战场后才发射光线并结算命中。特写暂缓战斗计时，暂停、离开镜头或重开仍能立即打断。本机使用用户试听确认的迪迦战吼，战吼优先播完，随后才播胜利语音和庆祝音效。录音单独放在 `Resources/Voice/beam_original.aiff`，不被语音生成脚本覆盖，也不提交 Git；没有该本机素材时使用英雄引导语音。来源与重建方法见 [美术与音频说明](docs/美术与音频说明.md)。

### 5. 连接电视

先在电脑上完成动作测试，再用适配的 USB-C 转 HDMI 线或转接器连接电视。笔记本保持开盖，放在电视附近，摄像头朝向孩子。电视模式与端到端延迟需要在实际设备上调试。

## 验证与调试

```bash
# 规则、协议和 Python → C# 本机通信；不会打开相机
./scripts/check.sh

# 真实模型加载与推理；输入是生成的黑色画面，不打开相机
MPLCONFIGDIR="$PWD/.cache/matplotlib" .venv/bin/python scripts/smoke_model.py

# 向 Unity 发送明确标记的合成动作，不打开相机
./scripts/camera.sh --demo

# 短时相机验证，不显示预览、不保存画面
./scripts/camera.sh --seconds 5 --no-preview
```

GitHub Actions 执行无需摄像头的自动检查。集成检查使用系统分配的独立端口，可与游戏同时运行。

从源码重新生成 macOS 游戏：

```bash
./scripts/build_macos.sh
```

构建脚本先编译支持 Apple Silicon / Intel 的本机音乐选择器，再读取工程记录的 Unity 版本；安装路径不同可通过 `UNITY_EDITOR` 指定可执行文件。先关闭正在编辑此工程的 Unity 编辑器，再运行批处理构建。日志保存在 `logs`，不包含摄像头图像，也不纳入 Git。
