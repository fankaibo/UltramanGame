# UltramanGame · 奥特英雄体感游戏

[![Core and pose bridge checks](https://github.com/fankaibo/UltramanGame/actions/workflows/check.yml/badge.svg?branch=codex/guided-arcade)](https://github.com/fankaibo/UltramanGame/actions/workflows/check.yml?query=branch%3Acodex%2Fguided-arcade)

给 4 岁孩子玩的家庭体感游戏：Mac 前置摄像头识别动作，Unity 呈现战斗，小米电视作为外接屏幕。语音引导选英雄、举手变身、左右挥拳、防御、发射必杀，胜利后自动合照，并可重拍或再玩一局。怪兽提前预警，受击后恢复，不设失败。

## 当前开发重点

按用户最新安排，**先用迪迦完成整局街机体验**：引导变身、连续攻防、必杀、胜利自动合照、预览和再来一局。其他英雄的模型、动作、技能和声音打磨放到最后；已有英雄和资源保留。当前不再等待新角色素材，帧率／内存专项仍后置。本轮记录：[迪迦受击倒地姿态迭代](docs/迪迦受击倒地姿态迭代.md)，前置引导记录见[儿童语音反应窗口](docs/儿童语音反应窗口.md)，镜头记录见[大招专属镜头锁定](docs/大招专属镜头锁定.md)。[执行顺序与验收条件](docs/开发任务看板.md#tiga-first)。

## 本机启动

本次固定安装环境需要 macOS 14 或更新版本、Python 3.12（使用 uv 管理）、Unity 6 编辑器；音乐选择器构建还需要 macOS Command Line Tools（clang++）。工程已使用 `6000.6.0f1` 导入和构建，版本及包依赖锁已提交。自动测试另外使用 .NET 8 SDK。

### 本机已经准备好：直接试玩

双击项目根目录的 **`启动游戏.command`**。它会一起启动游戏和前置摄像头服务；关闭游戏窗口会停止本次相机服务。首次从终端启动时，macOS 可能需要为终端单独允许相机访问。

站到肩膀、手肘、双手都能入镜的位置，双手举高并保持片刻完成变身，底部图示和进度条会引导动作。挥拳前先收手，手臂略弯也可以；向前挥拳发射光弹（赛罗发头镖），侧向挥拳近战（梦比优斯左手挥光剑），快慢出手对应不同动画速度。出拳回收阶段支持短暂的下一拳缓冲，已发出的光弹在转入防御后仍可命中。按 `F11` 切换全屏，按 `Esc` 暂停，按 `R` 重来。摄像头模式与键盘练习可用 `F2` 切换。按 `F4` 打开游戏设置：战斗页可调整怪兽血量（10–200 次普攻，默认 50），支持左右键调整、回车应用，应用后重新开局并记住选择；声音与音乐页可调整音量、开关背景音乐；语音播放时音乐会自动降低。按 `F6` 或“导入音乐”选择 MP3、WAV、OGG、AIFF，导入后循环播放并记住文件。

游戏右下角显示较小的镜像实时取景和最近识别结果。失去新画面时不保留旧图，提示镜头正在准备。孩子主要听语音并看底部动作图示，家长可使用上述快捷键调整设置。体感界面左下角保留“切换按键 · F2”按钮，设置窗口右上角也可双向切换；切换仅更换输入方式，保留本局血量、能量和已选角色。合照打开时切换模式不会关闭取景或预览。

胜利后自动进入实时镂空合照：所选奥特英雄的大小和位置固定在左侧，摄像头人物缩放到右侧，共用富士山夜景背景。听完引导后预留 3 秒准备，再倒数 5 秒自动拍照；未看到人或取景断流时会停止倒数，恢复后自动重试。拍完显示定格照片，先放下双手；举一只手保持可重拍，双手举高保持可再玩一次，全程无需键鼠。照片默认以 **1920×1080 PNG** 保存，画质设为 2K 时使用 **2560×1440**；文件保存到当前用户的 `~/Downloads`（本机 `/Users/fankaibo/Downloads`），每张使用独立文件名；保存失败会保留成片并重试。尽量让全身入镜可获得更协调的比例；只有半身时不会补造腿部。默认不录制摄像头视频，胜利合照环节才保存照片。自动测试只保存明确标注 TEST 的合成人物图，不使用真人摄像头。

手肘或手腕偶尔没看清时，游戏会继续，另一只看清的手仍可操作。身体离开画面或相机消息中断超过约 0.6 秒才自动暂停；回来后稳定片刻即可继续。识别服务意外退出或卡住时，启动器会自动恢复姿态、预览与合照连接，不重开这一局。若连续恢复失败，可按 F2 使用键盘练习；断线时界面不会再提示“让肩膀回到画面”。

```bash
# 仅键盘练习，不打开相机
./启动游戏.command --keyboard

# 自动合成动作试玩；游戏明确显示“合成动作测试”，不打开相机
./启动游戏.command --demo
```

公开仓库不附带《奇迹再现》音频。本机项目已保存用户提供的 MP3：`unity/Assets/Resources/Audio/miracle_reappearance.mp3`，构建后可通过「使用《奇迹再现》」恢复。其他电脑可用 F6 选择自己的音频；F6 只记住原文件路径，移动或删除该文件后需要重新选择。支持 1 秒至 15 分钟、小于 80 MB 的音频；失败时保留当前配乐。也可以启动时传入 `--music "/完整路径/奇迹再现.mp3"`。音乐账户的加密下载文件不能直接导入。

本机游戏包位于 `unity/Builds/TigaTraining.app`，构建产物不纳入 Git。直接打开 app 不会启动相机服务，日常使用请用上述启动入口。

开发候选可用 `试玩新效果.command` 启动；当前 A-116 已验收并同步到默认包，两者文件一致。需要在保留当前试玩包时构建候选，可指定独立路径：

```bash

./启动游戏.command --app "$PWD/unity/Builds/TigaTraining-candidate.app"
```

`cinematic_player_check.py` 和 `guided_player_check.py` 也接受 `--app`，验证记录包含实际安装包路径和摘要。不要同时开启两份真人相机试玩；候选自动检查使用独立的合成输入。


### 1. 准备本地识别环境

```bash
./scripts/setup.sh
```

脚本在项目内创建 `.venv`，安装固定依赖，从 Google 官方下载姿态模型并校验 SHA-256。首次准备需要联网；后续相机识别在本机执行。uv 安装方式见 [uv 官方文档](https://docs.astral.sh/uv/getting-started/installation/)。

### 2. 启动相机

```bash
./scripts/camera.sh --game-preview
```

macOS 首次使用时需要为实际启动 Python 的应用允许相机访问。预览窗口显示镜像画面和手臂关键点，按 `Q` 或 `Esc` 结束。确保肩膀、手肘、双手进入画面，先让一个人在镜头前试玩。

日常启动入口默认在 Unity 右下角显示预览，关闭独立调试窗口，并自动分配三个空闲的本机端口。手动启动服务时，默认姿态端口为 `127.0.0.1:8765`，`--game-preview` 另外启用 `127.0.0.1:8766` 的预览和 `127.0.0.1:8767` 的按需合照；可用 `--port`、`--preview-port`、`--photo-port` 指定端口，并给独立游戏传入对应的 `--pose-port`、`--preview-port`、`--photo-port`。预览图像只通过本机回环连接进入 Unity，不上传、不录制；仅主动合照后保存成品照片到 Downloads。

### 3. 打开 Unity 工程

在 Unity Hub 中添加本仓库的 `unity` 文件夹。打开工程后，选择 **UltramanGame → Open Arena**，再按 Play。场景在运行时创建，不需要手动绑定对象。

默认使用摄像头输入：先保持肩膀和手臂可见，再双手举高触发变身。挥拳前收手；防御时双手靠近胸前；能量满后，一只前臂竖起、另一只前臂横在胸前，保持片刻释放光线。

摄像头暂时不可用时，可以点击游戏底部的 **键盘练习**，明确切换到键盘模式：

| 按键 | 操作 |
| --- | --- |
| 空格 | 变身 |
| A / D | 左手 / 右手近战；梦比优斯左手为光剑 |

### 4. 安装固定中文英雄配音（macOS）

```bash
.venv/bin/python scripts/generate_voice.py
```

默认安装用户试听选择的「热血青年英雄」中文配音，共 12 条固定台词。它是新设计的合成角色声音，并非某位角色演员的影视原声。WAV 语音包及台词清单随源码保存在 `voice-packs/anime-hero`；构建脚本离线校验台词、文件哈希和音频内容，再转换到 `unity/Assets/Resources/Voice`。转换产物不纳入 Git，重新克隆后也无需下载语音模型。需要系统声音时可显式运行 `.venv/bin/python scripts/generate_voice.py --voice Tingting`；下次常规构建会恢复英雄配音。2 首循环音乐与 9 种音效已随源码保存，可用 `.venv/bin/python scripts/generate_audio.py` 重建；其中 `warning.wav` 是怪兽蓄力时的原创低频警示层。

大招先进入角色特写，配合聚光和招式字幕；迪迦使用 L 形光线姿势，赛罗将双头镖移到胸前释放双射击，梦比优斯从左腕聚能后以双臂十字姿势发射，格力乔环形蓄力后交叉双腕释放格力乔射线。镜头回到战场后才发射光线并结算命中。特写暂缓战斗计时，暂停、离开镜头或重开仍能立即打断。本机迪迦使用用户试听确认的战吼，战吼优先播完，随后才播胜利语音和庆祝音效。录音单独放在 `Resources/Voice/beam_original.aiff`，不被语音生成脚本覆盖，也不提交 Git；缺少原声的英雄使用通用引导语音。来源与重建方法见 [美术与音频说明](docs/美术与音频说明.md)。

### 5. 连接电视

先在电脑上完成动作测试，再用适配的 USB-C 转 HDMI 线或转接器连接电视。笔记本保持开盖，放在电视附近，摄像头朝向孩子。电视模式与端到端延迟需要在实际设备上调试。
