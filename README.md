# UltramanGame · 迪迦体感训练场

本轮街机演出补充：变身完成后绑定 `BattleStart` 语音显示约 2 秒的“迪迦 VS 哥尔赞 / 开战！/ FIGHT!”切入，首帧可见并自动淡出；同时播放本地生成的短促低频开战音，不依赖额外版权音频。它们只改变表现层，不改变动作识别窗口。哥尔赞爪臂修正让手腕有限度跟随前臂目标，同时保留爪掌原始滚转，减少近景中手掌挂在前臂上的感觉。帧率优化按当前计划后置。

2026-09-21：继续优先改善街机演出，帧率优化后置。迪迦重新烘焙了非对称站姿、前手刺拳、后手直拳和收拳过渡；前进步幅与屈膝、支撑脚曲线一起校准，减少拳头与怪兽身体之间的空隙。命中时先采样接触姿势，再在手部位置产生特效；短停顿与动作使用同一战斗时钟，火花和光照继续播放，体感输入每帧接收，避免旧版冻结画面却跳过后续动作的问题。每五次普攻的连击音效也改为在实际命中时播放。怪兽蓄力新增原创低频警示音，与蓄力环、屏幕预警和前冲音效分层播放。哥尔赞运行时新增指骨、拇指收爪层并预缓存骨骼引用，减少平面手掌和每帧字符串分配；能量满后大招在怪兽蓄力阶段仍保持可识别，延迟但未过期的相机帧不会清空动作蓄力。依据根目录街机录屏逐帧对照，新增角色外侧的短斜向速度线，出拳、怪兽冲刺和受击各自使用不同色调，增强电视距离下的动作节奏且不遮挡角色；大招专属特写加入小幅 3/4 环绕和上下呼吸位移，保持招式字幕与识别时序不变；哥尔赞胜利阶段从初始失衡开始，在约 1 秒内向后倒地，再进入合照准备。战斗场新增蓝色迪迦轮廓光和橙色哥尔赞轮廓光，按出拳、蓄力、冲刺和光线时序呼吸，暗色富士火山背景中的角色边缘更接近街机机台。角色材质也跟随战斗钟发光：哥尔赞眼睛在蓄力和冲刺时呈橙色脉冲，迪迦眼睛、计时器和水晶在变身和光线阶段呈冷蓝脉冲。命中后处理新增短促的径向屏幕冲击波，与闪光、镜头回弹、星芒和声音同一接触帧触发，扩散后自动清除，不改变动作时序。新增角色表面打击闪烁：哥尔赞受击时皮肤短暂暖橙点亮，迪迦成功防御时战衣短暂冷蓝点亮，让角色本体也参与命中反馈。长段攻防的待机间隙新增小幅交替重心和头肩跟随，按已完成的普攻与怪兽攻击次数改变节奏，减少每次收拳后回到同一静止剪影。体感战斗开始后动作卡片自动收缩为底部窄条，保留识别提示但让角色、特效和火山背景占据主要画面。哥尔赞普通受击窗口新增短促后退和侧向失衡，根部仍保持脚底锚定，下一段恢复会回到原来的 45° 对战线。迪迦拳后回收新增一小段肩部反向摆回与侧向落脚，左右拳不再直接切回同一待机剪影。新烘焙动作目前接入迪迦，其他英雄保留原素材。

已有的怪兽交替爪击、格挡受力、必杀近景、火山场景、无键鼠合照与续局继续保留。改动与本机对照入口见 [迪迦出拳与接触校准](docs/迪迦出拳与接触校准.md)，此前演出取证见 [街机画面对照与取证](docs/街机画面对照与取证.md)。持续开发中，尚未达到参考街机的最终角色和动画品质。

新增角色保留下载模型的外形；捷德当前是下载页的 Dandit Truth 特殊变体，非通常的原始形态。素材来源见 [第三方资源](THIRD_PARTY.md)。合照固定奥特曼大小，根据人物及脚踝位置调整拍照人的大小和落地位置。启用 AI 融合后，仅最终合照发送到用户配置的网关，由 `gpt-5.6-terra` 分析场景并给出有界的调色、边缘融合参数；原图保留，融合版另存，不阻塞下一局。可在 F4 设置中关闭。

给 4 岁孩子玩的家庭体感游戏。Mac 前置摄像头识别身体动作，Unity 显示英雄与怪兽，小米电视作为外接屏幕。孩子挥拳、双手防御、摆姿势发射光线；怪兽会提前预警，受击后恢复，首版没有失败。

## 当前进度

当前是可直接试玩的 **3D 家庭版**。迪迦和哥尔赞均使用带蒙皮骨骼的模型，摄像头触发连续战斗动作；当前不做逐关节身体跟随。战斗场景使用写实富士山夜景远景，前景保留焦土、碎石、熔岩裂缝、火星、喷发烟柱和远处天空偶尔出现的细短流星等动态效果。角色共用环境反光、冷暖灯光和街机前景补光，哥尔赞增加程序化皮肤凹凸和贴图微法线，并在待机/蓄力/恢复时把肩、肘、腕分层拉开，避免双爪贴成一片；出拳加强转肩、转腰和前倾，连续命中会显示街机式连击，命中时短暂放慢动作，光线、护盾、火花和照亮角色的局部光效一起响应。后处理保留全分辨率场景，光晕使用半分辨率缓冲，减少大招边缘发软。

2026-09-09：在现有儿童友好规则上完成战斗演出升级，新增默认 50 血量整局自动试玩，以及同动作的升级前后录像。原声、音乐导入、取景和胜利镂空合照保留。结果、复现方式与本机录像位置见 [战斗演出升级验收](docs/战斗演出升级验收.md)。模型接入历史见 [双角色实战接入](docs/双角色实战接入.md)。

孩子之前试玩后表示满意；普通动作识别已得到家长认可，大招容差和引导后 3 秒反应时间也已改进。本轮没有重新让孩子真人试玩，也没有测量小米电视的投屏延迟。哥尔赞仍来自原有老模型；新增皮肤材质能改善光照细节，但不能视为重新制作了影视级模型，不能宣称与商场参考视频完全一致。

战斗采用斜向 45° 站位：迪迦在左前景，能看到背侧和双臂；哥尔赞在右后景，能看清正面。出拳沿两人连线前冲，护盾和光线面向怪兽。变身完成后镜头平滑拉近，角色比准备画面约大三成；战斗标题、提示和底部操作条同步缩小，右下角仍保留较小的实时取景。怪兽先蓄力，再沿两人连线前冲挥爪，接触时结算护盾或受击，随后退回原位；配有冲刺拖尾、爪痕、冲击光圈及音效。

## 本机启动

本次固定安装环境需要 macOS 14 或更新版本、Python 3.12（使用 uv 管理）、Unity 6 编辑器；音乐选择器构建还需要 macOS Command Line Tools（clang++）。工程已使用 `6000.6.0f1` 导入和构建，版本及包依赖锁已提交。自动测试另外使用 .NET 8 SDK。

### 本机已经准备好：直接试玩

双击项目根目录的 **`启动游戏.command`**。它会一起启动游戏和前置摄像头服务；关闭游戏窗口会停止本次相机服务。首次从终端启动时，macOS 可能需要为终端单独允许相机访问。

站到肩膀、手肘、双手都能入镜的位置，双手举高并保持片刻完成变身，底部图示和进度条会引导动作。挥拳前先收手，手臂略弯也可以；出拳回收阶段支持短暂的下一拳缓冲。按 `F11` 切换全屏，按 `Esc` 暂停，按 `R` 重来。摄像头模式与键盘练习可用 `F2` 切换。按 `F4` 打开游戏设置：战斗页可调整怪兽血量（10–200 次普攻，默认 50），支持左右键调整、回车应用，应用后重新开局并记住选择；声音与音乐页可调整音量、开关背景音乐；语音播放时音乐会自动降低。按 `F6` 或“导入音乐”选择 MP3、WAV、OGG、AIFF，导入后循环播放并记住文件。

游戏右下角显示较小的镜像实时取景和最近识别结果。失去新画面时不保留旧图，提示镜头正在准备。孩子主要听语音并看底部动作图示，家长可使用上述快捷键调整设置。体感界面左下角保留“切换按键 · F2”按钮，设置窗口右上角也可双向切换；切换仅更换输入方式，保留本局血量、能量和已选角色。合照打开时切换模式不会关闭取景或预览。

胜利后自动进入实时镂空合照：迪迦大小和位置固定在左侧，摄像头人物缩放到右侧，共用富士山夜景背景。听完引导后预留 3 秒准备，再倒数 5 秒自动拍照；未看到人或取景断流时会停止倒数，恢复后自动重试。拍完显示定格照片，先放下双手；举一只手保持可重拍，双手举高保持可再玩一次，全程无需键鼠。照片以 **1920×1080 PNG** 保存到当前用户的 `~/Downloads`（本机 `/Users/fankaibo/Downloads`），每张使用独立文件名；保存失败会保留成片并重试。尽量让全身入镜可获得更协调的比例；只有半身时不会补造腿部。默认不录制摄像头视频，胜利合照环节才保存照片。自动测试只保存明确标注 TEST 的合成人物图，不使用真人摄像头。

手肘或手腕偶尔没看清时，游戏会继续，另一只看清的手仍可操作。身体离开画面或相机消息中断超过约 0.6 秒才自动暂停；回来后稳定片刻即可继续。识别服务意外退出或卡住时，启动器会自动恢复姿态、预览与合照连接，不重开这一局。若连续恢复失败，可按 F2 使用键盘练习；断线时界面不会再提示“让肩膀回到画面”。

```bash
# 仅键盘练习，不打开相机
./启动游戏.command --keyboard

# 自动合成动作试玩；游戏明确显示“合成动作测试”，不打开相机
./启动游戏.command --demo
```

仓库不附带《奇迹再现》音频。本机已使用用户下载的毛华锋原唱 MP3 完成导入、整局战斗和音量压低验证；其他电脑可在游戏里选择自己的普通音频文件，不会上传或复制进仓库。文件保持在原位置，移动或删除后需要重新选择。支持 1 秒至 15 分钟、小于 80 MB 的音频；失败时保留当前配乐。也可以启动时传入 `--music "/完整路径/奇迹再现.mp3"`。音乐账户的加密下载文件不能直接导入。

本机游戏包位于 `unity/Builds/TigaTraining.app`，构建产物不纳入 Git。直接打开 app 不会启动相机服务，日常使用请用上述启动入口。

### 1. 准备本地识别环境

```bash
./scripts/setup.sh
```

脚本在项目内创建 `.venv`，安装固定依赖，从 Google 官方下载姿态模型并校验 SHA-256。首次准备需要联网；后续相机识别在本机执行。uv 安装方式见 [uv 官方文档](https://docs.astral.sh/uv/getting-started/installation/)。

### 2. 启动相机

```bash
./scripts/camera.sh --game-preview
```

macOS 首次使用时需要为实际启动 Python 的应用允许相机访问。预览窗口显示镜像画面和手臂关键点，按 `Q` 或 `Esc` 结束。确保肩膀、手肘、双手进入画面，先让一个人在镜头前试玩。

日常启动入口默认在 Unity 右下角显示预览，关闭独立调试窗口，并自动分配三个空闲的本机端口。手动启动服务时，默认姿态端口为 `127.0.0.1:8765`，`--game-preview` 另外启用 `127.0.0.1:8766` 的预览和 `127.0.0.1:8767` 的按需合照；可用 `--port`、`--preview-port`、`--photo-port` 指定端口，并给独立游戏传入对应的 `--pose-port`、`--preview-port`、`--photo-port`。预览图像只通过本机回环连接进入 Unity，不上传、不录制；仅主动合照后保存成品照片到 Downloads。

### 3. 打开 Unity 工程

在 Unity Hub 中添加本仓库的 `unity` 文件夹。打开工程后，选择 **UltramanGame → Open Arena**，再按 Play。场景在运行时创建，不需要手动绑定对象。

默认使用摄像头输入：先保持肩膀和手臂可见，再双手举高触发变身。挥拳前收手；防御时双手靠近胸前；能量满后，一只前臂竖起、另一只前臂横在胸前，保持片刻释放光线。

摄像头暂时不可用时，可以点击游戏底部的 **键盘练习**，明确切换到键盘模式：

### 4. 安装固定中文英雄配音（macOS）

```bash
.venv/bin/python scripts/generate_voice.py
```

默认安装用户试听选择的「热血青年英雄」中文配音，共 12 条固定台词。它是新设计的合成角色声音，并非某位角色演员的影视原声。WAV 语音包及台词清单随源码保存在 `voice-packs/anime-hero`；构建脚本离线校验台词、文件哈希和音频内容，再转换到 `unity/Assets/Resources/Voice`。转换产物不纳入 Git，重新克隆后也无需下载语音模型。需要系统声音时可显式运行 `.venv/bin/python scripts/generate_voice.py --voice Tingting`；下次常规构建会恢复英雄配音。2 首循环音乐与 9 种音效已随源码保存，可用 `.venv/bin/python scripts/generate_audio.py` 重建；其中 `warning.wav` 是怪兽蓄力时的原创低频警示层。

大招先进入约 1 秒的迪迦专属特写，放大 L 形光线姿势，配合战吼、手部聚光和招式字幕；镜头回到战场后才发射光线并结算命中。特写暂缓战斗计时，暂停、离开镜头或重开仍能立即打断。本机使用用户试听确认的迪迦战吼，战吼优先播完，随后才播胜利语音和庆祝音效。录音单独放在 `Resources/Voice/beam_original.aiff`，不被语音生成脚本覆盖，也不提交 Git；没有该本机素材时使用英雄引导语音。来源与重建方法见 [美术与音频说明](docs/美术与音频说明.md)。

### 5. 连接电视

先在电脑上完成动作测试，再用适配的 USB-C 转 HDMI 线或转接器连接电视。笔记本保持开盖，放在电视附近，摄像头朝向孩子。电视模式与端到端延迟需要在实际设备上调试。

# 规则、协议和 Python → C# 本机通信；不会打开相机

GitHub Actions 执行无需摄像头的自动检查。集成检查使用系统分配的独立端口，可与游戏同时运行。

从源码重新生成 macOS 游戏：

```bash
./scripts/build_macos.sh
```

构建脚本先编译支持 Apple Silicon / Intel 的本机音乐选择器，再读取工程记录的 Unity 版本；安装路径不同可通过 `UNITY_EDITOR` 指定可执行文件。先关闭正在编辑此工程的 Unity 编辑器，再运行批处理构建。日志保存在 `logs`，不包含摄像头图像，也不纳入 Git。
