# 光线持续受击与撤步（2026-09-29）

对照参考录屏中的连续交战，再检查当前版本的大招序列，发现格尔赞在光线尚未结束时已经回到待机：原重击反应约 0.9 秒，而光线命中后的持续时间还包含停顿和发射尾段。

## 新动作

格尔赞先受到胸口冲击，再用一条腿撤步撑住，持续承受光线，最后收脚恢复。撤步距离约 0.6 个场景单位，躯干后移约 0.32，支撑脚保持固定。胸口保留小幅连续反应，光线终点跟随实际变形的胸部网格。

落脚由动作事件触发碎屑、扬尘和音效，每次大招只触发一次。新动作不会推迟下一次攻击；奥特曼根据怪兽剩余位移增加小幅追步，避免大招后第一拳落空。普通攻击不能把尚未收回的怪兽脚瞬间送回原位。暂停、新一局和胜利会清理撤步动作，胜利仍使用原来的倒地演出。

实现位于 `MonsterBeamMotion.cs`、`RiggedActor.cs` 和 `GameWorld.cs`；没有修改动作识别、伤害、能量或语音引导的等待时间。
