# 战斗提示与动作衔接（A-20261019-180）

基线 `10d0e55`。对应第一条“一局的引导与衔接”，本轮只修正提示，不扩展美术与英雄阵容。

## 问题与改动

原主提示兜底分支只检查文案计时器，并始终使用 `punch` 图示。格挡成功、必杀释放和受击恢复的文字也进入同一缓存：例如预警结束、继续保持护盾时，可能出现“挡住了！护盾成功”配出拳图示；快速完成光线后也可能重现已经结束的招式文字。

现在文案携带动作类别，展示前检查实际战斗阶段：防御成功配护盾图示，反击立即清除旧防御提示；受击结束和光线能量消耗后，不继续显示过时的恢复或必杀文字。暂停、胜利及新局继续由各自的引导接管。语音引导的文案保留时间增加原先漏掉的 2 秒，与现有儿童反应窗口对齐。

没有修改识别阈值、持续姿势、伤害、攻速和敌人反应时间，没有增加手势切换英雄。合照／举手续局规则保持。

## 验证

15／30／60 Hz 的真实核心战斗状态驱动格挡、反击、受击恢复、15 次普攻积能、释放光线和追踪暂停，新增 48 项检查。`bash scripts/check.sh` 的 58 项 Python 测试及累计 2411 项检查通过。源码 Release 构建和签名通过，170 个源码／着色器文件及发行程序集／资源哈希记录在 `artifacts/a180-guidance/build.json`。

同一实际发行包 164.7 秒完成一局战斗、两次全身合照、重拍、断流恢复及下一局开始。2087 个普通战斗输入帧全部为高位；32 次左右光弹命中，0 键鼠事件、0 手势切英雄。两张照片预览／保存差均为 0；重拍／续局在成片显示 4.81／4.97 秒接受，语音仍在播放，放手确认后 0.977 秒切换举手指令。已查看实际大招保持提示截图。

核对源码、包载荷及签名后，整包升级默认 `unity/Builds/TigaTraining.app`；上一版保留为 `TigaTraining-pre-a180.app`。`guided/guided-validation.json`、`build.json`、`promotion.json` 保存本轮证据。主提示格挡后分支由核心阶段切换检查覆盖，本次常规整局没有单独截取该分支，不冒充逐帧视觉对照。合成回放不能代替真实儿童和小米电视验收，不提高总看板 70.2%。
