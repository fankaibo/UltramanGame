# 必杀接触喷散与余烟（A-20261019-181）

基线 `437486b`。本轮对照根目录街机录屏与 A-180 实际包大招持续画面：旧接触效果主要是一团快速膨胀的灰雾和规则圆环，缺少明确的接触喷散，近景也遮住怪兽上半身轮廓。

## 本轮改动

- 用 36 条有不同速度、延迟和衰减时间的蓝白碎光，表现光线接触后向外喷散；轨迹带重力，朝光线来向和周边散开。
- 使用一份固定网格、两片交叉薄片构成每条碎光，侧面机位也有厚度。复用对象与网格，不在每次命中创建粒子对象；清理和显式时间跟随原命中事件。
- 烟雾减轻早期密度，收紧前后厚度，增加密度差异；先读到接触闪光和喷散，再留下较薄余烟。地面尘灰保持。
- 去掉旧体积接触圆环、通用必杀圆环及重复等角射线；非必杀接触路径保持。

没有修改动作识别、伤害、发射位置、角色动画或镜头时钟。其他英雄的精修仍后置。
