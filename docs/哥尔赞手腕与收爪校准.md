# 哥尔赞手腕与收爪校准（2026-09-26）

旧版将手掌维持为朝向前方，而蓄力动作会抬起并收回前臂。两种约束冲突，使手掌在蓄力与出击交接处反折；单看接触时刻容易漏掉问题。原有手指层还共用世界坐标中的弯曲轴，左右手换方向后收爪轮廓不一致。

现在从四根手指的掌骨起点计算真实掌骨轴。肩肘和腕部位置仍由原片段驱动，动画混合完成后将掌骨相对前臂的偏折限制为 35°，保留其余滚转。四指和拇指的弯曲方向也改为对应手掌的局部方向。未更改攻击时点、怪兽移动路径或体感识别条件。

## 对照与测量

## 复现

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ClawPoseReview.After \
  -quit -logFile "$PWD/logs/claw-alignment-after.log"
```

`Before` 入口只负责保存修改前的当前代码，并不会自动切换到历史版本；须在修改之前运行。不要用修改后的源码覆盖旧基准，再将两份相同结果声称为旧新对照。
