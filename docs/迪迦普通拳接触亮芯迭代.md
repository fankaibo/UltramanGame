# 迪迦普通拳接触亮芯迭代

增量：A-20261015-148  
日期：2026-10-15  
范围：迪迦与哥尔赞普通拳命中反馈；不改变识别、伤害、命中时钟或连击计数。

## 问题

实机三分之四镜头下，普通拳接触点只剩一条细白线，亮芯和放射方向不够清楚，和参考街机的短促打击峰值有差距。

## 实现

- 放大 `StrikeContactBurst` 普通接触卡，并延长极短的可见释放段；连击接触使用更大的变体。
- 普通拳增加 6 条短时方向性放射线，连击增加 8 条；它们只属于表现层，不创建额外命中事件。
- 保留原有烟尘、碎片、受击定格、伤害和音效时序，避免用特效遮挡下一次姿势。
