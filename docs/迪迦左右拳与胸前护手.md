# 迪迦左右拳与胸前护手（2026-09-28）

上一轮的实际游戏截图显示，迪迦普通拳虽然只用一只手命中，另一只手仍跟随原素材抬到头顶，视觉上容易被看成两只手一起出招。本轮把战斗准备、普通拳与收拳连接到同一个胸前护手姿势：一只手打出去，另一只手收在同侧肩膀下方，随后回到准备姿势。

迪迦继续使用原有踏步、转肩和攻击手动画轨迹；接触附近保留已有胸部表面落点修正。动画开始和回收时将攻击手与胸前位置平滑衔接，另一只手的肘部朝下。连击沿用既有的外侧弧线，并以同一准备姿势开始和结束。

切入护盾、必杀和受击时，以玩家实际看到的手臂姿势混合到目标动画，避免先恢复原素材的举高手姿势而发生跳动。每帧重新采样时会移除上一帧的修正，避免连续叠加变形。摄像头动作识别与伤害时序未改。

## 对照与复现

`artifacts/tiga-guard/index.html` 提供 7 秒连续修改前后对照、迪迦准备姿势和左右普通拳、五英雄连击回归画面。左侧基准为 `fdfb0f52f0b66458ba0a09c1e051b7cc741c0963`。两侧各 210 帧，420 条战斗状态一致；十拳仍扣 10 点血、充能 10 次。离线 30 FPS 不代表实际游戏帧率。

1. Unity 执行 `UltramanGame.Editor.TigaGuardReview.Release --combo-output <仓库绝对路径>/artifacts/tiga-guard`。
2. 执行 `bash scripts/build_macos.sh` 与 `.venv/bin/python scripts/cinematic_player_check.py --hero Tiga`。
3. 执行 `.venv/bin/python scripts/encode_combo_review.py --folder artifacts/tiga-guard --baseline fdfb0f52f0b66458ba0a09c1e051b7cc741c0963 --subject tiga-guard --player <本轮打包版证据目录>`。

生成脚本核对旧版与当前源码、输入状态和打包版程序／资源摘要。

## 验证范围

迪迦在 15、30、60 Hz 采样下分别完成 10 次交替普攻，检查了 30、70、130 个出拳阶段的护手样本。另一只手始终低于同侧肩膀 0.15，前伸 0.28 个场景单位；命中时两手沿战斗方向的间隔至少 0.919。拳端到胸部蒙皮顶点的最近距离最大 0.315，与原有落点范围一致。该测量用于排除明显打空，并非完整物理碰撞检查。

五英雄在 15、30、60 Hz 下的快速交替出拳、零时间重复采样、暂停恢复和新局复位均通过。迪迦切入护盾时最大单帧局部手部位移为 0.2912；五英雄普通拳接护盾与连击接护盾检查通过。连击检查保留原有脚部支撑、胸部接触和另一只手收拢的约束。

测量位于 `artifacts/tiga-guard/guard-validation.txt`、`validation/validation.txt` 和 `validation/interruptions.txt`；完整过程日志为 `logs/tiga-guard-release.log`。
