# 连贯战斗发力与镜头（A-20261010-83）

日期：2026-10-10。范围：现有角色的普通拳击／光弹身体发力，以及近战连续镜头。没有修改动作识别、伤害或蓄能规则。

## 行为变化

- 原先每拳镜头按正弦曲线来回移动，左右拳还会立即反转方向。现在连续拳共享一个镜头，短间隔保持取景；停手后渐退，防御、怪兽攻击和专属镜头接管。
- 髋部与胸肩改用拳击源动作中的不同时序。保留既有拳头接触、脚底 IK、下一拳预备姿势；左右镜像、动作速度沿用已经识别到的出手速度。连击重击、踢击和光剑继续使用各自动作。
- 逐拳倾斜从 ±1.55° 收到 ±0.45°，命中震动保留。
- 样片编码优先本机项目的《奇迹再现》，缺文件才使用原有回退音乐；记录 `audio-source.json`。样片事件音效是离线对齐，未包含引导对白，不冒充玩家实时录像。

## 动作来源与复现

CMU [subject 13, trial 17：boxing](https://mocap.cs.cmu.edu/search.php?subjectnumber=13&trinum=17)。BVH 来自 [转换库](https://github.com/una-dinosauria/cmu-mocap/blob/master/data/013/13_17.bvh)。感谢 CMU Graphics Lab 和 NSF EIA-0196217；数据可用于研究及产品，不把数据本身单独转售。原始下载仅留本地缓存。

源 SHA256：`5eba9811c5031d661f013e7269233c21878a9b70be0a1a4bed49baaec0161634`。取第 170–300 帧，第 238 帧对应伸拳峰值。抽取髋轴与肩轴水平角，移除终点朝向漂移，分别缩放 0.24／0.26；生成 33 个采样点，运行时平滑插值。源接触点映射到现有 0.12 秒命中／发射时刻，回收按近战 0.38 秒、远程 0.42 秒结束。

这里只采用**身体转动时序**，不是整个人物的全身动捕替换。脚、手和最终接触仍由项目动作与 IK 驱动。
