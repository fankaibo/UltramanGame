# 英雄出拳踏步与支撑（2026-09-27）

参考根目录街机录屏的连续出拳段落，角色攻击时需要身体前进、脚步承重和收势共同发生。现有梦比优斯、赛罗、捷德、格力乔虽然已校准手部方向，但原素材在出拳时会将双脚一起抬起，支撑脚同时移动和转动。本轮为这四位英雄加入独立的腿部约束；迪迦继续使用此前烘焙的拳击脚步。

出拳侧脚在命中前抬起并跨出，另一只脚保持在原落点；命中后前脚短暂停留承重，再抬脚收回。髋部按腿长适度下沉，膝盖朝前弯曲，脚掌保留站姿朝向。手臂瞄准在下半身调整后进行，避免下沉让拳头脱离目标。上一帧的修正会在下一次动画采样前移除，防止快速连拳时累积姿势。

动作识别、0.12 秒普攻命中、0.38 秒回收、默认 50 次血量、15 次普攻蓄满及引导后 3 秒准备时间均未改变。帧率专项继续后置。

## 画面对照与测量

`artifacts/roster-footwork/index.html` 提供梦比优斯的同步左右对照视频，以及四位英雄左右拳的接触帧。`comparison.mp4` 为 2.5 秒、75 帧的无声对照；每侧源帧 1280×720，拼接编码 1920×540 / 30 fps，不代表实时运行帧率。前后使用同一输入、镜头及随机种子，原图与各自源码、模型摘要保存在 `before` 和 `after` 中。

实际蒙皮和骨骼测量来自 `logs/roster-footwork-before.log`、`logs/roster-footwork-release.log`，单位为 Unity 场景单位。支撑脚漂移计入三维位移，不仅检查高度；脚掌旋转与初始站姿比较。

| 英雄 | 支撑脚最大漂移（前 → 后） | 脚掌最大转动（前 → 后） | 新版最大拳头接触间距 |
| --- | --- | --- | --- |
| 梦比优斯 | 0.1149 → <0.0001 | 7.44° → <0.01° | 0.2087 |
| 赛罗 | 0.1172 → <0.0001 | 7.44° → <0.01° | 0.2056 |
| 捷德 | 0.1054 → <0.0001 | 7.45° → <0.01° | 0.1537 |

四位英雄跨步最高抬脚约 0.1182，接触停留期间落点漂移小于 0.0001，采样蒙皮最低位置不低于 -0.0036。接触间距是手部前方 0.12 处的采样点到怪兽蒙皮顶点的最近距离，不是完整拳头贴面或物理碰撞的证明。每位英雄均完成两次独立命中、扣血 2 次。

`SurfaceImpactReview.CheckPunchRecovery` 在 15/30/60 Hz 逻辑步进下复核四位英雄的快速连拳、重复零时间采样、暂停恢复和新局复位。本轮在原手部检查中加入脚部和根节点检查，全部通过。逻辑步进频率不是游戏帧率。

已查看实际玩家左右拳回弹，以及离线序列的接触、收脚、恢复站姿画面。45° 镜头中部分脚步会被另一条腿遮住，应结合连续画面与测量观察，不能只用一张图推断双脚位置。

## 复现与剩余差距

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.RosterFootworkReview.After \
  -quit -logFile "$PWD/logs/roster-footwork-release.log"
```

该命令重建新版画面和检查结果，不覆盖已保存的修改前画面。本轮改善的是下半身支撑与拳击接触，四位英雄仍使用现有上身动画，动作数量、转身衔接和源模型细节仍与参考街机有差距。没有使用真人摄像头，也没有把离线渲染或合成动作测试当作孩子实际试玩。
