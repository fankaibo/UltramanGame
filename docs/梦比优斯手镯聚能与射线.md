# 梦比优斯手镯聚能与射线

改动 A-20261009-61；运行时 `54c3a13`，对照基线 `4b4e866`，2026-10-09。整体进度见 [开发任务看板](开发任务看板.md)。

## 依据与当前差距

圆谷[梦比优斯角色页](https://tsuburaya-prod.com/heroes/ultraman-mebius)确认 Mebium Shoot 名称和左腕 Mebius Brace。万代[官方模型页](https://tamashiiweb.com/item/14304/)及其[说明书](https://tamashiiweb.com/images/item/item_0000014304_bxIouAlv_300.pdf)展示右前臂竖直、左前臂横向交叉的发射姿势。本轮直接检查了说明书下方图示；连续的触碰手镯、双臂展开、交叉收束是游戏内制作的衔接，不声称为逐帧复刻原剧。官方参考图仅留本机查阅，不导入游戏、不提交仓库。

旧版直接套用通用 L 形片段，右手过高且手指弯曲；聚能光没有跟随梦比优斯的左腕装置。现在先在模型原有手镯位置聚能，展开双臂后进入十字手位，从右前臂发射；结束后回到准备姿势。光线使用现有梦比优斯暖色方案，聚能丝线、体积和局部受光与之统一。

手指从源网格 bind pose 提取本地旋转，避免仅拉直中间指节却留下弯曲的指尖。动作层每帧还原后再采样，保留原始骨骼长度。原 FBX、模型精度、影视原声与孩子的必杀手势不变。伤害、蓄能和命中时钟也不因此变化。

## 验证过程

旧版完整五秒序列先保存在 `artifacts/mebium-shoot-20261009/before/60/`。首次实现出现手指残余弯曲，实际画面复核后改为源网格绑定姿势；交叉前臂过近也在几何检查中发现并调整。取证变量与既有同名变量冲突、生命周期检查错误查找已隐藏的聚能物体，均保留失败日志并修正检查。

最终专项日志 `logs/mebium-shoot-release-check.log`：

- 15/30/60 Hz 均只有一次发射、一次 9 点命中；300 帧前后玩法状态完全一致。
- 十字手位右前臂偏离竖直约 0°，左前臂偏离水平约 0.82°；交叉中心线前后间隔约 0.108 个场景单位。该间隔是骨骼几何约束，不能等同于逐三角形碰撞检测。
- 原臂长误差约 0.000001，实际蒙皮最低高度 0.002；发射点与光线端点误差 0，零时间重复采样误差 0。
- 15/30/60 Hz 最大单帧手位变化 0.2613／0.1307／0.0658。仅记录当前连续段，没有把这些数值包装成相较旧版的平滑度提升。
- 33 组生命周期覆盖手镯蓄力／十字姿势／发射中暂停、新局、普通光弹／腕剑／防御接管、换人、动作展示页及终结技暂停恢复。换人后聚能颜色恢复，F5 展示页使用对应的十字手位，反复预览不叠加变形。

## 复现

```bash
UNITY='/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity'
# before/ 由旧版运行时生成，请勿用新代码覆盖。
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.MebiumShootReview.After -quit \
  -logFile "$PWD/logs/mebium-shoot-release-check.log"

  -executeMethod UltramanGame.Editor.FinisherReview.After \
  --finisher-output "$PWD/artifacts/mebium-shoot-20261009/beam-regression" \
  -quit -logFile "$PWD/logs/mebium-shoot-regression.log"

.venv/bin/python scripts/cinematic_player_check.py --hero Mebius --linked

.venv/bin/python scripts/guided_player_check.py --hero Mebius --tempo-skills \
  --gesture-wobble --gesture-entry-noise --output artifacts/mebium-shoot-20261009/guided \
  --log logs/guided-mebium-shoot.log
.venv/bin/python scripts/encode_mebium_shoot_review.py
```
