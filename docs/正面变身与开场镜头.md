# 正面变身与开场镜头

本轮继续优先改进街机演出。旧开场始终从背面看英雄，四条细螺旋线占据身体轮廓；镜头俯冲时还会露出背景上沿。参考录屏中的角色主体、连续动作和边缘提示原则，本轮制作了英雄正面揭示镜头，并非对视频某段动作的逐帧复刻。

首次改版的变身为 2.2 秒（9 月 30 日新增怪兽登场后总开场延长至 4.4 秒，见后文）。其中 0.26–1.66 秒使用缓慢推进的正面 3/4 视角，英雄举手与脸部完整入镜。切入、切回各配短促光脉冲，怪兽仅在英雄专属镜头隐藏；返回对战画面后恢复。上升光幕和短光丝替换原来的细螺旋线，局部补光跟随能量强度淡入淡出。

英雄名字放在左侧，体感与键盘共用这段开场界面。战斗开始时的提示缩小到顶部，避免遮住交战角色；键盘模式不显示空的摄像头预览。语音、听完后的 3 秒准备时间、默认 50 血量、15 次普攻蓄能以及动作识别门槛保留。

角色、光效和镜头现在使用同一个变身进度。旧表现层的局部时钟在暂停后会重置，新版恢复原进度，不重放已触发的切镜闪光。重开和进入战斗会清理变身光幕与隐藏状态。

## 哥尔赞登场与双方对峙（2026-09-30）

参考录屏开头给怪兽单独亮相的演出，当前版本在英雄变身后增加哥尔赞登场。怪兽迈出左右两步，脚下碎石和低位尘土随实际脚部接地触发；胸部和头部抬起，嘴部张开并播放一次低吼，随后回到双方对峙。背景保持用户选定的富士山夜景，没有照搬视频的红色背景或字幕。

开场总时长由 2.2 秒延长至 4.4 秒。原英雄正面揭示仍在 0.26–1.66 秒，怪兽镜头为 2.20–4.10 秒，4.40 秒正式开战。怪兽专属镜头隐藏英雄，切回后恢复显示；英雄镜头继续隐藏怪兽。双方的移动、脚步、张嘴、低吼事件和镜头读取同一个 `Battle.TransformationAge`，暂停不重放已触发的事件，重开清除计数和隐藏状态。演出期间的拳击／必杀不会造成伤害；开战后可立即出拳，语音时长加三秒反应时间仍从战斗指令开始播放时计算。

两步使用固定支撑脚与抬脚轨迹，身体重心随前后脚移动，结束时回到原战斗位置。脚步也会带动附近废墟轻微震动，强度不足以拆落构件。低吼是 0.88 秒的原创合成音效，并非影视原声，沿用现有静音、暂停和语音优先混音。英雄核心发光在变身结束后回落，不在怪兽镜头期间继续闪烁。

此前的战斗检查、角色取证工具和预热代码多处写死了 2.3／2.4 秒开场等待，已改为读取 `Battle.TransformationSeconds` 并保留原有战斗前缓冲时间。这些改动用于让原检查继续进入真正的战斗阶段，未放宽原动作和伤害断言。
