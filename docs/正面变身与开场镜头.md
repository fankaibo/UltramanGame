# 正面变身与开场镜头

本轮继续优先改进街机演出。旧开场始终从背面看英雄，四条细螺旋线占据身体轮廓；镜头俯冲时还会露出背景上沿。参考录屏中的角色主体、连续动作和边缘提示原则，本轮制作了英雄正面揭示镜头，并非对视频某段动作的逐帧复刻。

变身仍为 2.2 秒，其中 0.26–1.66 秒使用缓慢推进的正面 3/4 视角，英雄举手与脸部完整入镜。切入、切回各配短促光脉冲，怪兽仅在英雄专属镜头隐藏；返回对战画面后恢复。上升光幕和短光丝替换原来的细螺旋线，局部补光跟随能量强度淡入淡出。

英雄名字放在左侧，体感与键盘共用这段开场界面。战斗开始时的提示缩小到顶部，避免遮住交战角色；键盘模式不显示空的摄像头预览。语音、听完后的 3 秒准备时间、默认 50 血量、15 次普攻蓄能以及动作识别门槛保留。

角色、光效和镜头现在使用同一个变身进度。旧表现层的局部时钟在暂停后会重置，新版恢复原进度，不重放已触发的切镜闪光。重开和进入战斗会清理变身光幕与隐藏状态。

## 复现

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.EntranceReview.After \
  -quit -logFile "$PWD/logs/entrance-after.log"
```

帧率专项继续后置。开场的角色可见性与镜头层次得到改善，但参考街机的动作种类、场景互动和整体演出丰富度仍未全部实现。
