# 迪迦必杀特写构图与推进（A-20261019-168）

基线 `ea3084e`。重新查看街机录屏 50–56 秒代表段及当前发行包，现有大招特写虽然放大了角色，但视线偏低：腿部占据画面，头盔进入上方字幕黑边；两侧固定屏幕斜线也与实际聚能流光脱节。

## 实现与取舍

- 仅迪迦的大招专属镜头提高机位和视线，构图为头部、前臂与聚能动作留出空间。镜头仍在原战斗轴前侧，保留三分之二正面与原受击镜头。
- 镜头沿战斗轴轻微推进 0.35 个世界单位，用原特写时钟平滑采样；没有额外动画计时器，暂停或同帧重绘不会继续推进。
- 迪迦去掉两侧屏幕装饰斜线，保留真实的前臂聚能流光、黑边、招式名和已确认原声。
- 动作识别、特写持续时间、光线发射／伤害时机、怪兽反应和原合照流程不变。

第一候选解决了头盔遮挡，但看图发现手指仍接近黑边。初始测试只量头盔和手腕，因此不能证明完整手掌可见；改为同时测量实际蒙皮手指，使用旧镜头源码重做同口径基线，再提高构图。首候选图片、源码与日志保留在 `draft1-*`；未把初次通过当作最终验收。
