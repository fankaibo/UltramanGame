# 左右拳与护手衔接（2026-09-27）

上一轮补齐四位新增英雄的踏步后，继续对照街机录屏的连续出拳。梦比优斯、赛罗、捷德、格力乔在出拳时，另一只手仍跟随旧素材向前伸；两只拳头在战斗方向上的间隔仅约 0.30，轮廓容易被看成双手一起出击。

本轮让两手以同一个胸前准备姿势开始和结束：出拳手沿小弧线伸向怪兽，另一只手保持收拢，肘部向下。护手位置低于脸部，避免遮住角色面部；肩膀前倾与出拳进度同步，腿部继续使用上一轮的支撑与踏步。迪迦继续使用独立烘焙的动作。

护盾、必杀、受击等动作仍独立播放。额外检查发现，退出新护手层时先还原原始动画会导致手臂向外跳一下；现在进入下一个动作时从实际显示的手部姿势开始混合。重复采样仍先移除持续应用的修正，避免连拳时叠加变形。

动作识别、普攻在 0.12 秒命中和 0.38 秒回收、默认 50 次血量、15 次普攻蓄满以及语音后 3 秒反应时间均未修改。帧率专项继续后置。

新版命中间距与本轮修改前一致。该间距是拳头前方 0.12 处的采样点到怪兽蒙皮顶点的最近距离，不能证明整只拳头贴面或完整物理碰撞。

最初的短加速段让手部单帧位移达到 0.53–0.60；调整后四位英雄在 60 Hz 逻辑采样下最大单帧位移为 0.3703–0.4369。它仍高于旧版未收手姿态，因为现在从胸前完整伸出；这项数值与连续渲染共同用于检查跳变，不将其单独当作动画品质结论。

`RosterPunchReview.Release` 完成五位英雄各两次命中；迪迦的测量保持不变。四位新增英雄按 15/30/60 Hz 逻辑步进验证快速连拳、零时间重复采样、暂停恢复和新局复位。护盾测试另外包含从准备姿势进入护盾、退出护盾、普攻命中后的收势中切入护盾；修复后最大单帧局部手部位移为 0.2853–0.3531，保持一次普攻及一次扣血。初次发现跳动的日志保留在 `logs/roster-arms-guard.log`，修复后独立记录在 `logs/roster-arms-guard-fixed.log`。

## 复现与范围

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.RosterPunchReview.Release \
  --roster-output "$PWD/artifacts/roster-arms" \
  -quit -logFile "$PWD/logs/roster-arms-final.log"
```

指定独立输出目录会保留以前的接触与踏步证据；此命令重建本轮 `after`，不覆盖本轮 `before`。新护手用于实际战斗，F5 静态展示页仍展示原素材动作。实际玩家近景中的拳迹仍可见硬边三角面，特效质感有待改善。整体源模型细节、动作数量和长段攻防编排仍未达到参考街机的最终目标。
