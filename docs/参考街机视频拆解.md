# 参考街机视频拆解（2026-09-12）

素材：根目录 `ScreenRecording_09-12-2026 17-42-17_1.MP4`，约 200.5 秒，1206×2622，60fps。视频是商场街机实拍，包含抖音界面叠加层；分析只针对中间街机屏幕，不把抖音控件当作游戏 UI。

## 画面规律

- 角色几乎填满竖屏，玩家动作和角色动作保持同一视觉中心；屏幕边缘只放血量、连击和星级信息。
- 普通战斗使用连续的 3D 场景和明显的前后移动。出拳不是静态换姿势，而是伴随身体位移、命中闪光和短促震动。
- 怪兽攻击前有蓄力和姿势提示，前冲接触时有强烈的烟尘、冲击波和镜头反应。
- 大招先给出简短动作提示，再切入蓝白高亮的专属演出；光线贯穿角色和目标，命中时有全屏级亮度变化。
- 指令文字位于底部，句子短、字号大、停留时间足够；画面中央尽量不放大块面板。
- 胜利画面仍保留角色和场景，结算信息采用边缘化的分数/星级方式，不遮挡主体。

## 与当前版本的差距

- 当前横屏布局已经具备城市街区、双方角色、右下角镜像预览和大招特写，但顶部 HUD 和底部引导仍比参考视频更厚。
- 当前角色已经是真实骨骼模型，出拳、怪兽前冲、护盾和大招有连续时钟；还需要更多连续动作片段、攻击中的身体位移和更强的命中镜头。
- 当前大招已切换到迪迦正面三分之二近景并有分层光线；后续应继续强化切入/退出节奏和命中时的亮度、烟尘层次。
- 当前合照采用固定大小迪迦加摄像头人物；参考视频没有对应环节，因此合照按独立的友好引导体验验收。

## 后续验收重点

1. 普通战斗中角色占据主要画面，HUD 不压住角色。
2. 怪兽蓄力、前冲、接触、恢复四段都能被看见。
3. 大招提示、蓄力特写、光线发射、命中反馈连成一段连续演出。
4. 每次指令至少留出语音时长加 3 秒反应时间。
5. 电视投屏下保持 60fps 左右，镜像预览不遮挡战斗主体。
