# 哥尔赞肘部与收招衔接（A-20261018-163）

基线 `fd838b9`。上一轮交付肩后镜头，本轮继续处理哥尔赞连续动作中的手臂异常。

## 原因与修复

旧版已有手腕位置过渡和 35° 腕部弯曲限制，但这不能证明整条手臂自然：

1. 挥爪权重只插值手腕目标，肘部弯曲方向始终使用完整攻击方向；权重退到零后，下一阶段突然恢复动画里的肘部方向。
2. 落脚时为了固定爪的接触点，`PoseMonsterStep` 会在腿部开始需要下沉修正的第一帧，把左右肘强制朝身体两侧求解；即使下沉量很小也会突然改变肘部方向。
3. 动作片段切换只捕获旧手腕，新片段的肘部直接参与求解，导致手腕看似平滑而上臂仍外甩。

现在挥爪权重同时过渡肘部方向；承重修正保留原肘部位置所定义的弯曲平面；切换时捕获画面上实际可见的双肘，随手腕一起过渡。保持原骨长、脚步与伤害时钟，不改变识别逻辑或敌人攻击顺序。
