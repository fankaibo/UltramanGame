# 迪迦连续换手与收手衔接（A-20261019-184）

基线 `6d1a68b`。参考街机中左右动作接续、身体持续活动的读法，本轮先测量当前真实骨骼模型的连续光弹。发现换手时，正在准备发射的手已有可见位置接续，而上一拳的手直接切到新准备位置；高位慢速 60 Hz 样本的最大支撑腕单帧跳变约 0.149 场景单位。

## 改动

迪迦每次远程出手都同时记录另一只手在上一帧的实际位置。支撑手在 0.16 动作秒内平滑回到当前准备姿势；沿用已接受的出手速度，只应用一次。连续换手不再重新从隐藏的待机动画定位该手，仍允许实时姿态影响后续准备位置。

识别、输入优先级、蓄能、伤害、光弹发射与命中时序保持。发射手沿用原路径；其他英雄及近战动作保持原行为。
