# 怪兽远距前冲的分步移动

A-20261010-74，2026-10-10；对照 `4173b1d`。参考本机街机录屏的近身接触和当前发行画面，改进远距接近时的支撑脚滑动。上一轮真人起身与自然前伸手位继续保留。

## 原因与改动

原 `PoseMonsterStep` 只为 0.75 场景单位的近身前冲设置一个抬脚弧线。远距站位增加的约 1.40 接近距离，被直接加到左右两脚；即使后脚已经贴地，仍随着身体根节点平移。收回阶段也在前脚尚未抬起时开始平移脚底。

现在先用后脚完成额外接近，前脚越过后脚，在原 0.40 秒命中时承重；支撑期间保持目标位置。返回时前脚先抬起收回，后脚随后归位。近身距离为零时仍保留原有单步，不改变攻击／格挡／伤害／血量／能量／手势判断或摄像机时钟。

轻落脚和原有重踏分开：接近后脚、回收前脚、回收后脚各有一次低扬尘与较轻脚步音，挥爪重踏继续沿用原来的接触效果。15 Hz 可能在一帧内越过最后落脚与攻击结束，因此在确已完成前脚回收后，允许进入 Recover 的第一帧补记最后一次落脚；不重播接近或挥爪事件。

## 当前检查

- 实际哥尔赞骨骼的左右爪 × 15/30/60 Hz，6 组通过。60 Hz 记录的支撑阶段单帧贴地位移由约 0.06476 降至 0.000003 场景单位。检查只针对上述固定距离前冲场景，不是全局自然度评分。
- 重复采样误差为 0；网格最低点约 -0.000002（数值误差）；60 Hz 最大手部单帧位移仍为 0.185109。每轮 1 次格挡、0 受击，三个轻落脚事件各触发一次。
- 左右爪两段共 360 条旧新玩法状态逐字节一致；视频使用同输入、同机位、同随机种子和实际 Unity 输出帧，6 秒、30 FPS 离线编码，不代表游戏帧率。
- 既有腕部／手指 12 组稳定性检查通过，包含挥爪、连续命中、必杀、暂停恢复和新局；腕角约束保持 35°。
- 最终生命周期 18 组通过：15/30/60 Hz × 三个打断时刻 × 暂停恢复／新局，重复采样不重播脚步，清理后不遗留落脚事件。
- 完整检查：45 Python 测试、1085 核心 + 3 桥接集成检查通过。新增 31 项步序约束验证贴地不平移、攻击时前脚落地、动作结束前双脚归位、近距兼容和采样范围。

暂停专项初次错误地只等待 1 秒，而产品现有稳定跟踪恢复门槛为 1.2 秒；随后又把暂停清理特效计数误当作必须保留的累计数。按现有规则更正验证等待和清理期望，没有修改产品恢复规则，也没有降低脚底／手腕阈值；两次失败日志留存。
