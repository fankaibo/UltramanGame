# 英雄原模型局部遮蔽

改动 A-20261009-66，2026-10-09。实现 `2ff5c71`，对照 `9e41523`。

## 依据与改动

复看用户录屏 52–56 秒的连续攻击，并对照当前发行画面。参考机台中角色占屏大，头盔、胸肩的造型和材质层次更清楚。当前迪迦有局部几何遮蔽贴图，其他英雄没有；源贴图尺寸与模型精度的差异见 [资源审计](英雄模型资源审计.md)。

本轮用项目原有 FBX 在静止绑定姿势下，给赛罗、梦比优斯、格力乔烘焙短距离局部遮蔽。共六张 1024×1024 数据贴图：赛罗头部、头镖、身体；梦比优斯身体、腕部装置；格力乔身体图集。范围为模型高度的 2.5%，只烘焙局部几何，避免把某个战斗姿势的手臂投影永久画到身体上。

运行时将数据用于头盔、胸甲接缝和关节凹陷的环境光遮蔽，并加入小幅直接受光衰减。亮面和原色图集保持原有信息。独立眼灯、计时器材质不接入遮蔽，身体图集内的发光区域也使用原始颜色。迪迦既有处理和捷德临时模型配置保留。

这是一项局部材质修整：近景的接缝层次更清楚，常规战斗距离下提升较克制。**没有增加网格细节或原色贴图分辨率，不能视为精细模型替换，也没有达到整体街机视觉目标。** 捷德机敏形态仍按用户要求暂缓；泽塔、德凯强劲型仍缺模型。

## 资源与可追溯性

- 脚本：`scripts/bake_hero_cavity.py`，Blender 4.5.13 LTS，CPU、32 渲染采样、64 AO 采样、12 像素边缘扩展。
- 三个角色的 `Occlusion/bake.json` 保存原 FBX 哈希、烘焙参数与每张输出哈希；派生资源来源沿用父目录的 `ATTRIBUTION.txt`。
- 六张 PNG 总大小约 1.2 MB；Unity 使用线性数据、mipmap、不可读 GPU 纹理。新增纹理有占用，不将本项当作性能优化。
- 原 FBX 文件与 `9e41523` 逐字节相同，因此源网格、UV、绑定和动作没有被重导出。

## 验证与画面

证据根目录 `artifacts/hero-cavity-20261009/`。`before/`、`after/` 各有五英雄六组相同镜头、相同实际舞台灯光的待战／护盾／必杀姿势。源码哈希分别与旧提交及当前实现核对，`pixel-comparison.json` 保存逐帧差异；迪迦和捷德没有超过 1/255 的单通道变化。

`HeroCavityReview` 用实际材质和冻结的原模型，在固定光照下检查 GPU 遮蔽与发光输出。结果：

| 英雄 | 贴图 | 可测遮蔽像素 | 相同时间重复渲染差异 | 眼灯／计时器／护盾发光差异 |
| --- | ---: | ---: | ---: | ---: |
| 赛罗 | 3 | 3635 | 0 | 0 |
| 梦比优斯 | 2 | 3202 | 0 | 0 |
| 格力乔 | 1 | 4048 | 0 | 0 |

这些像素数用于确认数据生效及排查漂移，不是画质评分。目视检查正面与侧后方多姿势，未见新增明显硬边；真实电视亮度与儿童现场体验仍待验收。

## 复现

```bash
.cache/character-tools/Blender.app/Contents/MacOS/Blender \
  --background --disable-autoexec --python scripts/bake_hero_cavity.py -- \
  --hero Zero --output artifacts/hero-cavity-20261009/bake/Zero
# Mebius、Grigio 同样调用；不要覆盖原 FBX 或原色贴图。
UNITY='/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity'
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.HeroCavityReview.Release \
  --material-output "$PWD/artifacts/hero-cavity-20261009" \
  -quit -logFile "$PWD/logs/hero-cavity-after.log"
bash scripts/check.sh
bash scripts/build_macos.sh --release
.venv/bin/python scripts/cinematic_player_check.py --hero Zero --linked --guard-handoff
.venv/bin/python scripts/guided_player_check.py --hero Grigio --tempo-skills \
  --gesture-wobble --gesture-entry-noise \
  --output artifacts/hero-cavity-20261009/guided \
  --log logs/hero-cavity-guided.log
```

整体进度仍以 [开发任务看板](开发任务看板.md) 的 70.2% 为准；缺失素材、角色连续动作、原声与现场验收尚未完成。
