# 必杀光束体积与接触亮光（2026-09-27）

旧版命中闪光直接叠加到整个屏幕，光线命中时把富士山、地面和战衣一起染成亮蓝色；持续光束又偏细，容易看成一根发光线。本轮把闪光集中到真实接触位置，加宽光束的白色核心和蓝色外层，让命中瞬间仍能看清角色轮廓。

光束使用带覆盖率的白色核心、透明蓝色外层和向前流动的细丝，沿用原发射、接触、持续与收束时钟。普通命中、连击节点和怪兽前冲的亮光也改为按世界位置投影；相机移动后重新投影，冲击波按屏幕比例校正为圆形。变身与必杀特写切入保留较弱的整体亮度变化。

画面复核还发现原有胸骨估算点没有贴合皮肤。现在哥尔赞初始化时只在胸部区域选择一个网格三角形，缓存三个顶点的骨骼权重和坐标；光束、持续火花与接触补光随实际蒙皮点变化。普攻仍使用原有目标，避免这次光束调整改变四位新增英雄的出拳轨迹。

打包版需要保留哥尔赞网格的 CPU 读取权限，已同时修改资源 `.meta` 和导入器，避免重新导入时丢失设置；其余角色仍保持原设置。初次实机检查发现此差异导致启动异常，已经补上读取检查及可追踪的回退，并在玩家验收脚本中要求实际绑定成功，不能靠回退通过验证。

## 连续画面对照

视频是离线 30 fps 渲染，不代表游戏运行帧率；帧率专项继续后置。命中静帧两侧均取模拟帧 120，避免把不同闪光阶段当成差异。`provenance.json` 将修改前运行时代码与基准 Git 提交核对、修改后与当前工作区核对，并记录实际游戏验证来源。
