# 格尔赞发光消散退场（2026-09-29）

当前实机与参考录屏相比，胜利收尾主要依赖怪兽透明淡出。新演出保留失衡、落地和英雄转身，在原来的退场时间内，让怪兽从实际身体表面逐步消散，再由向上散开的光粒接回英雄庆祝。

## 画面与时序

- 胜利 2.65–3.55 秒：从身体低处向上推进，叠加不规则的空间波纹，留下短暂的金色发光边缘。
- 光粒来自一次采样的真实倒地模型，使用与表面相同的消散函数决定出生时间。384 个光粒向外、向上移动并淡出，没有循环播放。
- 哥尔赞身体、眼睛、常规阴影和接触阴影都裁掉同一部分。仍存在的身体区域保持不透明深度，不透出背面的模型。
- 消散开始时只触发一次低空尘雾与轻声上扬音效；保持原有胜利语音。光粒在自动合照前完全消失。
- 骨骼动作、英雄转身、血量规则、动作识别，以及胜利至少 6 秒且语音结束后再自动合照的规则均未改。

`MonsterDissolve` 在消散开始时采样一次实际蒙皮，并复用同一个网格。表面和接触阴影共用 `KaijuDissolve.cginc`，光粒使用显式胜利时钟；暂停时钟、重开和下一局不会残留旧的消散状态。哥尔赞眼睛改用关闭皮肤凹凸的同一着色器，使眼部和身体使用一致的裁剪范围。

  -executeMethod UltramanGame.Editor.MonsterDissolveReview.Release \
