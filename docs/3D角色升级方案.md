## 已取得的素材与处理

用户授权访问 BlendSwap 并完成账号登录后，通过其下载按钮取得 [Extrazhang / Ultraman Tiga](https://blendswap.com/blend/26877) 的 22.8 MB Blender 文件。页面标注 CC-BY-NC。原始文件完整保留在本机忽略目录；源作者署名、发布页、许可和修改说明见 [ATTRIBUTION.txt](../unity/Assets/Resources/Characters/Tiga/ATTRIBUTION.txt)，随导入素材打包。不得将该模型当作 Apache-2.0 代码素材或官方商业授权。

转换工具为 Blender 4.5.13 LTS，来自 Blender 官方 Apple Silicon 安装包，SHA-256 已与官方下载清单核对。工具置于本项目 `.cache/character-tools`，不要求玩家安装 Blender。读取下载文件时禁用自动脚本，不运行内嵌 Python。

可重建命令（替换 Blender 可执行文件和原始文件路径）：

```bash
Blender --background --factory-startup --disable-autoexec \
  --python scripts/prepare_tiga.py -- \
  'artifacts/character-sources/Ultraman Tiga.blend' artifacts/character-review/tiga --export --review
```

脚本提取原模型内嵌身体纹理、简化材质、编排 IK 动作并烘焙全部骨骼，输出 FBX 与 PNG；将两者复制到 `unity/Assets/Resources/Characters/Tiga/`。FBX 明确统一导出单位。Unity 用当前蒙皮顶点而非包含所有动作的缓存包围盒计算 3.45 单位站高，并在动画层级之外做尺寸归一化，避免动画改变角色尺寸或导致悬空。角色切换时做短暂骨骼混合，普攻沿双方连线前进后归位。

骨骼素材渲染检查入口为 Unity 菜单 `UltramanGame → Review skeletal combat`；批处理使用 `UltramanGame.Editor.RiggedReview.Render`。它验证尺寸、脚部高度、手腕及腰部变形、格挡/普攻/光线衔接，生成 300 帧无摄像头战斗预览。批量静态渲染额外对当前蒙皮做快照，避免没有 Player Loop 时 GPU 蒙皮停在上一帧。

## 模型进入游戏前需要看到的结果

1. 迪迦正面和背侧 45° 外形清楚：头盔、眼睛、计时器、胸甲、红紫银分区与身体比例正确。
2. 骨骼驱动下完成站立呼吸、收拳出拳、护盾、L 形光线、受击恢复，肩肘与腰部没有明显穿插或撕裂。
3. 哥尔赞有尾部、躯干与四肢的连续运动，前冲、挥爪、命中与回位衔接，不是整块模型平移。
4. 在现有城市背景与双方 45° 站位中检查灯光、材质、脚部落点；适配后的模型要看起来在同一场景里。
5. 先完成短战斗片段“几次普通攻击 → 怪兽反击 → 格挡 → 大招”，再决定是否扩展更多角色。保留现有合照和已验证的家庭玩法。
