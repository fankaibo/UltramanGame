# 举手开始与按键选角（A-20261011-109）

用户反馈双手举起不能开始，并明确要求不要手势切换英雄。源码基线 `92c942b`；同时保留上一轮尚未提交的 A-107 镜头改动，分别记录验证范围。

## 证据与修复

- 最近实际运行的 `logs/game-last.log`（2026-10-11 08:39）包含连续的 Tiga → Grigio → Tiga → Mebius 选角记录，末尾没有进入战斗。旧等待页的单手选角识别器会在孩子先举起一只手时触发角色替换，并重置开始识别。
- 删除 `HeroSelectionGesture` 和全部运行时调用。等待页仅支持左右方向键或点击卡片选英雄；单手举起不选角。双手举起开始，键盘模式仍为空格开始。合照中的单手重拍是独立功能，保留。
- 原变身高度阈值使用含深度的肩宽，摄像头推断深度异常时要求手举得更高。开始通道改用画面中的肩宽和腕部高度，接受可见的中等置信度手腕；战斗出拳、护盾和必杀几何规则不变。
- 手腕短暂不确定时最多暂停进度 0.20 秒，不累加时间，也不当作放手。合照续局仍要求实际放下双手后再举起；界面明确显示“先放下双手，再举高开始”。
- 按键选角后的 0.5 秒稳定窗口在识别前生效，避免开始事件先被识别器消费、随后被控制器丢弃，导致保持举手再也无法触发。
