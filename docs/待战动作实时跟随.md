# 待战动作实时跟随（A-20261010-77）

对照用户录屏，现有角色主要在离散招式触发后才运动。待战时抬手、收手准备动作不进入英雄动画。本次增加独立的连续显示通道，保留原来已可接受的识别阈值和战斗规则。

## 行为和边界

- 开场和战斗待机分别读取左右手腕；按肩宽归一化、按真实臂长转换，支持半身入镜，不依赖不稳定的深度估计。
- 指数平滑准备动作；一只手被遮挡只影响这只手，旧画面／追踪中断／输入模式关闭时回到自然待战。肩腕距离约束在臂长的 80%–92%，避免紧缩或锁死手肘。
- 出拳／护盾／大招／受击由既有动画接管。确认姿势时继续提供准备反馈，实际招式开始后由招式动画接管；显示数据不产生任何游戏输入，也不改变识别器、命中、冷却或语音窗口。
- 暂停仍保留 A-76 的自然前伸，F5 与合照的独立姿势不跟随。它是准备动作反馈，并非全身动作捕捉，也不宣称已经达到街机整套连续表演。
