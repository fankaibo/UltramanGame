# 迪迦出拳轨迹衔接（2026-09-28）

上一轮发现的 `RiggedReview` 失败已经定位并修复。它发生在右拳开始后的第 0.067 秒：源动画中的手腕已经向前运动，运行时又对这条移动中的轨迹做一次快速插值，导致早期加速度叠加。30 Hz 的基准序列里，右手先移动 0.269 个场景单位，下一帧突然移动 1.056。

现在源动画继续驱动身体转动和踏步，拳头则从胸前护手姿势沿单一曲线伸向怪兽胸口，再收回。左右手保留小幅不同的弧线，另一只手仍收在胸前；命中仍在原来的 0.12 秒，没有延迟输入、修改识别或改变伤害规则。

同一序列现在的前三帧位移为 0.562、0.864、0.565；原先对应为 0.269、1.056、0.770。最大单帧位移下降约 18%，用于消除突然前冲，不代表所有拳头速度都减慢。修改前后的 300 帧战斗状态逐项一致，包括动作、动作时钟、护盾、敌人阶段、血量和能量。
