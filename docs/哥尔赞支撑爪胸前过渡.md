# 哥尔赞支撑爪胸前过渡（A-20261015-144）

## 目标

参考三季度角度的发行回放，哥尔赞挥爪时的非主攻手曾被导入动作曲线抬到下颌旁，两个手掌在头部附近重叠，导致主攻手、支撑手和身体重心难以读清。本轮只处理这个表现层问题，不改动作识别、伤害、接触时钟或怪兽攻击顺序。

## 改动

`RiggedActor.CorrectAttackArms` 保留主攻爪的连续斜向挥爪轨迹，把支撑爪目标从 `height=2.20 / depth=.62` 收到胸前 `height=2.02 / depth=.48`。目标仍通过同一 `AimClaw`、支撑肘极点和原有 `settle` 时钟解算，攻击结束时自然交还导入动作。

这样在 45° 交锋镜头中，支撑手落在胸前、主攻手进入接触点，减少两只手挤在脸旁的折叠观感；预警、石块、地面砸击和受击专用姿态不受这条支撑目标影响。

## 边界

当前仍使用哥尔赞现有骨骼和动作资源；本轮不是重新制作怪兽手部模型，也不代表已经达到参考街机的最终连续动画质量。后续如取得更精细的哥尔赞手部资产，应在同一支撑目标接口上替换并重新做 15/30/60 Hz 验收。
