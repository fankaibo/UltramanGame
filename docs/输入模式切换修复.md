# 输入模式双向切换（2026-09-16）

原先的切换按钮只在键盘战斗页底栏中。体感使用精简街机界面，没有绘制该底栏，导致切到体感后找不到返回入口；设置和合照的提前返回还会跳过 F2。

本次修复：

- 体感界面左下角保留“切换按键 · F2”，键盘界面显示“切换体感 · F2”。等待、战斗、暂停、胜利、必杀特写和合照均有入口。
- 设置窗口右上角提供同一切换按钮，F2 在设置和合照内也处理。
- 切换清理旧姿态和手势，不再重新开局；保留血量、能量、所选角色及已打开的设置／合照。切到体感而没有有效识别流时仍按原规则暂停，切回按键后恢复。
- 已打开合照时，即使切换到按键，也继续更新摄像头预览。

验证：源码编译、Unity macOS 打包与本地签名通过。实际玩家进程中，用空格开始、A/D 命中两次，再经 F2 切到体感、切回按键，并在 F4 设置中往返切换；全过程保留怪兽血量 48/50、能量 2/15 和迪迦，设置窗口未被关闭。退出设置后恢复同一局。证据：`logs/input-mode-player.log` 中的 `[InputMode]` 与 `[Input]`，构建证据为 `logs/input-mode-build.log`。

实际截图已确认体感左下角和设置右上角的按钮及文案可见。自动鼠标工具在点击不同位置时，Unity 收到的指针位置没有随之更新，所以本轮没有将按钮鼠标点击记为通过；快捷键双向切换已验证。没有打开真实摄像头，未复测孩子动作或本轮合照内的模式切换。
