# 梦比优斯左腕光剑与挥斩

改动 A-20261009-58；实现 `19a7ca1`；2026-10-09。对照基线 `7849cb0`。任务状态以 [开发任务看板](开发任务看板.md) 为准。

## 原因与修改

旧光剑使用两条面向相机的线，方向按世界坐标旋转，角色仍沿用普通直拳。转动镜头后刃面变薄，剑身与前臂也会分离。

新版从现有模型 `MebiusBrace` 材质对应的 579 个顶点标定手镯中心，缓存到左前臂坐标。剑从真实手镯出刃，随前臂旋转；使用有厚度的收尖网格、琥珀色外缘和亮芯，短拖尾记录剑刃实际扫过的位置。[万代官方手镯介绍](https://toy.bandai.co.jp/ja/topics/01_19804/) 将「メビュームブレード」列为梦比优斯招式，并描述从手镯伸出光剑、挥臂斩击的流程。它支持这里的武器定位；具体动作曲线是本项目制作，并非提取原片动画。

左手近战改为转肩、挥斩、回收，右手保持护胸；剑刃长度计入手臂求解，因此角色不再像短拳一样冲到怪兽身上。右拳、远程光弹、第五击和必杀仍用原有分支。普通拳击的蓝色手部拖尾在光剑挥斩时停止发射。没有改变动作识别、伤害、必杀蓄能或命中时钟。

首次连续预览发现快斩手臂转动过大，已调整起始轨迹、随挥位置与回到护胸的过渡，并从正面检查收招。最终保留源 FBX 和贴图；本轮不提高人物网格精度。

## 已通过的专项检查

- 15/30/60 Hz 三种步长，慢速左剑、快速左剑和普通右拳：每组 3 次命中，前后 300 帧战斗状态完全相同。
- 实际剑轴与前臂最大角差约 0.028°，手臂长度变化小于 0.000002 个场景单位，手镯锚点误差约 0；蒙皮最低点约 0.002。
- 三种步长 × 三档速度共 9 组生命周期：三种时机的防御接管、连续五击、重复绘制、相机转向、暂停、新局、必杀特写、角色更换、远程和第五击排他全部通过。实际更换为赛罗再换回也没有残留剑刃。
- 低采样率的最快挥斩会跨过命中时刻。15 Hz 当前帧剑尖与目标间距最大 0.875；上一帧到当前帧的扫掠段与目标最近距离不超过 0.285。两项分开记录，不能声称每个离散画面都精确贴住目标。
- 60 Hz 最大单帧手位变化由旧版 0.8674 变为 0.8764，本轮没有证明整体动作速度更平滑；改进的是腕部绑定、立体剑形与挥斩动作。低帧率连续性仍需继续完善。
- `bash scripts/check.sh`：41 项 Python 和 904 项规则／姿态／通信检查通过。过程日志在 `logs/mebium-blade-*.log`，早期预览与最终结果分别保留。
