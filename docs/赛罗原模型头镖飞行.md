# 赛罗原模型双头镖飞行与归位

改动 A-20261009-57；实现 `fa7c4a6`；2026-10-09。此前版本 `fb05a70`。总体进度见 [开发任务看板](开发任务看板.md)。

## 变化与原因

旧版在远程出招时生成两个简化的新月形特效，模型头部的两片头镖没有离开，画面上出现重复。现有赛罗资源已包含 `slugger_L`、`slugger_R` 专用骨骼和 `Zero_Sluggers` 材质：每片在源网格上有 536 个完全绑定的顶点；Unity 因 UV／法线拆点后，两片合计 2,526 个蒙皮顶点。

新增 `ZeroSluggerRig` 从蒙皮绑定矩阵计算两片头镖的几何中心。身体动作采样前恢复挂载姿势，身体动作完成后记录新的挂载位置；飞行阶段直接移动这两个骨骼。保留源模型的形状、贴图、材质和大小。两片分别沿弧线飞向命中点，再回到动作中的头部，同时旋转回挂载角度。绘制范围随原头镖扩展，结束时恢复。

`HeroProjectile` 绑定真实骨骼后关闭额外的简化头镖，独立拖尾继续使用。未绑定角色的特效单元仍可使用原回退模型。伤害、动作识别、攻速、发射与命中时钟均保持原样；没有添加新的出招动作要求。

## 复现与连续画面

```bash
UNITY='/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity'
# Before 用 fb05a70 的运行时代码与 ZeroSluggerReview 保存基线，之后恢复新运行时代码。
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ZeroSluggerReview.After -quit \
  -logFile "$PWD/logs/zero-slugger-after.log"
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ZeroSluggerLifecycleReview.Validate -quit \
  -logFile "$PWD/logs/zero-slugger-lifecycle-final.log"
bash scripts/check.sh
bash scripts/build_macos.sh --release
.venv/bin/python scripts/cinematic_player_check.py --hero Zero --linked
# 将本次 player-validation.json 复制至 zero-slugger-20261009/native/。
.venv/bin/python scripts/guided_player_check.py --hero Zero --tempo-skills \
  --gesture-wobble --gesture-entry-noise --output artifacts/zero-slugger-20261009/guided \
  --log logs/guided-zero-slugger.log
.venv/bin/python scripts/encode_zero_slugger_review.py
```

本机连续视频 `artifacts/zero-slugger-20261009/comparison.mp4` 为左旧右新、5 秒三次不同速度释放。另有头部“发射中／归位后”近景。编码脚本核对源代码、原模型、300 帧玩法状态与发行包哈希后生成索引；离线 30 FPS 导出不代表实际运行帧率。证据文件位于忽略目录，不提交公共仓库。

这是原模型武器动作的修正，没有提升其他英雄网格精度。影视级角色与完整连续动画、缺失角色素材和原声、真实儿童及小米电视现场仍未完成；总体进度保持 70.2%。
