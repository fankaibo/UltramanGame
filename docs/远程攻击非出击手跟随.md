# 远程攻击中的非出击手跟随（A-20261011-111）

基线 `caa86ac`。用户要求游戏动作随真实玩家动作变化，同时保留现有可接受的识别规则。本轮改显示层：过去摄像头跟随只在待机时运行，一旦出招，另一只手也被统一收回固定护胸位，左右交替仍像循环播放同一套动作。

## 改动

- `LiveReadyPose` 在普通远程攻击期间继续读取**非出击手**的位置。出击手的目标值和身体跟随目标归零，由既有出招动画拥有控制权。
- 非出击手在护胸范围内用较小幅度跟随，收手时逐步回到跟随姿态。识别阈值、姿态类别、攻击速度、伤害、飞行和命中时机不变。
- 手腕遮挡、过期数据、关闭跟随、暂停、正式护盾和必杀仍交回原动画。没有新增手势选角；左右按键／卡片选择、双手开始和合照后放手重举保持。
- 增加独立 Unity 对照入口 `RangedSupportReview`、真实发行包左右支撑手截图标记及回放 `--support-follow` 检查。

## 对照与自动检查

新增回归用例在旧版真实失败：`support hand continues camera follow during ranged cast 15/False`，记录 `logs/a111-reproduce-core.log`。修复后 46 Python + 1780 项核心／桥接检查通过。

`artifacts/ranged-support-20261011/`：15／30／60 Hz 共 **525 行**游戏状态、动作时钟、血量、能量、发射和命中记录前后完全相同。每组 3 次远程攻击，慢／标准／快三种速度。

- 非出击手最大变化约 0.330／0.393／0.394 世界单位，来自输入手位，而不是额外攻击。
- 发射窗口（动作年龄 0.13～0.22 秒）出击手的位置差为 0。其余攻击时段最大差不超过 0.000061，来自接续姿态的数值收敛，不宣称整段所有骨骼字节一致。
- 60 Hz 最大单帧手位变化约 0.4012，保持原限制；重复零时间采样位置差为 0。
- `before-after.mp4` 为左右并排的五秒同输入连续 Unity 渲染，左旧右新，非真实摄像头录像。保留两侧关键图、CSV 和验证数据。
- 新增发行截图标记曾因局部变量 `key` 重名导致 Unity 编译失败，已修正为独立名称后重新验证；没有交付该失败中间版本。
