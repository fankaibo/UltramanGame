# 高位出招保护手（A-20261012-128）

2026-10-12，基线 `0f3af64b62777af71519a7388245ff780ccc2fae`。上一轮高位识别已交付，属于 Progress。本轮复看本地街机录屏 60 秒代表帧与 A-127 高位实际包画面，处理迪迦发射时另一只手紧缩在颈旁的可见问题。

## 问题与实现

发射手已经能伸出，问题来自保护手：旧目标固定在肩前 0.28 单位，并向身体中心收拢；迪迦的整条手臂约 1.08 单位，导致高位保护手的肘角仅 32.52–33.81°。原生画面中，右手保护时拳头贴在颈侧，左手保护时拳头从颈部附近露出，造成双臂紧缩的观感。

仅对迪迦远程攻击中的非发射手，改用自身臂长确定身体前方的弯肘保护位置，并略微向同侧让开，继续跟随已有摄像头手位偏移。发射手和回收时钟不变。新高位肘角 71.09–71.59°，保护手仍短于发射臂，容易区分哪只手正在攻击。
