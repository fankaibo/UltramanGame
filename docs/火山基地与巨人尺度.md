# 火山基地与巨人尺度

参考根目录街机录屏和 `artifacts/reference-video/punch-sequence.jpg`，建筑、道路与巨大角色之间的比例，是街机画面的一部分。此前火山战场只有岩石与熔岩，缺少人类尺度参照。本轮在现有富士山与动态火山背景中加入废弃观测基地，不改角色站位、镜头曲线或动作识别。

## 场景

- 左右两处开放的混凝土建筑残骸，楼板逐层断开，门窗是实际几何开口；破损柱顶露出弯折钢筋，内部有倾斜楼板与碎块。
- 后方加入坍塌车棚和支架；右侧有缺口储罐及断管；左侧有贴合地形的道路、破损护栏、标线和两辆小型车辆。
- 设施保持低矮，主体落在战斗区两侧与后方。富士山远景、熔岩喷口、烟柱与双方脚下的活动区保留。
- 所有构件在载入时生成，按混凝土、钢铁、道路、标记和残余玻璃合并为五组静态网格，不增加战斗物理碰撞或逐帧几何生成。

首轮渲染的立面和路面过于规整，已调整楼层断面、道路断口，并换入实际扫描表面。`OutpostSurface` 按世界坐标投射颜色、法线与 AO／粗糙度，保持竖直断墙的细节；冷色环境光与熔岩光沿用战场已有光源。色彩纹理按 sRGB 导入，法线与材质数据保持线性。

混凝土扫描纹理由 Amal Kumar 制作，来自 [Poly Haven：Rebar Reinforced Concrete](https://polyhaven.com/a/rebar_reinforced_concrete)，按页面的 CC0 许可使用。下载的三张 2K JPEG 与来源、文件摘要位于 `unity/Assets/Resources/Art/Outpost/`。几何由本项目生成，没有使用商场游戏的模型或录屏贴图。

## 同步对照

基准为 `9ed62ed9919a96f7a97168fd670f27ba01f52149`。`VolcanoStageReview` 用同一镜头、随机种子与输入渲染修改前后各 240 张 1280×720 图片，组成 8 秒并排视频；480 条战斗状态完全一致，冻结时钟时画面一致。

本机入口为 `artifacts/volcano-outpost/index.html`。可以播放连续攻防，或切换同位置静帧。离线导出为 30 FPS，不代表玩家运行帧率；帧率专项仍后置。

五位英雄的必杀流程均通过：一次发射、一次命中结算、光束接触跟随、特写与回位；迪迦额外检查 15／30／60 Hz 逻辑步长和飞行、持续命中、消散三个阶段的暂停及新局复位。记录在 `artifacts/volcano-outpost/finisher/after/flow-validation.txt`。已查看普通战斗与必杀近景，建筑位于角色后方及画面两侧。

## 最终程序

macOS 构建及本地签名通过。最终程序集 SHA-256 为 `bf7b8b023cffe98f81050f27233debed4a36910135176668dd87120090e98358`，资源摘要为 `953fc8ba9122bb2c24fef1674f23a428ef6afa69d139648b207e6fa6ca8b02bf`。

实际打包版在 97.46 秒内完成 32 次普攻、2 次大招、3 次格挡、1 次未防御受击、暂停恢复和胜利。1080P 原生截图在 `artifacts/cinematic-combat/player/20260929T174910855827Z/native/`，已查看战斗与正面庆祝构图。

同一构建的无键鼠回放在 138.0 秒完成自动合照 2 次、重拍、照片流中断恢复、预览姿势流中断恢复和举手续局。97 帧防御波动、11 帧大招波动期间误触普攻为 0，防御和大招各成功两次；照片预览与保存中心区域颜色差 P99 为 0。记录位于 `artifacts/volcano-outpost/guided/`。

本轮只使用合成姿势与 TEST 人像，没有开启真人摄像头、上传家庭照片或调用合照 AI。没有重新测定孩子实际动作手感或电视投屏延迟，也没有把模拟回放视为真人验收。

## 复现

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.VolcanoStageReview.After \
  --volcano-output "$PWD/artifacts/volcano-outpost" \
  -quit -logFile "$PWD/logs/outpost-after-refined.log"
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.FinisherReview.After \
  --finisher-output "$PWD/artifacts/volcano-outpost/finisher" \
  -quit -logFile "$PWD/logs/outpost-finisher.log"
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --output artifacts/volcano-outpost/guided --log logs/outpost-guided.log
.venv/bin/python scripts/encode_outpost_review.py
```

修改前使用上述基准提交导出，不能用当前代码覆盖后当作旧画面。编码脚本核对渲染源码、素材摘要、逐帧战斗状态及最终程序摘要。

本轮补足巨人尺度与场景层次。废墟破损仍是固定形态，建筑边缘和车辆细节有限；角色动作丰富度、近景模型与真实合照融合仍需继续提升，不能据此宣称最终街机目标完成。
