# 火山碎块与火星轨迹（2026-09-30）

实际战斗截图和喷口近景中，原先的熔岩弹呈现为始终发亮的小球，光晕边缘有方块感。飞行过程中缺少岩壳、冷却变化和方向，和已有体积烟柱、玄武岩地面不协调。检查确认光晕缓冲已经使用双线性采样，因此本轮处理发光物本身的几何、材质与轨迹，没有再次降低或提升全屏分辨率来掩盖问题。

现在喷出的是翻滚的不规则岩块，表面同时有暗色岩壳和高温裂口，热度随飞行逐渐减弱。细火星用柔和短轨迹显示速度方向，上升、回落和消散沿同一抛物线计算。每块岩石预先计算与实际地面的交点，末段逐渐缩小、冷却；没有加入独立物理时钟。远处岩壳细节根据像素覆盖范围过滤，减少细裂纹闪烁。

64 块熔岩碎块与 80 枚细火星合并成两组固定网格。材质、网格在场景销毁时由 `RuntimeResources` 清理，逐帧复用顶点和颜色数组。裁剪边界来自喷口、落点和最高点，近景转动摄像机也不会因为沿用错误包围盒而丢失整组特效。火星按场景深度遮挡，角色和岩石能挡住后方喷发。

`VolcanicEjectaReview.Validate` 使用实际材质渲染，检查两组网格保持不变、顶点有效且处于裁剪边界内、不会穿地，随后比较可见、移动、冻结、回退时钟及前景遮挡图像。

结果：可见效果影响 7,323 个像素，推进时间后 12,011 个像素变化；冻结和回退时间的差异均为 0，前景物体遮挡泄漏为 0。平地检查中的最低岩块顶点为 0.015，活动碎块数为 19–33，固定网格为 2。图像与记录位于 `artifacts/volcanic-ejecta/inspection`。

`bash scripts/check.sh` 通过 36 项 Python、397 项核心及包含通信的 400 项集成检查。

## 复现

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.VolcanicEjectaReview.Validate \
  -quit -logFile "$PWD/logs/ejecta-inspection.log"
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.VolcanoStageReview.After \
  --volcano-output "$PWD/artifacts/volcanic-ejecta" \
  -quit -logFile "$PWD/logs/ejecta-after.log"
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --output artifacts/volcanic-ejecta/guided --log logs/ejecta-guided.log
.venv/bin/python scripts/encode_ejecta_review.py
```

`Unity` 替换为本机编辑器的完整路径。基准画面必须在基准运行时代码下导出到 `before`，最终对照脚本会拒绝过期源码、不同战斗状态或不同安装包的证据。

这是实时程序特效，不是流体模拟或真实火山影像。废墟几何、角色原始模型和更多连续动作仍有提升空间，本轮不能作为整个街机目标已完成的证明。
