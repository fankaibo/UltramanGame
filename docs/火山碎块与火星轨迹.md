# 火山碎块与火星轨迹（2026-09-30）

实际战斗截图和喷口近景中，原先的熔岩弹呈现为始终发亮的小球，光晕边缘有方块感。飞行过程中缺少岩壳、冷却变化和方向，和已有体积烟柱、玄武岩地面不协调。检查确认光晕缓冲已经使用双线性采样，因此本轮处理发光物本身的几何、材质与轨迹，没有再次降低或提升全屏分辨率来掩盖问题。

现在喷出的是翻滚的不规则岩块，表面同时有暗色岩壳和高温裂口，热度随飞行逐渐减弱。细火星用柔和短轨迹显示速度方向，上升、回落和消散沿同一抛物线计算。每块岩石预先计算与实际地面的交点，末段逐渐缩小、冷却；没有加入独立物理时钟。远处岩壳细节根据像素覆盖范围过滤，减少细裂纹闪烁。

64 块熔岩碎块与 80 枚细火星合并成两组固定网格。材质、网格在场景销毁时由 `RuntimeResources` 清理，逐帧复用顶点和颜色数组。裁剪边界来自喷口、落点和最高点，近景转动摄像机也不会因为沿用错误包围盒而丢失整组特效。火星按场景深度遮挡，角色和岩石能挡住后方喷发。

这是实时程序特效，不是流体模拟或真实火山影像。废墟几何、角色原始模型和更多连续动作仍有提升空间，本轮不能作为整个街机目标已完成的证明。

## 补充：接地、弹跳与余热（2026-09-30）

基准 `fee530126e23139d2526593f2325ef3ba62dff61` 的碎块在飞行末段缩小，尚未落地就消失。现在以旋转后岩块的最低支撑面求第一次地面接触，保持实体大小，接地后短促弹跳并逐渐停止翻滚，停留约一秒后按固定表面图案消散。红热裂口持续冷却，细火星仍沿原飞行轨迹消失。岩块启用随实际轮廓和消散图案变化的阴影；光晕不投影。

落地仍由同一个场景时钟计算，没有添加独立物理模拟或粒子时钟。两组网格和逐帧数组继续复用，裁剪范围包含落地后的少量水平位移。接触使用既有地面高度场及其坡度，不包含独立废墟、喷口岩壳和扫描岩石的碰撞；岩块可能被这些场景物遮住，这不等于已接入完整物理碰撞。
