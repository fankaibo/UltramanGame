# 迪迦发射与命中统一演出（A-20261012-123）

基线 `ddaca89`。A-122 改善了飞行弹头，但普通远程攻击两端仍有大线圈、椭球薄盘、圆环及等方向亮线，与新弹头不协调，也遮挡拳头和怪兽前臂。本轮统一发射、飞行、命中这段演出的形态，不改变技能、战斗节奏或人物动作。

## 实现

- 迪迦发射使用小范围软体积亮芯；取消原先围绕手部的两条固定线圈，保留现有准备／消退时机和手部照明。
- 命中由蓝白短闪过渡为朝入射方向外侧扩散的蓝色薄雾，白热芯在约 110 毫秒内退去。去掉完整圆盘轮廓、圆环和十条规则亮线；保留已有四组弹道火花池、怪兽受击和局部照明。
- 实际命中后立即隐藏迪迦的飞行弹头和光晕，由命中特效接管，尾迹按原有时间淡出。命中时钟和其他英雄不变。
- 两段使用同一 `SkillDischarge.shader` 的不同密度分布，沿用现有球形容器，以 12 步积分得到软边体积。飞行仍为 A-122 的弹头／短尾迹，三个阶段共享既有射击时钟。
- `RangedSkillAccent.SetTigaStyle` 在选择英雄时切换样式并清空残留；其他英雄恢复原材质与原线条。没有增加每发对象、替换声音、改变命中计数或放宽体感门槛。

## 视觉与专项证据

根目录 `artifacts/skill-discharge-20261012/`：

- `comparison.mp4` 左旧右新、5 秒整段对照；`detail-comparison.mp4` 是相同帧的局部放大，`sequence.jpg` 为四个代表时刻。均采用每帧烘焙当前蒙皮的离线 Unity 渲染，导出 30 FPS 不代表实机性能。
- 60 Hz 的 300 行玩法、英雄手位／髋部与肘部数据前后逐字一致；15／30／60 Hz 的慢、中、快三发均恰好三次发射与命中，效果到期和暂停清理通过。
- 五 GPU 视角（0／45／90／135／180°）验证实际发射／命中有可见像素，薄雾随时间变化，零时间重复渲染差为 0。完整前景遮挡不漏光，效果到期不残留。
- 迪迦样式下线圈／圆环／规则亮线禁用，火花仍可见；恢复普通样式后两条线圈、一条圆环和十条亮线重新可见。40 次连续接触不增加对象数量，切样式／Clear 清理通过。
- 15／30／60 Hz 的实际 Battle＋HeroProjectile 路径确认飞行中弹头可见、实际命中后弹头隐藏、每发只命中一次，并可在新局重新发射。
- `scripts/review_light_bullet.py --discharge` 核对 Git 基线与当前渲染源码、状态／骨骼数据和 GPU 结果，再生成视频；`validation.json`、`gpu/validation.txt` 保存结果。
