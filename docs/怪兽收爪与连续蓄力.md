# 怪兽收爪与连续蓄力（2026-09-28）

原先哥尔赞在预警开始 0.4 秒后会长时间停在同一姿势，最后一秒才继续播放准备扑击的动作。前推近景使这种停顿更明显。本轮重新安排已有骨骼动画的播放顺序：展开后收爪、转肩和前倾蓄力，再稍微放松，等待时保持轻微呼吸；最后 1.1 秒衔接原来的扑击准备姿势。

左右预警分别朝下一次主攻爪的方向蓄力。胸部转动时头部小幅反向跟随，手指随收爪动作弯曲；双脚继续由原来的落点约束。运行时仍限制手掌与前臂夹角，未修改源网格、蒙皮、攻击命中时点或识别规则。

`MonsterWindupMotion` 只计算演出曲线。排队中的语音即使在预警最后一秒才延长等待，采样也按有限速度回到等待姿势，避免肩部和嘴部突然跳帧。受击时让出姿势控制，恢复后继续当前预警；新局重置采样状态。
