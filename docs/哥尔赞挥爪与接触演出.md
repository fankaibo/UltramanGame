# 哥尔赞挥爪与接触演出（2026-09-27）

上一轮手部拖尾修正后，接触阶段仍有三条又长又细的橙色弧线。它们在挥爪中形状基本固定，命中后继续跟随撤回的手，像挂在爪子上的线条。参考街机录屏的攻击与命中反馈，应让挥动、接触和散开拥有清楚的先后关系。

本轮改动：

- 以短弧形网格和带柔边的光效替换三条长线，主爪亮、两侧较弱；方向从命中前实际爪端的移动取得。
- 挥动阶段光迹随手展开，命中时转为固定在撞击位置的效果，再短暂散开。格挡转为蓝白色，未防御保持暖色。
- 未防御受击的额外冲击环也使用本次受击位置，移除旧版偏离躯干的悬空圆环。
- 接触后的位移、渐隐和转色采用敌人攻击时钟，命中慢动作期间不会提前跳回撤退的手上。

改变 `MonsterAttackEffects.cs`、`GameWorld.cs` 的特效触发参数，并新增 `ClawSweep.shader`。识别、怪兽手臂动作、伤害、血量 50、充能 15、语音后 3 秒反应时间及原有声音保持不变。帧率优化继续后置。

## 复现

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ExchangeReview.After \
  --exchange-output "$PWD/artifacts/claw-impact" \
  -quit -logFile "$PWD/logs/claw-impact-after.log"
```

时序复核使用 `ExchangeReview.ClawTiming`；五英雄格挡使用 `GuardImpactReview.Render --guard-output "$PWD/artifacts/claw-impact/guards"`。重新生成 after 不覆盖 before。

本轮改善怪兽接触特效；角色表面光照、材质细节和长段连续攻防依然需要改善，尚未达到参考街机的整体表现。
