# 迪迦光弹软体积与短尾迹（A-20261012-122）

基线 `4c66497`。参考街机 60 秒画面中远程攻击形成明亮、快速的轨迹；当前发行版的普通光弹则有光滑的椭球轮廓，并以直亮线连接发射处。本轮改善这段飞行的形态，不把参考实拍中无法分辨的细节当作原机内部实现。

## 改动

- 迪迦专用 `LightBullet.shader` 在原有球形容器内做 12 步软体积积分，形成白色热芯和流动的蓝色薄层，去掉旧表面着色的椭球硬边。继续使用现有对象，不新增每发实例或贴图。
- `ProjectileWake.shader` 增加淡出的流动细丝，白热部分集中在弹头附近；尾迹上限从 2.1 缩至 1.4 世界单位，减小规则摆动。第一版的两条波浪状尾迹偏明显，复核后已调整；`first-pass/flight.png` 保留初版证据。
- 只给迪迦切换新弹头材质。切到其他英雄时恢复 `SkillEnergy`；赛罗头镖、其他角色光弹、迪迦发射准备和命中效果保持原实现。不是更换技能或新增攻击。
- 发射起点、目标、速度、命中、角色动画和姿态规则不变；时间使用已存在的射击时钟，暂停不会继续流动。

## 同输入画面和专项验证

证据根目录：`artifacts/light-bullet-20261012/`。

- `comparison.mp4`：左旧右新、5 秒、30 FPS 离线 Unity 连续渲染；`detail-comparison.mp4` 为同一段的局部放大。导出帧率不代表运行时 60 FPS 或性能改善。
