## 已修复的兼容问题

本机 MediaPipe 1.0.1 默认 CPU 路径在模型初始化时出现 `Service is unavailable` 原生崩溃。显式选择 GPU 后，三通道 SRGB 又触发像素缓冲格式错误。改为显式 Metal GPU 与四通道 SRGBA 后，真实模型测试通过；这项配置由 `vision/model.py` 同时供相机入口和测试使用。
