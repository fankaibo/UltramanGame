# 续局放手确认与开始进度

任务 A-20261018-157；基线 `1eaabb3`。按用户“把第一条快速进行迭代”的要求，聚焦任务看板第一条：迪迦整局引导与衔接。

## 问题与改动

合照后返回等待页时，识别器虽然要求先放手，但仍累积举手进度，导致进度条填满却没有开始。另外，一帧低手腕位置就能解除放手门禁，后续持续高举可能直接跳过等待页。

- 门禁期间不积累举手进度；双手在肩线附近或以下可见约 0.30 秒后解除。只需回到胸前，不必把手垂到前置摄像头以外。
- 单帧低手误差、缺失手腕、输入中断或切换追踪流不能替代持续放手。
- 等待页分步显示“先把双手放到胸前，停一下”和举手开始提示；放手阶段使用放手示意及金色确认条，举手阶段使用高举示意及青色开始条。
- 首次开局继续直接举手；战斗出拳、防御、大招门槛与合照菜单规则保持现有值。选英雄仍只用左右按键／点击，没有新增手势选英雄。
