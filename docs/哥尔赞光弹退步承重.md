# 哥尔赞光弹退步承重 · A-20261019-187

基线 `3ca1034b575ba3f0c8ace3f55fa8d545dd86f928`。对应连续远程攻防的怪兽身体表现。

## 改动

现有第三次连续光弹命中会触发退步，脚有抬起、落地与回收，但身体只向后移动，缺少横向承重。现在远程受击退步先向仍着地的腿转移重心，再向落地腿回收；末端平滑归零，继续进入原动作。

`MonsterStaggerMotion.Balance` 根据原退步时钟生成有界横向位移；`RiggedActor.PoseStaggerStep` 只在远程退步使用它。脚步目标、落地时刻、左右脚、攻击／伤害／能量、识别与输入时钟保持，近战重击退步不加入这层变化。沿用既有撤销层，避免零时间采样积累偏移。
