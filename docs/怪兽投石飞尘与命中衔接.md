# 怪兽投石飞尘与命中衔接（A-20261011-114）

基线 `eb47665`。A-113 已完成发行验证和 GitHub 同步，本轮为持续街机演出工作。对照用户录屏 `artifacts/reference-recording/frame-60s.jpg` 的连续攻击反馈，以及本机当前远程和怪兽攻击画面，投石存在两项具体差距：飞行石头缺少粉尘轨迹，屏幕边缘速度效果沿用冲撞的 0.34 秒峰值、0.78 秒结束，恰好在投石接触时消失。

## 实现

- `BoulderDust` 固定 18 个烟尘面片：12 个飞行脱落点、6 个接触散尘点。使用项目已有 `ImpactCloud` 着色器和共享材质／属性块，无需新下载资源。
- 发射点按攻击时钟每 0.045 秒采样，一旦脱离石头就留在世界位置，随后扩散、下落、淡出；相机与目标移动不会拖着旧粉尘走。
- 撞盾和未防御受击都使用真实命中位置，散尘延续到怪兽收招；暂停、重开、展示或离开战斗清除。恢复时不重播已经发生的碎裂爆尘。
- 投石专属屏幕边缘速度峰值移到 `MonsterRockMotion.Contact`（0.78 秒），其他攻击的现有节奏保留。
- 不改变识别、预警时长、防御窗口、伤害、石头运动或角色骨骼轨迹。英雄仍只能方向键／点击选择，举手只负责开始与续局。

## 验收

`MonsterRockDustReview.Before/After`：15／30／60 Hz，格挡和未防御两类完整投石；60 Hz 保存连续画面，生成 30 fps 前后对照。逐行比较游戏状态、石头位置和双方手位，检查飞行／碎裂／收招散尘及最终清空。另核对镜头峰值与实际投石接触帧。

`MonsterRockDustReview.Lifecycle`：固定池、重复同时间采样、相机移动不拖动世界烟尘、过期、暂停后不重播旧爆尘。`FlowStops` 检查真实 GameWorld 暂停、展示、重置与新回合。
