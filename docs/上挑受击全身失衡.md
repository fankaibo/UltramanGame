## 复现

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.UppercutReview.Validate \
  --uppercut-output "$PWD/artifacts/uppercut-body/after" \
  -quit -logFile "$PWD/logs/uppercut-body-after.log"
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ClawPoseReview.Stability \
  --claw-output "$PWD/artifacts/uppercut-body/stability" \
  -quit -logFile "$PWD/logs/uppercut-body-stability.log"
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --output artifacts/uppercut-body/guided --log logs/uppercut-body-guided.log
.venv/bin/python scripts/encode_uppercut_body_review.py
```

其中 `Unity` 需替换为本机对应编辑器的可执行路径。基准画面必须在运行时代码仍为上述基准提交时采样到 `before` 目录，不能用新版代码伪造旧版对照。

整体与最终参考街机仍有差距，尤其是源模型细节、更多攻击动作与场景丰富度；本轮只证明全身受击动画及其连续流程得到改善。
