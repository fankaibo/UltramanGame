# 自然前伸的待战手位

改动 A-20261009-65，2026-10-09。实现 `e4127f7`，收拳衔接修复 `f52022f`，旧版对照 `f409d31`。

## 用户反馈与修复

用户截图中迪迦双手贴近肩前、肘部折叠过紧。原因是普通待战、收拳、远程和腕剑收招的目标位置使用固定的近身偏移。

现在按各模型上臂、前臂的实际长度计算待战位置：双手向前舒展并略微下沉，左手稍靠前，肘部保留弯曲。攻击接触阶段副手回护，收招后恢复舒展。该调整覆盖现有五位骨骼英雄；真正的护盾姿势、必杀、动作识别与命中时钟保持原有规则。

连续段检查还发现，旧的收拳过渡在进入 Idle 的第一帧把手臂 IK 权重降到零，短暂露出原动画的紧缩姿势。新的收拳终点与待战位置统一，并在进入 Idle 时继续使用该位置，消除这一帧回跳。

## 发现及验证更正

初轮把腕部父节点误作肘关节，该节点实际是扭转辅助骨。改为真实 `ForearmBase_L/R` 后重新生成旧、新完整对照；无效旧指标保留于 `before-wrist-metrics.txt`，未作为最终证据。

旧接触检查在旧代码上也失败：它把连击中的踢腿当作拳头接触，还把梦比优斯腕剑攻击当作手腕接触。现在分别检查九次拳头接触和实际剑尖；副手回护检查限定在接触阶段，收招允许恢复前伸。连续性同时记录世界坐标与角色局部坐标，区分整体追击脚步和手臂跳动，仍保留原世界位移上限。没有降低接触距离要求。第一次修正检查后发现的 Idle 手位回跳通过运行时修复解决，失败日志保留在 `logs/ready-arms-*.log`。
