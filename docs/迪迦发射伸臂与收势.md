# 迪迦发射伸臂与收势（A-20261011-103）

基线 `2a42c23`。用户要求手自然伸出去、动作连贯；最新光弹画面里，迪迦发射时前臂仍弯在身前。这次测量真实模型骨骼与连续动作，调整迪迦发射姿势，不改姿态识别、命中和声音时序，也不改变其他英雄的动作参数。

## 原因与实现

旧目标使用固定 0.88 世界单位，但迪迦肩到手腕的实际骨骼链长约 1.08。在发射阶段，肘角只有约 109°，伸展比例约 82%；光弹飞行中又从动作时钟 0.20 秒开始收手。

- 迪迦发射目标按实际两段臂长的 97% 计算，并保留原侧向／高度偏移。实际伸展比例约 97.2%，肘角约 153°，不拉长骨骼或锁死关节。
- 从当前可见手位轻微后收 0.14、下沉 0.08，再向前发射；原来快速收回肋部、再快速伸出的多余折返移除。
- 收势起点由动作时钟 0.20 延后至 0.26 秒，仍在原 0.42 秒结束。攻速仍由真实输入映射，防御随原规则接管，不增加孩子等待时间。

## 失败与检查修正

1. 第一轮旧检查把整个动作恢复阶段的非攻击手前伸也限制在 0.55；当前自然待战姿势本就前伸约 0.865（原版基线也有），因此误报“双手出击”。改为在真正发射段 0.10–0.21 秒检查非攻击手，仍用原 0.55 上限；全阶段最大值继续记录，不隐藏数据。原失败保存在 `initial-check` 和 `logs/a103-after.log`。
2. 只延长伸臂、保留旧深蓄力的版本，在快速出手时最大单帧位移 0.6531，超过原 0.65 门槛，未交付。随后改成从当前手位浅蓄力，最终降至 0.4273。失败数据和关键帧保存在 `extended-deep-windup`、`logs/a103-after-final.log`。
