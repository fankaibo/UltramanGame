# 迪迦普通光弹发射声音 · A-20261019-186

基线 `06cb19385a1311d3346dde7db6c0f941a0cdb50f`。对应迪迦连续战斗中的声音配合，不代表整体街机效果验收完成。

## 改动与范围

原发射声是一段 22.05 kHz、220ms 的单一降调振荡音，主要能量出现在离手后。本轮为迪迦增加原创非人声合成：短促压力／放电、较弱谐振核心、空气尾声与短反射；三个 44.1 kHz、280ms 的轻微变体轮换。没有使用或声称影视原声。

`CombatImpactSounds.CreateProjectileLaunch` 在启动时生成一次；`GameAudio.ProjectileLaunch` 使用缓存片段与原固定音源池。三个片段约占 145 KiB 浮点 PCM，不在每次发射时分配音效。原攻速到 0.90–1.12 音高的映射、发射事件、命中事件、屏幕声像和语音压低音效规则保持；其他英雄继续使用原声音。《奇迹再现》、迪迦战吼、已有命中声、识别与战斗逻辑未改。

## 实际混音与对照

在改动运行时代码前录制基线，再用同一 `AudioMixReview.Run --audio-projectiles --audio-version before|after --audio-output <目录>` 录制候选。不要加 `-quit`，工具完成后自行退出。两次均为 Unity AudioListener 实际立体声输出，不含麦克风；本专项关闭音乐，以便观察发射与命中。

`artifacts/a186-projectile-audio/` 保存：

- `before/after/mix.wav`：约 10 秒混音，含慢速、常速、快速连发、引导语音和大招接触参考。
- `before/after/audition.wav`：同一混音的 PCM16 试听版本。
- `waveform-comparison.png`：发射源包络和整段实际混音的可视化对照。
- `sources.txt`、`events.csv`、`comparison.json`：四个运行时代码哈希与基线 Git 内容核对，六次发射及六次命中的事件帧前后一致。

10ms RMS 窗口峰值：旧源约 66.4ms，新源三变体约 5.7–7.4ms。前 20ms 能量占比约从 2.3% 变为 64.6–64.8%；这是更早且短促的声音起音，不代表识别延迟变化。新版单个片段整体 RMS 低于旧源，避免把“更大声”当成改善。混音峰值前后均约 0.339，无削波；新片段首尾归零。三变体、40 次连续调用的固定池、音高映射、暂停、静音和其他英雄保留旧音频通过。

复核命令：`.venv/bin/python scripts/review_projectile_launch_audio.py --folder artifacts/a186-projectile-audio --baseline 06cb19385a1311d3346dde7db6c0f941a0cdb50f`。该工具核验资产、事件、数值与导出；波形不能证明影视真实感或电视音箱的听感，不冒充人工试听结论。
