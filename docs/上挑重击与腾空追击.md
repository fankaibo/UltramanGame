# 上挑重击与腾空追击（2026-09-28）

参考根目录街机录屏及 `artifacts/reference-video/punch-sequence.jpg`，重击不仅使怪兽后仰，还会产生明显离地、回落和碎石烟尘。本轮在现有五拳勾拳、撤步的基础上，增加第十拳的上挑变化，让一次普通连击有不同的动作段落。

每十次普攻使用上挑手部轨迹和身体转动。满足演出时机时，格尔赞短暂腾空：骨盆最高上升 0.72 个场景单位，两腿不对称收起，尾巴随身体离地。约 0.66 秒后落地、屈膝吸收冲击，随后左右脚分两步回到站位，整段约 1.36 秒。落地点触发一次地面碎石、烟尘、短促镜头震动和现有重落地音效。

镜头在上挑命中前开始准备构图，为怪兽腾空预留上方空间，再随落地恢复。五拳的勾拳／撤步仍保留，十拳改用腾空；怪兽正在攻击或即将结束蓄力时不插入腾空，以保留防御提示和挥爪动作。没有增加动作识别姿势，也没有改变每拳伤害、十五拳蓄满能量或战斗时钟。

## 腾空中的连续出拳

开发过程中，快速追击曾出现规则命中但拳头停在怪兽身体外的问题。现在怪兽尚未落地时，下一拳会带一个短促的追击步，后脚跟进，并追踪怪兽下胸部。腿部仍按实际骨长求解，不通过延长手臂或延迟输入完成接触。追击步幅在该拳开始时固定，避免怪兽中途落地导致拳路突变。

五位英雄、左右手的腾空追击都已验证。采样条件下，拳头接触点到怪兽蒙皮表面的最近距离约 0.124–0.252 个场景单位；现有命中特效覆盖这段距离。追击的英雄网格最低点约为 -0.0056 至 -0.0006，处于地面容差内。它们是游戏模型与采样指标，不是人体动作精度测量。

视频为离线 30 FPS 采样，不代表当前游戏实际运行帧率。页面同时展示真实 macOS 游戏 HUD 下的腾空、落地、恢复与地面扬尘截图，并记录源码及构建摘要。

`UppercutReview.Release` 验证通过：

- 40 组腾空流程：五英雄左右上挑、左右快速追击；迪迦额外覆盖 15、30、60 Hz，以及暂停、新局、必杀接管和临近怪兽攻击的防御。
- 普通上挑中，格尔赞实际蒙皮不进入顶部血量面板，模型没有穿地，落地保持段双脚位置稳定。落地特效每次恰好触发一次。
- 快速追击在怪兽尚未落地时命中，腾空不会因下一拳而瞬间取消；暂停、新局及必杀接管不会留下延迟落地事件。
- 7 组普通／组合拳接触检查、10 组护盾及暂停打断、7 组撤步及落地检查通过。
- 零时间重复采样中，根节点与脚的位置误差不超过 0.001，腾空手部沿用模型已有的 0.015 容差。

项目 `scripts/check.sh` 通过：33 项 Python 测试、300 项核心检查，以及含 Python/C# 本地通信的 303 项集成检查。

复现：

1. 基准版本执行 `ComboStrikeReview.Before --combo-output <仓库>/artifacts/uppercut`。
2. 当前版本执行 `UppercutReview.Release --combo-output <仓库>/artifacts/uppercut`。
3. `bash scripts/check.sh`、`bash scripts/build_macos.sh`。
4. 执行 `scripts/cinematic_player_check.py --hero Tiga`。
5. 执行 `scripts/guided_player_check.py --output artifacts/uppercut/guided --log logs/uppercut-guided.log`，将运行前后的程序、资源摘要保存为同目录的 `build.json`。
6. 执行 `scripts/encode_uppercut_review.py --player <本轮实战证据目录> --guided artifacts/uppercut/guided`。

本轮新增连击动作变化，尚不能视为达到最终参考街机效果。角色细节、攻击种类与场景丰富度仍需提升；回到普通战斗镜头后，底部引导与英雄脚部的间距也需继续优化。帧率专项仍后置。
