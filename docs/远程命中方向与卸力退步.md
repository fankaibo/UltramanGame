# 远程命中方向与卸力退步

A-20261010-71；代码 `6b07151`，对照 `5674caf`。

## 问题与行为

复看参考录屏和 A-70 连发回放，远程攻击的主体镜头已经保持，但哥尔赞在连续光弹中一直站在原地。代码还以英雄“当前动作”决定怪兽受击方向：光弹离手后孩子可以立即防御，命中时 `Action=None`，左右信息因此丢失。

`Battle` 现在保存真正施加伤害的动作、是否远程和递增命中序号。它只记录原有伤害事件，不生成攻击，也不改变时钟、伤害、能量或识别。动作层按该回执选择胸部扭转和左右爪反应。声音、受光和受击类型也按招式身份判断，不再把“同一帧掉了多少血”当作必杀：两次普通攻击同帧结算不会冒充大招，必杀打掉最后 1 点血仍保留必杀表现。

连续三次远程命中后，哥尔赞使用已校准的卸力步：被击中一侧的脚抬起向后踏，另一脚支撑，落脚扬尘，随后回到原站位。两次命中间隔超过 2 秒重新累计；正在卸力、腾空或承受光线时不重启动作。敌人最后 1.1 秒预警、攻击、必杀、展示、新局及暂停具有原来的优先级。左右方向以实际发出的拳为准，不受孩子后续防御影响。
