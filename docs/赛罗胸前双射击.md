# 赛罗胸前双射击

改动 A-20261009-60；运行时代码 `b448ed4`，对照基线 `cc58041`，2026-10-09。整体进度见 [开发任务看板](开发任务看板.md)。

## 招式依据与原问题

圆谷[赛罗角色页](https://tsuburaya-prod.com/heroes/ultraman-zero)将 Zero Twin Shoot 列为必杀。圆谷[官方合作模型介绍](https://tsuburaya-prod.com/news/2989)进一步说明，双头镖从头部拆下、装到胸前，形成双射击姿势。该资料用于动作与武器位置参考，没有把网站图片导入或分发到游戏。

之前招式名称已经正确，但角色仍采样通用 L 形光线片段，从右前臂发射；头镖一直留在头顶。因此，仅换名字和颜色没有让赛罗真正使用对应招式。

## 当前改动

`ZeroTwinShoot` 以原模型胸口计时器的 184 个网格顶点标定发射点，跟随胸骨运动。角色先抬起双手，再将两枚原模型头镖沿弧线移动到胸前计时器两侧，双手随行，胸前聚能并发射；结束后将头镖放回头部、双手回到准备姿势。保留头镖原网格、大小和贴图，没有额外复制一套留在头上。

专属姿势叠加层在下一帧采样前还原，避免手臂累计变形；普通远程投镖和必杀共享原武器，但由战斗状态决定当前使用者。大招后立刻防御或攻击时，输入优先；重新开局、换英雄和取消清理旧姿势。终结光线被暂停时保留其可见姿势，恢复后完成释放与归位。

孩子仍使用已熟悉的必杀手势。识别、语音、15 拳蓄能、9 点伤害、命中时机及无键鼠流程均未改动。赛罗影视原声依旧缺失，没有用别人的声音冒充。

## 专项验证

- 15/30/60 Hz 的完整实模必杀均为一次发射、一次 9 点命中；与旧版对照的 300 帧玩法状态完全相同。
- 胸前头镖定位误差约 0.000001，光线起点与胸口发射点误差为 0；发射点距实际计时器网格中心保持 0.07000 个场景单位。
- 手臂长度误差约 0.000001，实际蒙皮最低高度 0.00200；重复零时间采样无漂移。15/30/60 Hz 的最大单帧右手位移分别 0.3333／0.1977／0.1025；这些是更新步长检查，不是实机性能结果。
- 27 组生命周期覆盖取镖／胸前／发射中暂停、新局、防御接管、普通远程头镖接管、换英雄、胜利归位及终结技暂停恢复。
- 通用光线回归覆盖五位现有英雄、迪迦三种步长及三个取消时机：发射、命中、怪兽后仰跟随、镜头构图、暂停和新局通过。41 Python + 916 规则／姿态／通信检查通过。

日志保留 `logs/zero-twin-before.log`、`zero-twin-after.log`、`zero-twin-after-render.log`、`zero-twin-final.log`、`zero-twin-verified.log`、`zero-twin-beam-regression.log` 和 `zero-twin-checks.log`。首次编译因角色 ID 变量名错误失败，修正后重新编译、渲染和验证；不把失败日志算作通过。
