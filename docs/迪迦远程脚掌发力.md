# 迪迦远程出招脚掌发力（A-20261011-112）

基线 `21eabae`。上一轮已提交并完成 CI，属于 Progress。本轮复看本机街机录像 60／120 秒代表帧，并对照 A-111 实机；目标是减少当前远程动作只有上半身运动的割裂感。录像没有提供可精确测量的脚底轨迹，本轮脚掌设计是本项目实现，不声称复原街机内部动画。

## 实现与修复过程

- 为迪迦同侧出招脚加入最大 18° 的后跟抬起，发射前逐步发力、收手时回落。另一只脚保留既有支撑，使用已按玩家速度缩放的动作时钟，不重复加速。
- `FootContactRoll` 从真实模型的鞋面蒙皮权重提取局部鞋底和前端支点，一次缓存。每帧绕支点旋转并重新解膝部，避免直接绕脚踝旋转而把鞋尖插入地面；骨盆和手部不因这层动作改变。
- 新检查发现第一版在左侧慢速出招接防御时脚位单帧跳变 0.200445，未放宽 0.20 门槛。复测无脚跟改动基线最大约 0.1393；根因是原远程防御只接续手臂。迪迦改用完整可见姿态交接，60 Hz 最大防御脚位变化降至 0.0308，手位变化降至 0.1582。其他英雄保留原交接逻辑。
- 不改姿态识别、招式命名、伤害、蓄能、预警时间或自动合照流程。英雄选择仍仅方向键／点击，双手举高开始，合照后先放手再举手。
