# 哥尔赞待战弯肘与手位

增量 A-20261018-154；基线 `65a8384`；日期 2026-10-18。

## 问题与实现

参考视频的怪兽在连续攻击间仍有明确的准备姿势。当前近景中哥尔赞待机／收回时双手下垂、肘部外张。原 `SolveArm` 分别把上臂朝向肘目标、前臂朝向腕目标；旋转后没有统一保证最终手位，导致外观偏平、手掌悬垂。

现使用双骨段求解：先在原手位和目标之间插值，再按实际骨长计算可达手位与肘部弯曲平面；手掌随前臂方向转动，原有手腕角度限制继续保留。待战手位稍提高并收近，肘部低于手掌，两手保持不同前伸距离和呼吸节奏。

修改限于哥尔赞已有待机／预警／恢复修正，不改变五种攻击类型、伤害时机、体感识别、语音反应时间或合照流程。第一候选虽然五攻击检查通过，但两臂过直、仍有垂手感；已调整目标，保留候选近景与源码哈希，未交付第一候选。
