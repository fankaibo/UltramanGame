# 连续拳预备衔接（A-20261015-141）

日期：2026-10-15。主线：迪迦与哥尔赞的第一条连续战斗演出迭代。

## 改动

普通左右拳现在允许在当前拳的可见收拳阶段提前登记下一拳。`Battle.PunchQueueLeadSeconds` 设为 `0.24s`，`HeroPunchLink` 使用同一个常量让肩膀、手臂和拳面提前进入下一次衔接。下一拳仍在当前攻击完成后才真正开始；命中、伤害、识别和必杀蓄能时钟没有提前。

这样连续左右拳不会在一拳完全回到待机后停住，视觉上能从收拳自然接到下一拳。远程光弹、护盾、大招和输入门槛没有改动。
