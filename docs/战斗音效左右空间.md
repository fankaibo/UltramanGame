# 战斗音效左右空间（A-20261012-120）

基线 `cbf823e`。当前英雄在画面左侧、怪兽在右侧时，发射与接触音效原先都从正中播放，无法通过声音区分出手与命中的位置。本轮补齐画面和音效的左右对应，不替换音乐、语音或角色原声素材。

## 实现

- 以战斗摄像机的视口横坐标计算声像，限制在 −0.45 到 +0.45。发射使用实际光弹起点，命中使用怪兽胸前的受击目标点；近战、格挡和怪兽出击使用对应一方的位置。镜头转到另一边时，下一个声音会跟随画面；镜头背后或无有效摄像机回到居中。
- 每个声音开始时记住自己的声像，已播放的尾声不因下一拳或下一镜头左右跳动。复用原有 10 个战斗音效声源和 4 个碎石声源。
- 命中音效在同一 Update 的世界／镜头更新后播放，使用最终画面位置；命中判定、伤害、动作识别、语音反应时间和攻击时钟不变。
- 背景音乐、《奇迹再现》、语音引导、迪迦战吼保持原声道设置；不会将语音随角色偏向一侧。此功能是有界左右声像，不是环绕声或 HRTF。

## 实际 DSP 对照

`AudioMixReview.Run --audio-spatial --audio-version before/after` 记录 Unity AudioListener 的 48 kHz 双声道最终混音，不使用麦克风。before 是同素材／同事件时间、未调用 SetStage 的居中对照，**不是另行运行旧版发行包的录音**。音乐在该隔离测试中关闭，便于测量效果；没有改变游戏的音乐设置。

`artifacts/combat-stereo-20261012/validation.json` 与 `scripts/review_combat_stereo.py`：

- 两份事件表相同，录音各 8 秒；基线所有事件左右能量比 1.0。
- 新版左发射／左命中的左右能量比约 1.750，右发射／右命中约 0.571，居中探针仍为 1.0。
- 峰值从 0.143 到 0.162，无削波；合成单声道后的事件 RMS 约降低 0.95%，不会因左右分配丢失主体声音。
- 摄像机两侧、镜像构图、背后／空摄像机回退、最大偏移、重叠尾声保持、音乐／语音居中、40 次效果的固定池和暂停清理通过。
- 原有音频回归确认独立音调、有限并发、优先级抢占、单声源音量、静音与暂停清理通过。源码和原始音频保存在 before／after／regression 下。

这只证明本机混音和调用规则，不能替代小米电视扬声器的实际听感。整体街机效果、真实相机长期稳定性和其他英雄原声仍待完成，总进度不变。

## 构建与整局验证

- `logs/a120-check.log`：49 项 Python、2044 项核心／桥接检查通过；Release 构建和签名通过（`logs/a120-unity-build.log`）。
- 真实发行包五类怪兽攻击回放 170.59 秒通过：32 普攻、2 必杀、4 格挡、1 受击、暂停恢复与胜利；原生战斗图仍保留 A-119 碎光效果。34 次命中声音的运行时声像范围 0.098–0.160，均对应画面右侧目标，无重复音效事件。原始证据 `artifacts/cinematic-combat/player/20261011T203758214604Z/`，统计 `melee-source-validation.json`。
- 该运行的两个 FPS 窗口 50.6／51.9，包含截图开销且未控制宿主负载；本轮不是帧率专项，不据此宣称达到 60 FPS。

- 完整合成体感回放 191.0 秒通过：32 次发射／命中、2 次必杀、5 次防御、两张自动合照、重拍及同英雄续局；0 键鼠、0 手势换英雄、持姿噪声误攻击 0。重拍 4.86 秒、续局 4.94 秒均在语音期间接受；预览／保存 P99 差 0。`guided/guided-validation.json` 保存全部数据。
- 实际远程发射声像 32 次均为负（−0.177 至 −0.090），34 次命中含两次必杀均为正（0.144 至 0.161），与当前镜头左右站位一致；`ranged-source-validation.json`。原资源文件摘要与 A-119 相同，未更换音乐／声音素材。
- **保留异常**：第二次大招前出现 648.9 ms 渲染帧与追踪暂停，恢复后收到 `beam_reset`，测试玩家按现有指引放手两秒再完成大招；没有改识别阈值或绕过门禁。本轮不将通过流程解释为长期稳定，也未证明该长帧的根因。
- 默认包已替换为同一通过验证的 A-120，160 文件／权限相同并复核签名，`promotion.json` 留存旧／新摘要。程序集 `64c5e983dfd5bb567878b87ac0bf38a2d26925f6aea7281fb820dcf5d69eb12b`；resources `93f2f4b004c26582cc9879a628c9daf9a6ea15de15cbadceffe668d646bfb11b`。
