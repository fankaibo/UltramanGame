# 迪迦光弹连续尾焰（A-20261011-102）

基线 `657b416`。再次对照用户街机录屏 60 秒画面与当前发行包 `artifacts/photo-target-20261011/guided/native/light-bullet-right.png`：远程能量飞行需要在角色之间清楚可见，原光弹主要呈现小球、轮廓环和细折线。此轮只改迪迦普通光弹展示，不改动作识别、出手速度、命中时钟、伤害或其他英雄技能。

## 最终实现与视觉复查

- 弹头由 0.25×0.25×0.65 调整为 0.36×0.36×0.95 的发光体，保留原深度遮挡及命中淡出。
- 迪迦飞行轮廓环移除；柔和弹头光晕与最长 2.1 世界单位的连续尾焰相接。尾焰长度随已经飞过的距离增长，沿初始发射方向向后展开，不修改光弹落点。
- 新 `ProjectileWake` 使用明亮中心、低亮度外缘、尾端渐隐和随原光弹时钟变化的轻微能量纹理。等宽、双控制点条带负责几何，宽度变化在着色器中完成。暂停／新局／换角沿用已有清理路径；其他英雄恢复原 shader、顶点数和宽度曲线。

实际失败留证：首版多节收窄条带出现明显折线；改成双控制点后仍有斜向接缝。读取实际网格与 UV 发现，几何宽度变化使三角形内部插值的 UV 中心偏移。最终改为等宽几何并在 UV 内收窄，实际第 36 帧接缝消失。两个失败版本分别保留 `attempt1/60/0018.jpg`、`attempt2/60/0018.jpg`，诊断数据位于 `mesh-check/60/wake-mesh.txt`。

4 秒实际 Unity 前后对照：`artifacts/tiga-projectile-20261011/before-after.mp4`，左侧修改前、右侧修改后，三次快速连发。同相位关键帧 `before/60/0018.jpg`、`after/60/0018.jpg`；这段是固定时钟编辑器渲染，不是实际摄像头录制或性能测试。
