# 哥尔赞左右挥爪复查（A-20261011-93）

本轮针对挥爪时非出击侧手臂抬肘、贴胸的紧缩姿态。保持出击爪的轨迹和命中时机，让另一侧手掌略向前、向外、向下，肘部自然下沉。未修改姿态识别、伤害、音乐或合照规则。

## 原检查的覆盖缺口

旧 `ClawPoseReview` 只执行前两次攻击；目前第二次已是投石，不能证明第五次左爪动作正常。现在支持 `--claw-attacks 5`，实际执行右爪、投石、砸地、头部光线、左爪，再逐侧检查肩肘腕与恢复。实际播放器和完整战斗渲染另加 `--review-claw-cycle`；普通游戏不启用此回放选项。

## 对照结果
