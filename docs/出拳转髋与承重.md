# 出拳转髋与承重（2026-09-30）

参考街机录屏中的连续挥拳，当前版本增加髋部带动上身、屈膝承重和下一拳的髋部预备。普通拳髋部先于接触转动，重心随后降低；已经有较大转肩的勾拳使用较小幅度。双脚继续使用原动画／已有踏步求解的落点和脚掌朝向，避免整个身体转动时脚底跟着滑走。头部部分反向补偿，保持面向对手。

最初的转髋幅度过大，15 Hz 连击检查捕捉到手部位移超限，画面中的膝盖方向也不自然。最终收小幅度，并沿原动画的膝盖方向承重。姿势修正在下一次采样前恢复，不把前一帧的转髋叠加到下一帧。

普通拳复查还发现，原先从每帧移动中的肩膀护手位置插值到目标，会叠加身体前冲速度。现在从上一帧实际看见的出拳手位置出发，用短的加速／减速段和较均匀的中段速度到达目标；收手仍回到胸前。出拳时长 0.38 秒、命中时间 0.12 秒、伤害、能量和动作识别规则均未改变。

## 复现

基线使用当前采样器（新增了输出目录与身体坐标记录），仅将 `RiggedActor.cs` 暂时替换为上述提交中的版本；其余战斗规则与角色资源相同。先保存当前文件，再运行 `PunchLinkReview.Before --punch-link-output <目录>` 和 `RosterPunchReview.Before --roster-output <目录>/contact` 保存基线，最后恢复当前文件。不要用当前角色代码覆盖 Before 证据。恢复后运行：

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.RosterPunchReview.After \
  --roster-output "$PWD/artifacts/punch-weight/contact" -quit
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.PunchLinkReview.Release \
  --punch-link-output "$PWD/artifacts/punch-weight" \
  --combo-output "$PWD/artifacts/punch-weight/support" -quit
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --gesture-entry-noise --gesture-shape-noise \
  --output artifacts/punch-weight/guided --log logs/punch-weight-guided.log
.venv/bin/python scripts/encode_punch_weight_review.py
```

`artifacts/punch-weight/index.html` 提供同步视频、同位置左右拳切换、五位英雄衔接图及当前程序截图。编码脚本核对源码、输入状态、双脚位置、普通拳检查和实际程序摘要。视频是离线 30 FPS 导出，不代表游戏运行帧率。
