# 战斗音色与语音优先混音（2026-09-30）

本轮针对街机战斗中普通出拳、连击重击、必杀声音层次接近，以及战斗声音容易盖住儿童引导的问题。保持已确认的中文青年英雄语音、迪迦原声战吼和用户导入的背景音乐。

## 实现

普通命中改为接触脆响、低频撞击、短促表面碎响和轻微反射的组合，启动时生成三个确定性变体。每五拳的重击使用更低的撞击与更长的尾音；必杀接触使用独立的轰鸣层。声音仍在原伤害节点触发，挥拳、命中、光线发射和落地没有合并为一个提前播放的长音频。

原来十余类瞬态音效共用一个 AudioSource，每次出拳调整它的 pitch，可能一起改变尚未结束的声音。现在每条播放通道只拥有一个片段，普通音效最多 10 路、地面碎石最多 4 路；容量已满时优先替换旧的低优先级声音，低优先级声音不能挤掉必杀尾音。通道只在启动时创建。

语音开始的同一帧，碰撞与挥拳音效降到原来的 42%，碎石降到 32%；语音结束后平滑恢复。原有音乐、蓄力和怪兽光线的避让继续保留。暂停、重置和静音会停止已占用的瞬态通道；关闭音效期间不会新增碰撞声。运行时合成片段随所属对象释放。

## 录音证据

对照基准为 `4b1328f` 的 `GameAudio.cs`。`AudioMixReview` 在 Unity 播放模式中执行相同的 15 秒控制序列，使用 AudioListener 上的 `OnAudioFilterRead` 获取最终立体声输出，没有录制麦克风。最初尝试的 AudioRenderer 在本机返回空样本，所以没有把它的执行结果当作有效录音。

对照入口：`artifacts/combat-audio/index.html`，有普攻／重击、语音与必杀三组试听。原始录音为 48 kHz 立体声浮点 WAV，试听版转成 PCM16，没有自动拉高两组音量。该序列用于比较声音本身，不能替代完整游戏验证。

- 修改前，已有的 600 Hz 测试音被后续挥拳改成约 576.05 Hz；当前保持 600.04 Hz。
- 语音出现后，旧版测试音变化约 +0.22 dB，当前下降约 7.02 dB。测量包含真实语音，因此与理论值略有差异。
- 两份完整录音的峰值均为 0.5304 以下，没有削波；这只能证明该测试序列，不能声称所有可能的播放组合都已验证。
- 独立检查覆盖不同音高的叠加、通道饱和、重要音效保护、各片段音量、停止、静音及暂停。

`scripts/review_combat_audio.py` 复算频谱并绑定当前声音源代码摘要。`scripts/cinematic_player_check.py` 另行检查实际构建中的 26 次普通命中、6 次重击及两次必杀音效，与完整战斗的 32 次普攻、两次必杀对应。

最终构建及本地签名通过；36 项 Python、373 项核心和包含跨进程通信的 376 项集成检查通过。实际打包版在 96.6 秒内完成整局：32 次普攻、两次必杀、三次防御、一次受击倒地、暂停恢复和胜利。26／6／2 个命中音效节点与预期完全对应，原声战吼播放两次；当前程序截图包含左右出拳、连击、怪兽砸地／光线、必杀及退场。

随后使用同一构建完成 143.6 秒无键鼠回放：自动合照两次、重拍、照片流和姿势流中断恢复、举手进入下一局全部通过。146 帧防御噪声及 16 帧大招噪声期间误触普攻为 0。照片与姿势均为合成 TEST 数据，没有调用真人照片 AI；当前录音、源码和两类实机回放的构建摘要统一记录于 `artifacts/combat-audio/validation.json`。

## 复现与范围

```sh
Unity -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.AudioMixReview.Run --audio-version after \
  -logFile "$PWD/logs/combat-audio-after.log"
.venv/bin/python scripts/review_combat_audio.py
bash scripts/check.sh
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
```

`AudioMixReview` 会进入播放模式并自行退出；不要加 `-quit`。基线录音和对应源码保留在忽略的 artifacts 目录，重新生成基线必须使用记录的旧版本，不能仅把新版本输出命名为 before。

声音优先级没有更改姿势阈值、怪兽血量、15 拳蓄能或听完指令后的反应时间。图像融合、角色模型精细度以及更接近参考视频的连续演出仍未最终验收；本轮声音升级不能代表整个街机目标已经完成。
