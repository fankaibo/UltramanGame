# 远近战与英雄武器

需求：A-20261008-51；代码提交 `61c5f0d`。让角色拉开距离，以近战、投石和英雄武器形成变化，沿用已有的前挥、侧挥、防御输入。

## 本轮玩法

- 保留斜向 45° 站位，双方默认距离由约 2.70 增至 4.10 Unity 单位，增加约 52%。普通镜头略放宽，角色仍是画面主体。
- 向前挥拳为远程出招；侧向挥拳会冲近，再收招回到原位。左右手和上一轮的 0.65–1.70 倍攻速继续生效。
- 赛罗的普通远程攻击改为双头镖：从头部附近飞向怪兽，再旋转返回；每次仍只扣一次血，不因返程追加伤害。
- 梦比优斯左手普通近战增加梦比姆光剑，从左腕伸出并挥斩。向前挥拳仍是远程光弹；原有第五击踢击等连招保留。键盘模式 `A` 左手近战、`Q/E` 左右远程。
- 怪兽每六次攻击轮换：右爪近战、投石、砸地冲击、额头光线、左爪近战、砸地冲击。投石会提前举石示警，再抛出带弧线和旋转的岩石。每轮的两次爪击分别使用左右手。
- 石头在攻击开始后 0.22 秒离手、0.78 秒到达防线。护盾挡住后碎裂；未防御则进入已有受击倒地流程。暂停、断流、必杀打断或新局会清理在途投石。
- 普攻／光剑／头镖仍各算一次普通命中、增加一点能量；默认 50 次普攻血量、15 次攒满必杀的规则保持一致。

怪兽投石使用场景中已有的扫描岩石网格和贴图，提前创建一块石头和七块碎片并复用。没有新增联网依赖或录像上传。

## 名称与素材边界

万代官方将赛罗头部的两把回旋镖称为「ゼロスラッガー」，本轮对应赛罗头镖。[官方资料](https://toy.bandai.co.jp/ja/series/ultraman/item/01_4785/)

梦比姆光剑「メビュームブレード」是由梦比优斯手镯伸出的光刃，本轮为梦比优斯增加左腕光剑表现。[官方资料](https://toy.bandai.co.jp/ja/topics/01_19804/)

本轮武器是游戏内程序几何与特效，尚非影视级精细道具；现有赛罗模型上的头镖没有单独拆卸动画。没有新增角色影视原声音频，也没有把武器套用给其他英雄。
