# 普通光弹飞行照明（A-20261019-175）

基线 `df2bdc6`。复看本机参考录屏及 A-174 实机画面后，继续补齐远程技能与角色表面的联系：此前已有手边离手亮光和命中亮光，飞行期间的光弹只有自身发光，没有随弹头移动的局部照明。

## 改动

- 迪迦普通光弹增加一个常驻复用的点光源，跟随原有 `Tip` 位置，用同一 `Shot.Age` 渐入、渐出；飞过手腕和接近怪兽时，蓝白光照到原有角色材质上。
- 实际命中后立即交给已有接触照明，不在怪兽身体内留下第二个常亮光源。收手后飞行仍按原有规则继续。
- 光源仅在迪迦有效飞行段启用，范围 2.6，峰值强度 2，不投射额外阴影；暂停、新局、换英雄和隐藏飞行都关闭。每发不创建对象。
- 识别、左右手、体感攻速、飞行轨迹、伤害和能量规则不改；其他英雄维持现有照明。
