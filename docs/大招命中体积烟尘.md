# 大招命中体积烟尘（2026-09-29）

光线命中原先由橙色烟片、光圈和射线叠加组成，烟片遮住光线且缺少空间厚度。本轮在实际大招伤害发生时产生一次蓝白冲击烟团，并在怪兽脚边扬起短暂的低矮灰尘。

## 实现

`BeamImpactVolume` 使用两个可复用的体积网格和一份缓存的三维密度噪声。烟团在接触表面外侧扩张、上升和消散；地面烟尘以不规则环形向外滚动。着色器沿视线采样密度，由场景深度截断，所以前景角色和岩石会遮挡烟尘。蓝白高亮只保留在最初的冲击核心。

体积效果由 `GameWorld.Hit(true, ...)` 触发，通用胜利闪光不会再触发一次。特效仅使用显式演出时钟，约 1.85 秒结束；等待、暂停和重开清理实例。普通出拳、伤害、能量和手势保持规则没有改变。实际大招命中不再叠加旧的橙色烟片与大光圈，保留短闪光、碎屑和少量射线。

启动预热会渲染胸前烟团与地面烟尘，避免首次大招才编译其材质。

## 验证

- `BeamImpactReview.After` 生成 6 秒连续对照，360 个模拟状态与 `d35aa40` 基线一致：15 次预充能普攻、一次大招命中、怪兽剩余 56 点血量、能量归零。
- 效果出现 111 个 60 Hz 采样帧，随后消失；重置后计数和可见性清除。
- 独立渲染检查：停止时间前后像素差为 0；不透明前景完全遮住体积时像素差为 0；效果能渲染并到时清除；无着色器编译错误。
- 本地对照页：`artifacts/beam-impact/index.html`，含同时间播放、拖动和命中时刻切换。源文件摘要保存在 `before/sources.txt` 和 `after/sources.txt`，基线验证器另存于 `before/BeamImpactReview.cs`。

macOS 构建、本地签名和完整游戏验证通过，结果记录在 `logs/beam-impact-player-result.json`：运行 72.01 秒，32 次普通攻击、2 次大招、1 次防御、1 次受击、暂停与胜利完成，保存 47 张实际打包版截图。排除启动预热后，大招体积命中恰好 2 次。此次使用自动输入，没有启用真人摄像头。

`artifacts/beam-impact/status.json` 绑定连续渲染、源码摘要及本次打包版的程序和资源摘要。实际游戏截图目录是 `artifacts/cinematic-combat/player/20260928T194928109475Z/native/`。

这轮只增强大招接触的空间感与烟尘连续变化，仍不代表整体演出已达到参考街机品质。帧率专项优化仍按用户要求后置。
