# 迪迦同进程三局验收（A-20261011-92）

基线 `b539a59`。本轮补齐主线交付中“同一个发行游戏进程连续三局”的自动验收；不是启动三次独立游戏，也不把第二局开场当作第二局已完成。真人孩子、真实相机和小米电视仍单独待验。

## 验证方式

- `guided_player_check.py --rounds 3` 通过同一个本机姿态接收器送入合成肩肘腕数据，依次完成三次胜利、四张自动合照（首局重拍一次），并进入第四局战斗。
- 每次继续都先保留旧举手，再放下、重新举手，检查同一姿势不会直接跳过下一阶段。每局通过日志核对怪兽血量回到 50、能量回到 0、投射物序列无重复，并要求胜利后经过合照续局入口。
- 每张照片保留独立的冻结预览截图，逐张比较 1920×1080 导出与屏幕预览的主体区域。旧取证逻辑只保存首张 Review，因此以前单局结果不能证明后续照片相同。
- 所有轮次使用同一 PID，定期采样进程 RSS／VSZ。合成的人物会摆动双臂，但仍不能代表真人分割边缘或近远移动的全部情况。
- 原脚本默认仍为一局；多局选项要求使用同英雄续局，其他英雄的现场验收不属于本次范围。

## 复现

```sh
bash scripts/build_macos.sh --release
.venv/bin/python scripts/guided_player_check.py --timeout 780 --hero Tiga --tempo-skills --early-photo-choices --same-hero-replay --rounds 3 --memory-output artifacts/tiga-three-rounds-20261011/memory.tsv --memory-interval 2 --output artifacts/tiga-three-rounds-20261011/guided --log logs/tiga-three-rounds-guided.log
```

本机结果保存在 `artifacts/tiga-three-rounds-20261011/`；仅使用明确标识 TEST 的合成图，不保存真人照片、不调用 AI 美化。相机流和姿态流的中断由测试主动注入，不能当作真实相机错误。
