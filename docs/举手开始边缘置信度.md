# 举手开始边缘置信度

## 目的

这是 A-20261015-149，针对迪迦整局主线的第一条引导衔接问题。前置摄像头把双手举到画面上沿时，MediaPipe 可能降低腕点置信度；原来的等待页开始通道按 `.45` 的腕点置信度和较高的肩线上移量判定，孩子已经举手但游戏仍停留在选角页。

## 修改

- `Pose.cs` 的开始通道把双腕最低置信度放宽到 `.35`，肩膀和躯干存在性仍保持 `.45`，普通出拳和护盾规则不变。
- 双手仍必须同时可见并持续保持；单手挥动不能开始。
- 高举阈值从肩线以上 `0.55 × 肩宽` 放宽到 `0.42 × 肩宽`，允许弯肘高举，仍不会把胸前护盾当作开始。
- `Reset(requireTransformRelease:true)` 的合照续局门禁保持不变：必须先观察到真实放手，再允许下一次举手；选英雄继续只接受左右按键或点击卡片，未增加手势选角。
