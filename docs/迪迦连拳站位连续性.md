# 迪迦连拳站位连续性（A-20261011-90）

基线 `1552ccb`；按用户要求集中迪迦与哥尔赞，其他英雄打磨后置。本轮处理连续近战中的大幅前后折返，不修改识别、伤害、能量或攻击速度。

## 可见问题与修改

复看参考街机 60 秒附近的连续近身攻击，以及当前同输入战斗 31.5–33.5 秒。当前版本虽有交锋站位保持，每一拳仍叠加迪迦原片段 1.25 单位的前冲，然后退回，再重新前冲。连拳读起来像单段动画的重复。

现在把这段前冲的 55%（0.6875 单位）保留在近战交锋站位中，相应减少逐拳移动，出拳峰值的总前进距离保持一致。腿部目标沿同一站位计算，停手后使用原有分步退回。踢击单独扣除已保留的距离，避免连击第五下把人物再次送进怪兽身体。

只对迪迦启用这个分配；其他英雄原来的步幅不变。远程施放的 0.10 单位移动不变，近战转远程／防御沿已有退步衔接。原有动作速度、左右拳、15 拳蓄能、50 次血量、语音反应时间保持不变。

## 复查发现的近身穿插

初版 75.19 秒发行近战整局和 152.0 秒合成体感合照续局均通过，但检查 `attempt-1-transitions/Tiga-near-fall.png` 发现英雄与怪兽躯干重叠。原来的衔接检查只约束地面和站位锚点，没有约束双方躯干间距，不能据此判为视觉通过。

仅按近距离缩短怪兽前冲的首轮修补仍失败，新检查量出最小胸部距离 0.1073。进一步定位到 `GameWorld.BindActors` 只设置了英雄的对手，没有为怪兽绑定英雄；因此怪兽始终按开局远处的位置计算追击。修正为双向绑定，并让近距离爪击的身体、前脚位移一起缩短，保留原攻击命中时刻。失败日志与坐标见 `logs/tiga-continuity-close-diagnostic.log` 和 `diagnostic/transitions/`。最终包必须在此修正后重新验证，不能借用初版的通过结果。
