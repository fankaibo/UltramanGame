# 哥尔赞张爪、抓击与松爪（A-20261019-176）

基线 `e212954`。本轮重新渲染当前五类攻击的手臂近景，而非沿用早期问题截图判断。此前反折腕已受 35° 限位约束，但爪击仍缺少明确的手指动作：双手主要共用一个宽缓的弯曲脉冲，预警末段已经蜷指；掌心转向按攻击状态直接切换，代码中计算的渐变量没有用于朝向。

## 修改

- 只对左右爪击的出击手：预警最后 0.5 秒逐渐张开，攻击 0.10–0.40 秒随原有接触时钟收拢，0.53 秒后随回收放松，结束时回到原恢复手形。
- 出击掌心在攻击前 0.20 秒逐渐转入抓击方向，0.64 秒后渐回；替换原来按阶段直接切换的目标，清除未使用的变量。
- 保持原肩肘腕位置、骨长、35° 腕部限制、前冲落脚及命中时机。投石握持、砸地、头部光线、支撑手和待战手形不套用此抓击节奏。
- 识别、语音反应时间、伤害、合照和英雄选择规则不变。没有重新制作网格；长指比例和模型精细度仍有改进空间。
