# 必杀光线分段与命中跟随

本轮继续优先完善街机演出，帧率优化后置。旧版在发射第一帧直接显示整条白色光线，持续火花固定在场地坐标；哥尔赞后仰后，光线与身体接触处会错开。键盘练习界面的招式标题还会挡住举起的手臂。

新版保留蓄力近景，然后依次表现光束飞出、胸口命中、持续放射和淡出收束。光束由蓝色外层、白色窄芯和沿射线移动的纹理组成；光束末端与局部补光跟随胸部骨骼，命中前不产生怪兽身上的连续火花。必杀受击使用较弱的蓝色材质反馈，普通拳击保留暖色反馈。

两种输入模式都在画面下沿显示招式名；键盘模式发射期间暂时收起动作卡片，体感模式暂时隐去正上方的积分条，避免遮住举起的手。家长控制入口仍然可用。已确认的原声、动作识别、儿童反应时间、50 次默认血量、15 次普攻充能和一次必杀 9 点伤害不变。

## 时序与接触点

- `BeamCloseup` 仍为 1.35 秒特写，期间保留输入检查，战斗时钟暂停。
- 特写结束后的动作时钟到 0.28 秒开始发射，到 `Battle.BeamHitSeconds`（0.45 秒）抵达目标，与原有唯一一次伤害结算一致。
- 接触后持续发光和产生火花，从 1.22 秒开始收束，到原有 1.5 秒动作结束清空光束。
- 胸口目标在初始姿态中保存为胸骨局部坐标。实际反冲测试中目标移动约 0.46 Unity 单位，光线跟随这个位置，发射端始终绑定当前英雄前臂。
- 暂停、跟踪丢失进入暂停、重新开始均走现有清理路径，没有创建额外战斗阶段。

## 复现

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.FinisherReview.After \
  -quit -logFile "$PWD/logs/finisher-after.log"
```

`Before` 只保存当时源码的表现，不会切换历史版本；不要在新版上重新生成并冒充旧版对照。

这是现有骨骼动作之上的必杀表现改进，角色原始模型、动作丰富度和整局镜头编排仍与参考街机存在差距。自动回放也不代替孩子真人操作和电视显示验收。
