# 护盾薄膜与局部受击（A-20261012-137）

基线 `4a36d84`，2026-10-12。A-136 已交付高位连击镜头，属于 Progress。本轮基于实际高位中景继续改善防御画面，不修改姿态识别和玩法。

## 观察与实现

原盾面使用较宽的菲涅耳发光，在斜视时中央也大面积增亮；额外六边形线框与椭圆盾面形状不一致。原实现已经有盾面接触波纹，另有通用接触圆环与九根均匀放射线叠加，容易像辅助标记。

将斜视发光收窄，保持中央几乎透明，沿曲面薄边缓慢流动。六边形纹理只在真实格挡的接触波纹经过时点亮；删除额外线框，格挡不再创建通用接触圆环和均匀放射线。保留原接触投影、局部光波、火花、短闪光、盾面压缩、身体反光、双方后坐与声音。没有新增纹理、屏幕抓取、反射相机或逐次攻击对象。

首候选虽然减轻了中央遮挡，但边缘过厚，像发光圆环，未采用。证据保留在 `after-wide-rim/`；最终收细边缘，并去掉接触时多余的辅助图形。视觉改善不等于真人电视验收通过。

## 同输入与 GPU 验证

`ShieldFilmReview` 使用真实迪迦／哥尔赞场景，记录预警、格挡接触及恢复的六秒连续画面。15／30／60 Hz 共 630 行记录，核对战斗状态、护盾、血量、格挡／受击次数、镜头位置旋转和视角、英雄根节点；前后逐字节一致。每组一次实际格挡、零受击；对象数量固定，暂停／新局清空护盾，最终格挡中不残留通用圆环或放射线。

GPU 分别从 0°／35°／65° 观察。中央区域蓝色增量（8 位像素差均值）由 10.94／34.43／103.32 降为 2.00／2.00／11.67；这是此背景下的色光覆盖量，不能当作真实透明度百分比。边缘可见峰值仍为 177–179，受击相对静止画面的最大差为 149–163。重复冻结采样差为零，前景遮挡差为零，0.8 秒后波纹回到静止基线。未用只检查编译来代替实际 GPU 渲染。
