# A-152：大招特写与战场回切

2026-10-18；root；`codex/guided-arcade`；源码基线 `1daed93`。

## 实际问题

参考街机的招式特写、发射、怪兽受击和恢复站位连成完整演出。当前 `GameWorld` 限制所有机位移动速度，只豁免迪迦特写期间；特写结束时，朝向和视角已经切回普通战场，机位却还在从角色正面慢慢移回后方。结果不是平滑过渡，而是穿过角色、拍到空背景。怪兽受击／变身／入场特写也受同一个位置限速器影响。

先测量的 16 秒普通战斗没有复现严重跳镜：60 Hz 最大角速度 26.113°/s、视角变化 19.710°/s、机位速度 9.511 单位/s。本轮据此保留普通镜头逻辑，没有另加平滑层。进一步测量 5 秒必杀段，在第一次特写回切后发现 **连续 12 帧丢失双方主体**（60 Hz 时为 0.2 秒）。实际画面只剩怪兽身体边缘和废墟。

## 修改

`GameWorld.cs` 将迪迦特写、怪兽受击特写、变身特写和怪兽入场特写视为完整切镜：进入、维持以及离开时，机位、朝向、视角一起生效。普通战斗追随仍使用原来的 13.5 单位/s 位移上限；重开清空上一镜头状态，零时间重绘保持镜头冻结。没有改识别、伤害、能量、语音反应时间、动画和出招时钟。
