# 迪迦双臂聚能与发射衔接（A-20261018-164）

基线 `e0a8363`。参考街机录屏的大招由角色近景进入高亮发射，当前实际包的近景主要是细线绕行，交叉双臂时能量亮芯藏在胸口。此次增强蓄力的可见性，并保持脸部和手势可读。

## 改动

- 迪迦的聚能中心移到较低横臂前方；左右手高度接近时连续插值，避免手位高低互换造成能量团跳到另一侧。
- 沿用已有体积噪声与深度遮挡，强化蓝色碎雾，收紧白色亮芯；不是在角色前叠一张不受遮挡的白色圆盘。
- 24 条既有流光从绕圈改为较直接地向内汇聚，增加软边和沿线亮度变化；不增加每次施放时创建的对象。
- 聚能按原特写时钟收拢至实际光线起点，保持蓄力、特写退出、发射连续。必杀语音、识别、伤害、镜头和游戏时钟不变。
- 仅迪迦启用新样式；其他英雄保持原有配色和聚能轨迹。

## 候选与证据

目录：`artifacts/a164-beam-gather/`。

首轮离线工具没有调用 `SetHeroProfile`，未覆盖实际迪迦特效配置。这次修正 `FinisherReview` 和 `BeamChargeReview`，同时按相同配置重做旧源码与新源码对照。`unconfigured-baseline`／`unconfigured-review` 只作为工具问题证据，不能作为最终前后比较。

`draft-face-occluded` 的双手中点偏高，亮芯遮脸；`draft-bright-core` 仍偏亮。最终候选将聚能中心下移、收紧亮芯，关键帧保留。最终对照是 `before` 与 `after`，不是上述候选。

`continuous-before-after.mp4` 为 4.2 秒、30 fps、左旧右新的完整蓄力／发射／命中／收招画面，没有变速或插帧。对应 252 行 `sequence.csv` 完全一致，包括动作时间、特写状态、光线可见性、怪兽血量和光线起点。

- `FinisherReview.After`：迪迦 15／30／60 Hz、其余四位英雄 60 Hz，飞行／命中／衰减／反应镜头通过；三种施放中断点均清理光线、光照与镜头。

- 58 Python 测试与累计 2324 核心／通信检查通过；正常 Unity 源码 Release 构建和签名通过，源码与包身份记录在 `build.json`。
- 实际发行包 165.6 秒高位合成体感流程通过：2103 帧普通战斗输入中 0 低手位，32 次左右快慢拳光弹发射／命中、2 次必杀、4 次防御，两次自动合照、重拍、短暂断流恢复和语音续局进入第二局；0 键鼠事件、0 手势选角，两照预览差 0。已检查原生特写与发射前桥接画面。
