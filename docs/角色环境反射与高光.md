# 角色环境反射与高光（2026-09-27）

本轮按“街机画面优先、帧率专项后置”的顺序调整角色表面与场景照明。火山场景原先没有专属环境反射，银色装甲较依赖局部灯光；强光直接输出到屏幕，容易出现硬亮斑和白色区域丢失层次。

`VolcanoEnvironment` 在创建场景时捕获一次柔和的天空、地面及熔岩方向反光，使用 128×128 六面 HDR 纹理和八级缩小纹理，不捕获角色和战斗特效。该项目使用 Gamma 渲染，反射着色器按实际色彩空间编码。组件在运行时及编辑器预览销毁时释放资源，且只在仍持有全局反射时恢复之前的设置。

英雄的银色装甲与彩色战衣分别降低光滑度和金属度，补光更接近中性的冷光；提高环境暗部，使面部和胸口仍可读。必杀时的蓝色轮廓补光减半。最终合成在通道值 0.78 以上使用柔和高光过渡，暗部与中间调不受这条曲线影响；逐通道接近白色，避免强光硬裁切。

## 本机对照

`artifacts/hero-environment/index.html` 包含五位英雄各六张材质镜头、4.2 秒连续大招左右视频和本轮原生游戏截图。材质镜头两侧使用相同姿势、镜头和原始贴图，下缘有裁切，仅用于材质对照。

视频左侧来自 `01cefe230da8385a008f2172d273b6c98e3248f3` 的已有渲染，右侧为新版，各 126 帧、每帧 1280×720，合成后为 2560×720。双方 252 个动作时钟与光束起点样本完全一致。离线 30 FPS 视频不代表游戏帧率。

`scripts/encode_environment_review.py` 验证基准文件摘要与该 Git 提交一致、新版摘要与当前工作区一致，并核对玩家程序集及资源包摘要后才附加实机图。来源保存在同目录的 `provenance.json`。

## 验证

- `logs/hero-environment-release.log`：反射六面和八级纹理有效，缩小后平均亮度稳定；在无灯光和环境漫反射的独立 GPU 场景中，真实英雄着色器的 25,739 个像素受到反射影响，重复渲染不闪烁。连续三次创建/销毁恢复之前的纹理、模式和强度；清理旧组件不会覆盖新的环境持有者。
- `artifacts/hero-environment/inspection/highlights.txt`：HDR 输入峰值 0.1、0.5、1、2、4、8 的输出保持强度顺序和颜色通道顺序，高光不硬裁切；0.1 与 0.5 保持原亮度，仅含原有暗角影响。
- 五英雄护盾的局部受光、回弹、脚部支撑、衰减、暂停及新局清理通过；受光不扩散到腰部以下。记录为 `artifacts/hero-environment/guard/validation.txt`。原有接触闪光的位置、圆形比例、衰减、暂停和重置也通过。
- `logs/hero-environment-arena.log`：五英雄必杀发射、命中和恢复通过，另检查迪迦 15／30／60 Hz 逻辑步进及飞行、持续、收束中途取消；这些是逻辑采样，不是运行帧率。
- `logs/hero-environment-build.log`：macOS 构建与本地签名通过。

真实 macOS 玩家回放用时 113.41 秒，完成 32 普攻、2 必杀、1 格挡、1 受击、暂停恢复和胜利，保存 29 张 1920×1080 截图，已查看开战、护盾、必杀特写和持续光线。使用合成输入，没有调用真人摄像头。证据目录：`artifacts/cinematic-combat/player/20260927T123041268264Z`。

该次程序集 SHA-256：`4225cf2ceac6e1c51ca42f10e9c64bb6b9cacf6d8c2dd9f4932822521e5a6738`；资源包 SHA-256：`27a3bf16957fa9f14b70b86862c7537a9499cb84cc7bf8dfd81b0eacde8f97e7`。日志确认只在启动时捕获一次反射。采样帧率仍低于 60 FPS，专项后置；本轮未重新验收真人体感、电视投屏或合照 AI。

本轮没有改变动作识别、输入模式、默认血量、充能次数或无键鼠流程。主要收益是光照与表面的配合；低清贴图、角色素材和连续动作仍限制最终街机观感，不将本轮描述为达到参考视频品质。

## 复现

1. Unity 执行 `UltramanGame.Editor.EnvironmentReview.Release --guard-output "$PWD/artifacts/hero-environment/guard"`。
2. Unity 执行 `UltramanGame.Editor.FinisherReview.After --finisher-output "$PWD/artifacts/hero-environment/arena"`。
3. `bash scripts/build_macos.sh`，再运行 `.venv/bin/python scripts/cinematic_player_check.py --hero Tiga`。
4. `.venv/bin/python scripts/encode_environment_review.py --player <该次玩家证据目录>`。
