# 受击动作连续性（2026-09-18）

本轮以用户参考街机中的连续受力、收势为目标，修正普通拳和光线命中后哥尔赞的反应。帧率优化后置，动作识别和战斗规则不变。

## 改动

- 移除受击时整个怪兽根节点的平移、后仰和侧倾，保留烘焙动作中的骨盆下沉、膝部缓冲和固定脚掌，避免脚随躯干被抬起或钻入地面。
- 普通左拳和右拳分别带动相反方向的胸腔扭转，头部比胸腔晚约 35 毫秒开始跟随，随后平滑回到原姿势。旋转按战斗场景的世界轴施加，避免左右镜像骨骼使用不同局部轴而扭错方向。
- 光线受击恢复从 0.4 秒延长至 0.9 秒；保留最初的快速受击，拉长后续收势。只改变表现，伤害仍在同一时点结算。
- 叠加姿势在下次采样前撤除，防止过渡混合重复叠加上一帧旋转。怪兽主动爪击仍使用原烘焙动作；暂停、展示姿势和待机不叠加受击层。
- 主动爪击增加轻量的胸腔／头部跟随层：主攻侧不同，双手和脚部仍完全由 `Attack`／`AttackAlt` 烘焙曲线控制。第一次与第二次爪击的取证帧显示不同的头部朝向和重心转移，避免连续战斗像重复播放同一个姿势。
