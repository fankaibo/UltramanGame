# 迪迦眼部透光层次（A-20261011-113）

基线 `8655104`。上一轮脚掌发力已构建、整局验证和推送，属于 Progress。本轮查看 A-112 实际发行必杀近景，眼部呈统一黄色亮片，近景可见三角面反光；此问题影响大招与合照的角色质感。

## 来源与实现

只读检查 `artifacts/character-sources/Ultraman Tiga.blend`，禁用模型内脚本，确认作者 `EYESEMI` 材质原有 `Layer Weight`、`Fresnel`、颜色梯度和发光混合。原转换脚本 `prepare_tiga.py` 将其替换成单一颜色与发光，Unity 又使用 Standard 材质，丢失角度层次。可重复运行 `scripts/inspect_tiga_lens.py`，摘要及节点记录为 `artifacts/tiga-lens-20261011/source-inspection.json`。原始文件没有修改。

- `TigaLens.shader` 根据实际表面法线和相机方向，让暖色中心到较暗边缘连续变化，保留眼罩反光。使用作者线性颜色转换后的显示颜色；这是实时近似，不声称逐节点复刻 Blender 的全部离线效果。
- `TigaLensMesh` 对眼罩发光面合并接缝处法线，消除近景三角反光，保留黑眼眶边界。运行时克隆由 `RuntimeResources` 随角色释放，源 FBX 不变。
- 真实眼罩使用刚性 `MeshRenderer`，并非身体的 `SkinnedMeshRenderer`。初版只处理蒙皮网格没有生效，已改为支持实际眼罩类型，且以源／实例网格比较检查防止静默漏做。
- 只有迪迦眼罩使用新着色器。胸灯、额头水晶、其他英雄、骨骼动作、识别、伤害和开始／合照流程保持现有实现。

角色身份参考页：[圆谷官方迪迦页面](https://tsuburaya-prod.com/heroes/ultraman-tiga)；实际材质依据是项目已有作者模型，未下载或替换为官网图片。模型授权继续以 `Characters/Tiga/ATTRIBUTION.txt` 为准。
