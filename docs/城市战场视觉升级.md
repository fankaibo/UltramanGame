## 当前实现

- 将滨水空平台改为立体城市街区：道路、楼群、窗格、屋顶设备和小型车辆提供巨人尺度参照，保留远景城市原图。静态城市按材质合并，避免每扇窗或建筑附件单独产生绘制调用。
- 镜头降低，怪兽前冲时作短距离跟随；普通战斗保留迪迦背侧、怪兽正面的斜向站位。特写、大招和暂停回位继续使用原战斗时钟。
- 大招切换到迪迦正面三分之二镜头，能看到脸、胸甲和双臂蓄力；光线目标从怪兽腰部上移到胸口，核心光束和外围电弧比例同步调整，结束后恢复斜向战场。
- 体感模式界面采用双侧角色头像、紧凑能量/血条、连击数和短动作引导；保留右下角镜像预览。修正渐变纹理重复采样造成的边缘细线。
- 增加命中烟尘和小碎片；效果使用固定对象池，有明确生命周期，暂停/重新开始会清理。
- 哥尔赞左臂镜像 IK 的 pole angle 从 0 改为 π，重新烘焙六段动画。原先待机左肘朝胸口内折，修正后朝外；未修改蒙皮权重或原始网格。同步更新 FBX 哈希和资源署名。
- 合照迪迦的大小、位置和裁切固定，只有摄像头人物按比例缩放和定位；全身模式对齐脚部，半身模式按头肩比例处理，并提示退后。半身摄像头未拍到的腿不会被补造，因此半身构图仍需进一步美术处理。
