# 护盾准备与来袭强弱衔接（A-20261019-174）

基线 `55ac94b`。当前实际普通战斗中，孩子双手保持较高、收拳进入防御时，护盾会经常出现；此前怪兽休息和攻击时使用同一强度的轮廓，缺少准备与承受攻击之间的区别。

## 改动

- 准备防御时保留较轻的透明轮廓；怪兽进入预警或攻击后，约 0.19 秒平滑恢复原完整轮廓，恢复／休息时渐弱。
- 只改变常亮边缘和薄膜的强度。实际接触亮芯、分段前沿与六边网格传播保持原算法、接触点和时钟，不因准备轮廓变轻而削弱。
- 识别阈值、是否格挡、伤害、角色姿势、镜头和反应窗口不变。暂停／新局清理强度状态，没有增加每击创建的对象。
- 护盾验证工具改为每帧刷新真实蒙皮；新旧版本都用同一取帧方法，避免角色姿势落后于当前效果。
