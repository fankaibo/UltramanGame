# 连击近景与镜头回位（2026-09-28）

普通拳原先只有短暂的轻微推进，第五拳连击也沿用同一镜头，难以突出接触与怪兽后撤。本轮给每第五拳增加约 0.8 秒的侧向近景：镜头在挥入时靠近，短暂保留双方上身与双手，再随收招退回对战构图。左右拳采用相反的侧向偏移。

镜头由独立表现时钟控制，不阻塞识别、攻击或伤害结算。进入防御或怪兽预警时快速淡回；必杀、受击、暂停、新局和合照展示直接清理该镜头。第五拳触发记录保留到下一次攻击，避免清理后同一拳重新触发近景。

所有战斗侧移同时改用固定的场地坐标轴，不再读取上一帧相机的右方向，防止特写返回或重复渲染时累积方向偏移。近景抬高瞄准位置，为怪兽头部与顶部血条留出间隔。

真实游戏截图暴露出鼓励文字与扣血数字重叠在怪兽脸前的问题。一并将鼓励文字移到左侧连击区，将扣血数字缩小并收进怪兽血条下方，保留角色面部和命中位置。
