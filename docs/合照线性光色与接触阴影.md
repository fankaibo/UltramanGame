# 合照线性光色与接触阴影

用户反馈 AI 照片与原图观感接近。此前已确认，现有实现由 `gpt-5.6-terra` 返回调色参数，再在本机执行，不是生成式图像编辑。本轮修正其中真实存在的色彩计算错误，并验证实际游戏的后台处理链；没有把调色宣称为已经实现人物重绘与完整场景融合。

## 修正

Unity 的照片、半透明人物和背景按线性光照合成；旧后处理直接使用 sRGB PNG 的数值反算人物颜色，再乘曝光系数。在 25%／50%／75% 透明区域会得到错误的颜色，曝光也比相同摄影 EV 更暗。

现在先解码到线性光照空间，还原人物、调整曝光／RGB 增益／亮度加权饱和度、处理边缘与环境包边，然后重新编码为 PNG。边缘处理宽度随照片高度缩放，人物原始蒙版外不增加身体像素；允许修改范围外沿用原图字节，避免干净底图的少量 GPU 舍入差异改变奥特曼。

原来在整个人物的底边画一个宽椭圆阴影，现在只在实际可见的脚底轮廓下分别生成软接触阴影。触及照片下沿的半身肖像不生成落地阴影，两脚之间不会出现横跨空隙的阴影条，左侧英雄始终不在阴影修改范围内。

模型现在同时看到最终照片、包含固定英雄的干净场景和人物透明度蒙版，提示明确曝光以线性光照的摄影档位计算、匹配可见英雄的受光，而不是把脸压到夜空的亮度。模型仍为用户指定的 `gpt-5.6-terra`，网关与密钥来源未变；没有接入未经选择的额外图像编辑模型。

设置和预览状态改为“AI 光色优化／AI 光色版”，对应当前能力。原照片仍保留，另存 `_AI.png`。网络失败只返回错误类别、函数名称和可选代理状态码；不会记录请求地址、密钥、响应正文或异常描述。

## 实际验证

`PhotoFusionReview` 从真实 Unity 合照相机导出成片、干净底图和线性蒙版。迪迦／格力乔、1920×1080／2560×1440、全身／半身／半透明色块共 12 组。输入是明确的合成测试图形，没有使用家庭照片。

基线为 `f7b26485b52461397b55e65c42d5f49d1bf32fc6` 中的旧 Python 实现，两版使用同一组 Unity 像素与参数。独立的物理曝光参考检查中，旧算法半透明色块的通道误差 P99 为 23～40 个灰度级，当前为 1；全不透明区域由 27 降为 0。所有案例中左半幅英雄与背景逐像素保持原样；半身蒙版之外变化为 0，全身在双脚下生成接触阴影。

两项新增回归在修改前失败：曝光与半透明反算误差、缺失脚底接触阴影；修正后通过。另外覆盖网络错误诊断不会暴露异常正文，原图在成功与失败后均保留。

独立模型调用使用一张合成全身 TEST 图，15.93 秒完成。`gpt-5.6-terra` 返回的场景分析识别月光、蓝色环境光与远处暖色火山光；输出保持 1920×1080，左侧英雄逐像素不变。

随后通过真正的 `LocalPhotoEnhancement` 后台线程启动 Python 入口，经历 TLS/代理连接的暂时失败；终端与 Unity 的 TLS 库、代理和只读网关连接核对一致并恢复后，再次执行成功。补齐安全错误诊断后的最终入口检查在 8.24 秒完成，Unity 能载入另存 PNG，原图摘要未变，英雄像素未变。失败记录保留在本地日志；没有声称修改了网关或消除了外部网络故障。

本机对照入口为 `artifacts/photo-linear-fusion/index.html`，记录 GPU 源码摘要、旧／新处理源码、实际模型参数、后台工作线程和最终程序验证。图片与原始证据在 Git 忽略目录中。

最终 macOS 构建和本地签名通过。`scripts/check.sh` 通过 36 项 Python、330 项 C# 核心和含跨进程协议的 333 项集成检查；随后补查的字符串网络错误分支也通过。实际最终程序完成 140.2 秒无键鼠回放：95 帧防御噪声、10 帧大招噪声期间误触普攻为 0，格挡和必杀各两次；两次自动合照、重拍、倒计时照片流中断恢复、预览姿势流中断恢复和举手续局通过。照片预览／保存中心区域颜色差 P99 为 0。

程序 SHA-256 为 `5314cb9898181e407aa77e35fc4c5b20538633fa3b7d7865b3dbee6d9a5ab181`，资源 SHA-256 为 `804335bea41031d66d5b5fa997e068d82586891d6a5ac1d053ab551e365f3403`。无键鼠回放使用合成 TEST 人像并按现有规则关闭联网美化；真实模型与 Unity 后台任务是前述独立的合成照片检查，不把两者混称为孩子实拍验证。

## 复现

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.PhotoFusionReview.Run \
  -quit -logFile "$PWD/logs/photo-linear-render.log"
.venv/bin/python scripts/review_photo_fusion.py
# 以下两步各会实际调用一次用户配置的模型，仅发送合成测试图：
.venv/bin/python scripts/review_photo_fusion.py --request-model
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.PhotoEnhancementWorkerReview.Run \
  -quit -logFile "$PWD/logs/photo-linear-worker.log"
bash scripts/check.sh
bash scripts/build_macos.sh
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --output artifacts/photo-linear-fusion/guided --log logs/photo-linear-guided.log
.venv/bin/python scripts/review_photo_fusion.py
```

人物几何、缺失身体和真实发丝结构没有被重绘。真人照片的边缘质量、非均匀环境光融合及更接近街机的连续动画仍待改进；这些合成输入检查不能代替孩子的真实摄像头体验。增加图像编辑模型的选择仍待用户答复。
