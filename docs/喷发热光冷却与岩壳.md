# 喷发热光冷却与岩壳（A-20261012-133）

2026-10-12，基线 `a70a3d1311745025a70880d2f2a6f6a3ff571b78`。重新查看参考机台及当前发行版：角色占据主要画面，但背后喷发碎石的大橙色光团仍显得规则且抢眼。本轮改善场景层次，不改变角色动作或识别规则。

## 原因和修改

`VolcanicEjecta` 已传入随热度改变的顶点 RGB，但 `VolcanicSpark` 忽略了 RGB、只读取透明度，并重新生成固定橙色高亮。隔离 GPU 测量中，同一几何、同一透明度，热度从 1 降到 0.3 后，旧版 RGB 累积能量从 2069.70 变为 2078.84，几乎没有变暗，绿／红比也维持 0.21。

现在火星直接使用传入热色；碎石外层光晕随热度平方衰减并收小，固体岩壳在同一弹道上保留。第一候选仅调整光晕，完整场景差异偏弱，未交付；第二候选同时修改 `VolcanicBomb`，以随冷却扩大的暗色岩壳包住不规则熔融斑块，取消整块表面持续泛橙光的偏置。远处斑块继续做像素足迹过滤，避免高频闪烁。

最终隔离测量：热度 1／0.3 的 RGB 能量为 2572.30／1229.96，冷态约为热态的 47.8%；绿／红比由 0.26667 降至 0.17390。该结果证明颜色和辐射强度响应热度，不是物理温度标定或写实程度评分。

## 连续对照和回归

`EjectaCoolingReview.Before/After` 调用真实舞台：每侧八秒、240 张图，480 次逻辑采样。前后玩法 CSV 完全一致；一次格挡、怪兽血量 50、无未防御受击。另有四秒喷口近景和三个视角，冻结时间重绘一致。已查看舞台和喷口实际渲染，亮色喷发仍可见，空中和落地碎石的暗色表面更加清楚。

240 帧完整岩体网格、活动数和落地数摘要一致，证明改动没有移动固体轨迹。现有 `VolcanicEjectaReview.Validate` 验证两张固定网格复用；GPU 可见像素 5,229，动态变化像素 8,579，冻结／回退差异和前景漏光均为 0。三种坡度 × 三块岩体 × 15／30／60 Hz，共 27 组接触检查通过，最小离地距离 0.00300、稳定落地间隙 0.00300、接触边界步进 0.000461 世界单位。

49 Python／2222 核心与姿态桥接检查通过。没有修改喷发数量、抛物线、旋转、落地时机、烟柱、熔岩沟、战斗时钟、英雄手位、动作识别或合照规则。
