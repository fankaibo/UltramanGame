# 怪兽交锋镜头与遮挡修正（2026-09-28）

前一版在怪兽前冲时继续推近并收紧视角，迪迦头部容易进入顶部状态栏，脚部接近底部边缘；受击时又会立即切换镜头运动。参考街机的连续交锋需要清楚呈现蓄力、前冲、接触与恢复，本轮改为提前准备双人构图，并连续跟随挥爪与防御结果。

在预警结束前 0.6 秒平顺调整构图，随挥爪侧移，左右攻击使用相反的侧移方向；完整呈现攻击后用 0.55 秒退回普通镜头。未防御时保持倒地、落地和起身的构图，起身结束后再退回。持盾的普通景别稍宽，以容纳举起的手臂；蓄力特写仍拥有独立的近景视角，不会因孩子举起护盾而削弱。

语音提示取消或延长预警时，镜头从当前位置平顺退出。必杀切入、暂停、展示与新局会清理交锋镜头。镜头只读取战斗状态，不改变姿势识别、攻击命中、护盾判定或提示反应时间。撤步时沿用已完成的侧移量，避免敌人切换至恢复状态时镜头横向跳动。

## 连续画面对照

`artifacts/enemy-exchange/index.html` 提供左右对照视频与真实游戏 HUD 截图。左侧为 `084a611e76dac15260458363fb7062673a2315b4`，右侧为本轮实现。四段各 4 秒，依次为第一侧挥爪格挡、第一侧挥爪受击、另一侧格挡、另一侧受击，不把四段拼接称作一次完整战斗。

两侧各 480 帧，四份战斗状态 CSV 逐字一致；离线渲染为 30 FPS，不代表游戏实际运行帧率。对照脚本核对基准源码、当前源码／模型／HUD 摘要和打包版摘要。原始模型、贴图和骨架均未修改。

## 编辑器验证

共 28 组：五位英雄 × 两侧攻击 × 格挡／受击，迪迦额外覆盖 15、30、60 Hz。实际蒙皮网格采样中，顶部面板覆盖区域的模型顶点数为 0，攻击时底部引导条覆盖区域的模型顶点数也为 0。模型完整保留在画面内，四角射线确认背景没有露边；重复零时间采样不会移动镜头。最大相机移动速度约 2.44 个场景单位／秒。

另有 21 组退出检查：提示替换、预警延长、暂停、新局、重置、展示和必杀，分别覆盖 15、30、60 Hz。提示打断／延长时最大退出速度约 0.821 个场景单位／秒，未残留交锋镜头。五位英雄的原有蓄力近景另行回归，怪兽投影放大约 1.276 倍；攻击前回到防御构图。

复现：

1. Unity 执行 `UltramanGame.Editor.EnemyExchangeReview.Release`。
2. Unity 执行 `UltramanGame.Editor.ThreatCameraReview.After --threat-output <仓库路径>/artifacts/enemy-exchange/threat`。
3. 执行 `bash scripts/build_macos.sh`、`.venv/bin/python scripts/cinematic_player_check.py --hero Tiga`。
4. 执行 `.venv/bin/python scripts/guided_player_check.py --output artifacts/enemy-exchange/guided --log logs/enemy-exchange-guided.log`，记录运行前后构建摘要至该目录的 `build.json`。
5. 执行 `.venv/bin/python scripts/encode_enemy_exchange_review.py --player <当前打包版证据目录> --guided artifacts/enemy-exchange/guided`。

本轮专注交锋的连续性和可读性；更多攻击动作、演出内容与整体模型品质仍需继续提升，不能据此宣称达到参考街机的最终效果。帧率专项继续后置。
