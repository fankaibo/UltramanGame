# 受击倒地与起身演出（2026-09-26）

本轮继续优先改善街机演出，帧率专项后置。参考根目录录屏与 `artifacts/reference-video/contact-sheet.jpg` 中的连续攻防节奏，针对旧版“受击后瞬间站回去、身体落到画面外”的问题完成一段可读的受击演出。该改动不代表整体品质已经达到参考机台。

## 变化

- 受击动作从 0.55 秒延长至 1.65 秒：前 0.30 秒后仰失衡，至 0.68 秒保持落地姿态，然后撑起身体并恢复战斗站姿。倒地期间不会出拳或展开护盾，起身后重新接受正常动作。
- 五位英雄均使用骨盆定位、双腿关节求解、单手撑地与原有受击片段；修正了旧版旋转整个模型导致腿部穿地的问题。不同角色按站立时的脚踝高度计算靴子离地量。
- 修正其他四位英雄使用 `bip_*` 骨骼时，上臂及左前臂未被缓存的问题，使撑地手和已有肩部表现层也能生效。
- 增加独立 `HeroLanded` 事件。身体触地时发出扬尘、低强度落地声与恢复语音；不再在刚被打中、身体仍在空中时就产生整片地面尘浪。尘浪的位置来自本帧骨盆投影。
- 倒地时抑制怪兽冲刺推镜，镜头拉宽并向英雄侧移；底部动作卡片暂时收起，保留设置、模式切换和暂停入口。起身后卡片恢复。
- 识别门槛、50 次默认血量、15 次普攻蓄能、预警语音后的儿童反应时间均未改动。追踪丢失仍立即暂停，不要求孩子跟着角色真的摔倒。

.venv/bin/python scripts/cinematic_player_check.py

  --output artifacts/knockdown-guided --log logs/knockdown-guided-player.log
