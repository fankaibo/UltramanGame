# 慢速连发镜头连续性（A-20261011-107）

基线 `3043b33`。继续检查街机的连续交锋体验，发现镜头只为快速连发保持中景：普通发射动作结束后仅等待 0.65 秒，孩子稍慢地收手、换手再发射，就会被判为新一组，镜头反复退远再推近。怪兽已有左右受击及第三次连续命中退步，本轮不改这些动作，也不改动作识别门槛。

## 复现与实现

- 新增每 1.2／1.4／1.6 秒交替出手、混合 0.65／1.7 攻速的核心回归。旧代码在 15 Hz、1.2 秒节奏就失败，日志 `logs/a107-reproduce-core.log` 保留真实失败。
- 把下一次出手的镜头保持时间由 **0.65 → 1.45 秒**。仅影响普通远程连发构图，不影响攻击冷却、伤害或输入。单次孤立发射仍只小幅推进；停止出手后仍回到原远景。
- 连发期间的单向侧移上限由 **0.24 → 0.65 世界单位**，沿已有 2.4 秒平滑轨迹完成；第一只出手的方向确定该段镜头，左右手交替不会翻转视角。接近后保持中景，没有每发弹丸都重新摇镜头。
- 防御、近战和怪兽预警仍使用原快速退镜响应；暂停、展示、必杀和新局仍由原专属镜头接管，长保持不覆盖它们。

## 相同输入的实际渲染

扩展 `RangedCameraReview` 的输出目录、出手间隔与迪迦单独复查参数。电影帧改用 JPEG，复用现有编码函数。默认快速五英雄几何检查可单独运行，不把它冒充前后对照。

每 1.4 秒出手、五次交替攻击的 10.2 秒对照：`artifacts/volley-camera-20261011/before-after.mp4`，左旧版、右新版。60 Hz 的关键镜头 `before/Tiga-60/volley.png` 与 `after/Tiga-60/volley.png` 已直接查看。新版是中景，部分小腿可出画，以肩部、手部及弹道为中心；防御／怪兽反击时恢复交锋构图，不以全身始终入画作为此镜头目标。

三帧率均完成五次命中、血量 45、能量 5；五英雄快速连发的头部／双手、HUD 遮挡、背景边界与停止后回远景检查通过。三帧率 × 九种接管情形（防御、近战、连击、预警、暂停、展示、重置、新局、必杀）均通过，原平滑返回速度上限未放宽。暂停／专属特写仍允许既有切镜，不把这些切镜报告为平滑移动。46 Python + 1735 核心／桥接检查通过。

## 复现

```sh
# Before 必须在记录的旧运行时代码下生成
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.RangedCameraReview.After --tiga-only \
  --cast-cadence 1.4 --ranged-camera-output "$PWD/artifacts/volley-camera-20261011" -quit
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.RangedCameraReview.Framing \
  --ranged-camera-output "$PWD/artifacts/volley-camera-20261011/fast-roster" -quit
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.RangedCameraReview.Lifecycle \
  --ranged-camera-output "$PWD/artifacts/volley-camera-20261011" -quit
bash scripts/check.sh
bash scripts/build_macos.sh --release
```
