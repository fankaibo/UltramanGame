# 哥尔赞尾部分节随动（A-20261010-84）

日期：2026-10-10；上一版 `7a76caf`。本轮再次查看用户提供的街机录屏代表帧，针对当前怪兽身体运动中较明显的僵硬点推进。

## 变化

原先普通攻击时尾巴仅根部整体摆动，其他五段恢复为同一个固定形状。本轮让六段尾骨按不同延迟跟随，前冲／投石蓄力时反向配重，出击后尾尖较晚收回，受击时增加衰减跟随。正面光线与双手砸地的摆幅更小。倒地和腾空仍使用原有专用姿态。

`MonsterTailMotion` 给出从尾根到尾尖的累计朝向；`RiggedActor` 只把相邻朝向差施加到关节，避免每一段重复累加整条尾巴的转角。世界竖轴转动保持既有高度和骨长；短时间平滑限制姿态提示变化时的跳转。新一局清空随动缓存，重复同帧采样不再次叠加。

这不是新增碰撞伤害或尾扫技能，也没有改变怪兽手臂约束、攻击时钟、玩家识别或固定英雄大小的合照规则。
