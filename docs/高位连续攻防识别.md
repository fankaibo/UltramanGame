# 高位连续攻防识别（A-20261012-127）

基线 `bf6eff58f2fda8a31d75c705d5784239a6de3f03`，2026-10-12。上一轮定位并复现高位出拳漏检，属于 Progress；本轮修复该问题并扩大整局测试覆盖。整体街机目标保持，未提高完成百分比。

## 已确认的原因与修正

`PunchMotion` 把当前和历史手腕的肩膀相对高度都限制为最低 -0.45 肩宽。图像 y 向下，负值表示手腕高于肩膀。因此拳头放在脸旁时，不仅当前前伸可能被拒绝，收回的高位拳也无法作为下一拳的起点。相同三次前伸轨迹，肩上 0.4 肩宽仍为 3/3，肩上 0.5／0.6 肩宽原来均为 0/3。这里检查的是动作分类，不是摄像头检测骨骼的准确率。

两处上界统一放宽至肩上 1.10 肩宽。其余前伸／侧伸位移、速度、垂直运动排除、连续观测确认、收拳和冷却规则保持；开始与合照续局的举手门槛不变。防御和大招原有优先级仍保留。这一改动解决已复现的高度门槛，不能宣称解决真人遮挡、估计深度噪声或渲染停顿。

## 回归范围

新增 `HighHandGestureChecks`：15／30／60 Hz × 两种脸旁高度 × 满能量／未满能量。每组直接高位防御起步，左右快慢出拳交替三轮（六拳），收回仍在脸旁，随后防御、L 形大招并持续持姿。另测高位护盾深度噪声、双手和单手上下移动，要求没有误出拳。保留既有低位、胸前、遮挡、输入暂停、自动合照和只用按键／点击选角检查。

基线先运行新增用例，在首个高位连续出拳断言失败；改动后 49 项 Python、2222 项核心／桥接检查通过。证据位于 `artifacts/high-hand-audit-20261012/`（初始 `result.txt`、`before-regression.txt`、`after-result.txt`）和 `logs/a127-check.log`。测试输入由程序生成，不代表儿童真人准确率。
