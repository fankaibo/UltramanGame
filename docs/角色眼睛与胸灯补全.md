# 角色眼睛与胸灯补全（2026-09-27）

格力乔与捷德的模型将眼睛、胸灯和战衣放在同一张贴图中，没有独立的眼睛材质。旧逻辑按材质名称分配发光，因此实际必杀近景里两位英雄的眼睛偏暗，胸灯也没有蓄力反馈。

新增 `HeroAtlasLights`，为这两个具体素材配置原始贴图中的眼睛与胸灯区域。`HeroSurface.shader` 在区域内结合原颜色筛选发光，排除暗边、银色和橙红色战衣；发光来自角色表面，随原有骨骼变形和遮挡，未添加屏幕贴片。格力乔保留暖色眼睛，捷德保留蓝色眼睛，胸灯使用原蓝色。区域按 256×256 原图的归一化坐标记录，没有修改贴图、UV、模型或动画。

首次实际试玩发现捷德的白色眼部高光被冷色筛选漏掉，形成内部暗块；已补充区域内的明亮中性高光，重新检查模型映射、GPU 范围与最终游戏近景。没有把第一次候选截图作为最终效果。

眼睛保持常亮，变身与必杀时略微增强；胸灯随既有战斗状态加强，暂停和新局恢复常态。独立眼睛材质的迪迦、梦比优斯、赛罗继续使用既有逻辑。护盾局部反光与身体颜色保持原有处理。

## 复现

修改前使用 `HeroMeshReview.Before --mesh-review-output "$PWD/artifacts/hero-lights"` 保存基准；修改后：

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.HeroLightReview.Release \
  --mesh-review-output "$PWD/artifacts/hero-lights" \
  --guard-output "$PWD/artifacts/hero-lights/guards" \
  -quit -logFile "$PWD/logs/hero-lights-review.log"
```

当前发光区域针对已下载的两张角色图集；更换图集布局需重新校准。原贴图精度和角色连续动作仍需继续改善，本轮不表示已达到参考街机的最终品质。
