# 护盾、大招与合照比例修正

2026-09-10 根据家长反馈继续修正。家长确认大招既有误触发，也有摆出姿势仍难触发的问题。

## 问题与修改

- 旧护盾要求两手相距小于肩宽的 0.65 倍、手腕置信度至少 0.55。改为允许分开护胸、近脸防御及交叉双手，采用 0.45 可见度，不要求肘部无遮挡；已经建立的护盾容忍 0.2 秒手腕短暂遮挡。放下双手、明确伸出单拳或长时间失去手腕仍会退出防御。
- 旧宽松 L 形仅凭双手有小幅高度差即可成立，并且优先于护盾。现在低位不齐的护胸姿势保留为防御；怪兽蓄力和攻击期间关闭大招入口，防止引导孩子防御时却触发光线。护盾可取消已经命中后的出拳收尾，不再等完整出拳动画结束。
- 大招保留一手竖起、一手横放，以及双手向前推两种方式。需要实际观察到收手/非大招姿势，再保持约 0.65 秒确认；容忍 0.2 秒短暂姿势抖动，不在缺失帧上增加进度。持续摆着某个姿势等能量充满不会自动释放，画面会解释需要先收手。新增同款合成英雄音色的 `beam_reset` 提示，3.67 秒，提示后沿用 3 秒反应时间。
- 已查看本地最后一张合照：半身人像被拉到迪迦全身高度，导致头部尺寸失衡。半身构图按头顶到肩膀的比例统一缩放，同时对齐肩线，并把迪迦裁成对应半身；全身构图改为对齐头顶和脚底，避免角色悬空。双方一起适配取景宽高，举手不会只让其中一方缩小。
- 真人头肩参考使用本机近期姿态中距离抠像时间戳最近的一帧（最多相差 220 ms），结合头部窄区域透明轮廓估计头顶；不是将任意新姿态与旧图片强行匹配。无姿态时采用保守轮廓估计。构图只处理本机纹理，未上传真人照片。
