# 怪兽受击重心与连续回弹

参考根目录录屏的普攻段落，角色受击需要有身体位移、上身方向变化和连续的回弹。此前哥尔赞虽有胸部、头部反应，但后移同时带动双脚滑动，收势又与待机摆动重叠。这轮针对这些问题改进连续普攻表现，帧率专项继续后置。

普通命中后，怪兽髋部在约 0.10 秒后坐，短暂承重，再于 0.52 秒内收势；胸部先转动，头部稍后跟随，左右拳对应不同的扭转方向。双脚约束到站立落点，膝盖根据腿长屈曲，避免把整个人平移来代替受力。待机同样保留脚底约束，重心微动仍由身体完成。

连续命中会继承上一拳尚未收回的身体偏移，也会承接待机重心；命中瞬间不把根节点强制归零。待机呼吸在受击收势后淡入，避免两套姿势同时覆盖躯干。暂停和新一局清除旧的受击状态。每帧先移除上一帧的腿部约束再采样动画，重复零时间采样不会累积修正。

这些是角色表现调整。普攻伤害、输入窗口、默认 50 血量、15 次普攻蓄能、语音及儿童反应时间保持原规则。普通受击表现延长到 0.52 秒，不延长玩家出拳动作，也不阻止下一次输入。大招的受击时长保留，双脚也使用相同落点约束。

## 复现

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.StaggerReview.Release \
  --exchange-output "$PWD/artifacts/stagger-exchange" \
  -quit -logFile "$PWD/logs/stagger-release.log"
```

当前仍使用原有哥尔赞模型。后坐、承重和连续命中的衔接得到改善；实际播放器截图也显示命中的整身红色闪烁仍偏强，材质细节与局部光效需要继续调整。动作种类、场景互动与整体演出丰富度仍未达到参考街机的完整效果。
