# 待战侧身与重心跟随（A-20261010-80）

参考街机录屏中的准备动作，A-77 只有双手连续反馈，身体仍主要停在固定待机姿势。本轮在 `a54d1e1` 增加肩膀倾斜和肩髋相对侧移驱动的身体反馈；五位已就绪英雄共用，既有动作识别与战斗规则不变。

## 行为

- 使用肩宽归一化的肩线斜率、肩膀中点相对髋部中点的偏移。孩子整体向摄像头左右移动不会被误当成侧弯，远近变化也不会直接放大效果。
- 肩线与侧身分别有限幅和小幅抖动死区；身体用 0.14 秒时间常数平滑。髋部被裁切或遮挡时，仍可使用可靠的肩线倾斜；不会猜测被遮挡的重心。
- 骨盆轻移、胸背侧倾，头部部分补偿保持朝向怪兽。两腿重新求解至原有脚底位置和鞋底朝向，保留原有呼吸／脚步，不增加滑步或改变战斗距离。
- 普攻和护盾在 0.10 秒内交接，命中前由正式招式接管；大招、受击、胜利与 F5 展示使用各自姿势。追踪暂停平滑回正，切换按键／新一局清理偏移。合照使用独立固定角色姿势。
- 这是准备动作的连续反馈，不是完整全身动作捕捉，也不是新的闪避／伤害判定。

- 五英雄 × 15/30/60 Hz 通过，3675 条血量／能量／动作／得分状态前后逐字节相同。
- 左右头部侧移约 0.171–0.280 场景单位；身体新增的 60 Hz 单帧侧移不超过 0.03733。原出拳和护盾本身较大的头部移动另计，没有把它当成待机抖动。
