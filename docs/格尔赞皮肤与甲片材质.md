# 格尔赞皮肤与甲片材质（2026-09-28）

本轮按“街机体验优先、帧率优化后置”的方向，改善格尔赞在蓄力近景、连续攻击和受击时的模糊皮肤与塑料反光。原始身体贴图仅 256×1024；新增基于它生成的 `GolzaBodyHD.png`，强化甲片、胸腹、背部和尾部的鳞纹，并将身体的金属度由 0.03 调为 0、平滑度由 0.22 调为 0.16。

高清候选通过内置 image_gen 编辑工具生成，详细提示词、原始输出尺寸、文件摘要与局限见[生成记录](格尔赞高清材质提示词.md)。生成图保留为 724×2172 原文件，Unity 使用横向缩放 0.75、偏移 0.125 映射中间的原图集区域。导入使用项目统一的高质量压缩、三线性过滤、4 倍各向异性过滤和 12 级 mipmap，关闭非二次幂尺寸缩放。眼睛仍使用原贴图。

FBX、骨架、蒙皮权重、动作片段和原身体／眼睛贴图均保留。运行时缺少新贴图时回退原贴图。该资源包含 AI 生成的细节，并非官方高清素材或原始细节的准确恢复。原模型的部分 UV 接缝和多边形轮廓仍可见；本轮没有完成几何重建，也不能视为达到参考街机的整体品质。

复现：

1. Unity 执行 `UltramanGame.Editor.KaijuSkinReview.Release`。
2. Unity 执行 `UltramanGame.Editor.SurfaceImpactReview.Validate --surface-impact-output <仓库路径>/artifacts/kaiju-skin/surface-impact`。

4. 执行 `.venv/bin/python scripts/encode_kaiju_skin_review.py --player <当前打包版证据目录>`。
