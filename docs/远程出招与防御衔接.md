# 远程出招与防御衔接

改动 A-20261009-55；代码 `650b286`；2026-10-09。总体目标与剩余工作见 [开发任务看板](开发任务看板.md)。

## 画面变化

复看用户录屏 52–55 秒，角色挥臂、能量发射和收招在同一动作中连贯呈现。当前版本虽然已有光弹和头镖轨迹，但底层仍播放近战冲拳，迪迦会明显深蹲；赛罗也没有与头镖关联的准备动作。

远程技能现在以站立姿势为基础，由转肩、单臂准备、向前释放和沿弧线收手组成。另一只手留在胸前；赛罗将准备位置移到对应头侧，再挥臂引导头镖。体感左右手与攻速仍驱动同一战斗时钟，发射在 0.12、命中在 0.30、收招在 0.42 动作秒，未改变识别阈值、伤害、蓄能或无键鼠流程。

防御意图接管和确认护盾分别从当时画面上的手部位置继续运动，避免取消远程动作后立刻跳回默认手位。护盾判定立即接管；已经发射的技能继续完成一次命中。

## 复现

```bash
UNITY='/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity'
# Before 应使用 2d25eb0 的 Runtime 加本次审查器，先保存旧动作。
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.RangedCastReview.Release -quit -logFile "$PWD/logs/ranged-cast-release.log"
bash scripts/check.sh
bash scripts/build_macos.sh --release
.venv/bin/python scripts/cinematic_player_check.py --linked
.venv/bin/python scripts/guided_player_check.py --hero Tiga --tempo-skills \
  --gesture-wobble --gesture-entry-noise --output artifacts/ranged-cast-20261009/guided-tiga \
  --log logs/guided-ranged-cast-tiga.log
.venv/bin/python scripts/guided_player_check.py --hero Zero --tempo-skills \
  --gesture-wobble --gesture-entry-noise --output artifacts/ranged-cast-20261009/guided-zero \
  --log logs/guided-ranged-cast-zero.log
.venv/bin/python scripts/encode_ranged_cast_review.py
```
