# 重击与废墟构件掉落（2026-09-30）

参考街机录屏中的碎块和巨大角色互动，以及当前战斗画面，脚下已有烟尘与石块，但两侧建筑在所有攻击中完全静止。本轮让实际建筑轮廓中的松动部分响应地面接触，补足角色与场景之间的受力关系。

## 表现和事件

两处废弃楼房共 18 个外侧楼板、窗楣构件可脱落。普通重踏和撤步使尚未脱落的构件短暂震动；砸地、上挑后的落地、英雄倒地和怪兽倒地，会从每栋建筑选择一块高处松动构件。震动按接触点到建筑的距离延迟到达，构件先晃动，再翻转下落。落地时扬尘，并用 0.24 秒翻平到地面；留下的碎片及缺口保留到本局结束。

反应由现有 `GroundImpact` 的真实地面接触事件触发，因此不依赖相机距离、屏幕闪光或每帧轮询猜测攻击时刻。同一接触只触发一次。游戏暂停和大招专属镜头时冻结碎片时钟，新局与演出复位恢复原始建筑。没有改动血量、动作识别、角色动画、攻击时机或原有音效。

构件合并成一组固定动态网格，432 个顶点与法线、切线数组逐帧复用；16 个尘团复用 `GroundDust` 材质。没有添加 Rigidbody 或随战斗不断创建对象。下落轨迹使用解析运动，首次接地检查旋转后每个顶点与实际地形的间隙；落地翻平时继续贴合地形。法线和切线跟随旋转，裁剪包围盒留有小幅余量。原来的五组静态基地网格保留，其余道路、车辆、钢架及储罐不参与此次破坏。

## 实际安装包

macOS 构建与本地签名通过。原有检查通过 36 项 Python、397 项核心和包含通信的 400 项集成检查。通信检查首次受到沙盒回环端口限制，在允许本机端口的环境中运行通过。

完整打包版回放耗时 97.13 秒，完成 32 次普攻、2 次必杀、3 次格挡、1 次受击、怪兽砸地、怪兽光线、暂停和胜利。12 次地面接触与 12 次废墟响应的类型及顺序一一对应，其中 5 次强冲击安排了 10 块构件脱落。实际截图记录了尘团与后续保留的破损，位于 `artifacts/cinematic-combat/player/20260929T214829115517Z/native`。

同一安装包完成 138.1 秒无键鼠引导流程：自动拍照 2 次、重拍、照片流和预览姿势流短暂中断恢复、举手续局均通过。98 帧防御干扰包含 45 帧对侧手腕遮挡，另有 15 帧大招姿势干扰，受保护期间误触普攻为 0，格挡和大招各成功 2 次。预览与导出照片的中央区域像素一致。输入是合成姿势和 TEST 人像，没有调用真人摄像头或外部 AI。

## 复现

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.OutpostDamageChecks.Release \
  -quit -logFile "$PWD/logs/outpost-damage-checks.log"
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --output artifacts/outpost-reaction/guided --log logs/outpost-reaction-guided.log
.venv/bin/python scripts/encode_outpost_reaction_review.py
```

`Unity` 替换为本机编辑器路径。旧版 `Before` 必须在基准运行时代码下单独采集，不能用新版重录成“修改前”。

这是预设构件的受力演出，不是整栋建筑的结构物理模拟，也没有验证孩子本人的最新摄像头体验。角色模型细节、更多动作和合照融合仍有差距，不能将本轮当成最终街机目标完成。
