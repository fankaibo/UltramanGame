# 怪兽后撤与落脚（2026-09-28）

本轮针对参考视频里的全身受力感：第 5、10、15 次等连击命中后，哥尔赞随左右拳交替抬脚后撤，落脚承重后收步，身体跟随支撑腿移动。后撤约 0.58 个世界单位，抬脚最高约 0.20，整个过程 0.88 秒。落脚瞬间触发脚边扬尘、轻微镜头震动和低沉脚步声。

后撤属于该次接触；连续普通拳不会把正在抬起的脚直接拉回原位。敌人即将攻击的最后 1.1 秒不触发新后撤，避免覆盖预警动作。大招、攻击和胜利接管时逐渐退出，暂停和新一局清除后撤状态。

同时修正出拳落点：迪迦保留原动画，只在接触附近调整出拳手；另外四位英雄增加普通拳踏步距离，并以哥尔赞胸部表面为目标。步幅限制为 1.10，避免支撑腿超出可达范围而滑脚。另一只手保持原有护手姿势。

## 对照与复现

本机 `artifacts/monster-backstep/index.html` 提供同输入的 7 秒修改前后录像、五英雄左右后撤落脚姿势和实际游戏截图。基准为 `179223cb058e78922774014962709d7a937653a4`。离线录像每侧 210 帧、30 FPS，不代表游戏运行帧率。

1. Unity 执行 `UltramanGame.Editor.MonsterBackstepReview.Release --combo-output <仓库绝对路径>/artifacts/monster-backstep`，渲染后版并验证落脚、接触与中断。
2. Unity 执行 `UltramanGame.Editor.ContactReactionReview.After --contact-output <仓库绝对路径>/artifacts/monster-backstep/contact`，检查普通受击与重复采样。
3. 执行 `bash scripts/build_macos.sh`，再依次执行 `.venv/bin/python scripts/cinematic_player_check.py --hero Tiga` 和 `--hero Mebius`。
4. 执行 `.venv/bin/python scripts/encode_combo_review.py --folder artifacts/monster-backstep --baseline 179223cb058e78922774014962709d7a937653a4 --subject backstep --player <迪迦证据目录> --player <梦比优斯证据目录>`。脚本核对源码、420 条战斗状态和实际程序／资源包摘要。

## 验证范围

五英雄各完成 10 次交替普攻和 2 次后撤落地。迪迦另测 15、30、60 Hz 动画采样；怪兽支撑脚与落稳后的活动脚位移小于 0.0001，脚底网格未穿地，后撤 0.58，最高抬脚 0.197–0.200。普通拳及连击的拳端到胸部顶点距离最大 0.358；测量只接受胸部蒙皮，避免把怪兽手臂误当作命中目标。

15、30、60 Hz 下，快速连打、暂停、新局、大招接管、临近攻击时防御均通过；五英雄连击接护盾及暂停恢复也通过。连续录像中的十拳仍扣 10 点血、充能 10 次。源码和状态记录位于 `artifacts/monster-backstep`，Unity 日志为 `logs/monster-backstep-release.log`。
