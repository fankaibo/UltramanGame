# 格尔赞双爪砸地（2026-09-29）

参考录屏中的连续反击、夸张身体重心和地面碎石，本轮给格尔赞增加一次完整的攻击变化：前两次沿用左右爪前冲，第三次双爪举起、下蹲砸地、碎石向英雄推进，随后起身继续战斗；第六次重复同一变化。

## 行为与画面

- 最后 1.35 秒预警逐渐抬起双爪；语音晚开始而延长预警时，双爪会平滑回到等待姿态。
- 攻击开始后 0.28 秒落爪，6 段碎石和低空尘浪在随后 0.12 秒内由怪兽推进至英雄前方；0.4 秒仍由原有战斗规则决定格挡或受击。
- 砸地使用独立的站姿、双腿支撑和脊柱前倾，不叠加单爪前冲动画。脚腕保持原落点，尾巴保留地面高度；手腕继续使用已有 35° 弯折约束。
- 两侧手爪各有下落拖尾，停用不适合砸地的横向爪痕。护盾接触特效下移，地面接触触发短促震动、暖色补光与碎石声。
- 镜头震动不暂停战斗时钟，避免碎石推进与伤害时刻错位。碎石有真实厚度、重力、两次衰减反弹和淡出；低空尘浪保留上身动作可见性。
- 孩子仍使用同一护盾动作；识别阈值、15 次普攻蓄满大招、默认 50 次普攻血量，以及语音结束后的 3 秒反应时间均未改变。

## 修复的开发期问题

第一版将下蹲叠在原前冲动画上，右小腿蒙皮最低穿地 0.128 个场景单位，虽然脚腕位置正确。改为独立站姿后，完整网格检查最低约为 0。检查覆盖了实际蒙皮顶点，而非只检查骨骼落点。

蓄力时被普攻打断，旧过渡先撤掉抬爪层、再从隐藏的原始姿势混合到受击，造成双手瞬间跳变。现在从画面中真实的抬爪姿势向受击动画混合，并平滑重新进入砸地动作。恢复阶段也不再误回到举爪目标。

## 自动验证

`MonsterSlamReview.Release` 在 15／30／60 Hz 各执行 7 组流程：持续防御、完全不防御、延迟预警语音、蓄力时出拳打断、攻击中暂停、重开、连续反击至第六次。21 组全部通过：

- 每次砸地只产生一次地面接触，持续防御得到 3 次格挡，不防御得到 3 次轻度受击；重复流程有 6 次格挡和 2 次砸地。
- 两脚落点误差小于 0.00002，手腕弯折不超过 35.001°；采样的蒙皮顶点没有明显穿地。
- 同一时刻重复更新的姿态误差小于 0.000002，没有叠加漂移。
- 暂停和重开不残留下蹲位移或待发出的碎石。

另外 3 组特效检查验证第一段 8 个碎石／4 个尘团推进至 48／24、碎石最低顶点保持在地面上、到期消失、对象池大小不变，清除后延迟段不复活。
