# 合照尺寸变化确认（A-20261011-101）

基线 `f78a032`，运行时基线 `fdeb2bd`。针对用户反馈的合照人物忽大忽小，在 A-97 头顶定位及单帧比例限幅基础上修正持续噪声引起的缓慢缩小；迪迦大小、动作识别与战斗规则不变。

## 证据与改动

相同人物取景，仅在遮罩左侧交替加入一块不属于身体的区域，原版 48 帧后人物比例降为初始的 88.4%；每次连续两帧出现的噪声，最大缩小约 9.6%。原因是每一帧异常都进入缩放平滑器，单帧限幅只能减慢缩小，不能阻止积累。

新增 `PhotoScaleTarget`：拟合比例相对已接受目标变化超过 8% 时，需要连续三次目标相互接近（相对第一候选误差不超过 4%），才交给原平滑器。8 Hz 输入下约增加 0.25 秒确认时间。小幅变化直接跟随；无效目标忽略；重拍清空候选。等待确认时同时保持横向锚点，避免宽度噪声把多人构图拉向一侧。仍保留每次投递最大 2.5% 的比例变化和脚底锚定。

## 同输入实际 Unity 渲染

`PhotoMotionReview.Before/After` 各运行七组、每组 48 帧，共各 336 帧。使用合成遮罩与姿态，不读取、上传真人照片；每组只保存第 0／23／47 帧 JPEG 和完整 CSV。
