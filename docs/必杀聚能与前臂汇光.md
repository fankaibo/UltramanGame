# 必杀聚能与前臂汇光（2026-09-29）

根目录的街机录屏在必杀前有明显的能量汇集和释放。旧近景主要在头部附近画三条蓝色椭圆环和一片亮光，遮住脸部细节，也没有清楚的收束过程。此轮重做英雄的蓄力效果，保留已经完成的光线飞行、胸部命中和怪兽反冲。

## 改动

- 24 股短光流沿弯曲路径向胸前双臂汇集；蓝色体积光中逐渐形成亮核，末段收束到实际发射前臂。能量中心下移，避免竖臂姿势把亮核放在脸前。
- 体积光使用三维噪声与深度遮挡，手臂和其他前景物体可以遮住后方能量；细光流具有柔和横截面和渐细尾端。移除原来的三条蓄力圆环，发射时的枪口亮光继续使用原实现。
- 聚能与近景共用时钟，近景回到战场后仍保持，直到光线发射后短暂淡出；暂停、失去追踪和重开会清理能量、补光及音效。
- 新增原创低频聚能循环，音高和音量随能量增强；迪迦原战吼播放时降低底层音量。近景被中断或能量消失时立即停声，避免定时音频在合照或下一局继续播放。
- 五位英雄都从各自实际手部位置采样，角色、动作识别、血量和伤害时序不变。

## 验证与对照

基线提交为 `ed97945f10a59baf7e6a25ab1ceb50d5c9956fbf`。`artifacts/beam-charge/index.html` 提供同步修改前后短片、五位英雄的三个蓄力阶段、实际打包版截图和验证结果。两段均为 4.2 秒、126 帧的离线渲染；30 FPS 是视频编码速率，不是游戏性能测试。两份逐帧战斗记录完全相同，大招均只发射一次、伤害 9 点、正确收势。

五位英雄各检查了 71 帧近景聚能和 16 帧回到战场后的发射衔接；消失、暂停和重开清理通过。迪迦在 15、30、60 Hz 更新下，以及另外四位英雄在 60 Hz 更新下，光线接触与恢复均通过。GPU 检查中相同时间重复渲染差异为 0，前景遮挡泄漏为 0，推进时间后能量图像正确改变。音效循环长度 0.5 秒，样本峰值 0.7321、RMS 0.1589、循环边界差 0.00018。

33 项 Python、324 项 C# 核心检查及包含跨进程通信的 327 项集成检查通过。macOS 构建及本地签名通过，实际应用完成 85.39 秒完整战斗：32 拳、2 次大招、2 次防御、1 次受伤、第三次重踏、暂停和胜利退场。2 次聚能声音启动与停止分别对应 2 次必杀，迪迦原战吼播放两次；没有检测到运行时异常。

同一游戏包通过 138.1 秒无键鼠体感协议回放：98 帧防御深度噪声、11 帧大招深度噪声期间误触普攻为 0，成功防御与必杀各两次。自动拍照两次、重拍、取景和预览断流恢复、举手进入下一局均通过；保存 PNG 与预览中心区域颜色差 P99 为 0。测试使用合成姿态和 TEST 人物，没有保存真人图像或调用合照 AI。

两次实际应用测试的程序集摘要为 `060d3d853c8fc2fb36215ec5abcec771b731cf362a09a98595730f6a8cf2633d`，资源包摘要为 `cf195dab15acd503d144c511f1a009c7178d29949c446b5057ee8bb8e4b376a9`。引导测试前后摘要一致，详见本机 `artifacts/beam-charge/provenance.json`。

## 复现

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.BeamChargeReview.Run \
  --finisher-output "$PWD/artifacts/beam-charge" \
  -quit -logFile "$PWD/logs/beam-charge-review.log"
bash scripts/check.sh
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --output artifacts/beam-charge/guided --log logs/beam-charge-guided.log
```

基线图像必须由基线提交下的 `FinisherReview.Before` 生成并保留；不能用当前代码重新生成“修改前”。编码脚本校验基线 Git 内容、当前渲染源码、完整战斗记录及实际应用资源摘要，避免把旧截图当作新版本证据。引导测试的运行前后程序集与资源摘要另存于 `guided/build.json`，供 `scripts/encode_beam_charge_review.py` 校验。

本轮是必杀表现层的增量改进，尚未达到参考街机的整体模型与动画品质。测试使用合成姿态，不能代替孩子在摄像头前的试玩；真人合照的硬边、光照和身体裁断仍需继续处理，当前 AI 调色不能称为生成式融合。帧率专项继续后置。
