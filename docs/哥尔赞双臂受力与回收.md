# 哥尔赞双臂受力与回收

参考录屏中的怪兽受击会带动四肢，当前游戏原先主要依靠胸部、头部和根节点后仰，双爪经常保留同一个前伸姿势。本轮补上双臂的受力与回收层，沿用现有伤害、命中、蓄能和识别时序。

## 动作

普通左／右拳使相应一侧手臂先向外、向上弹开，另一只手稍后向胸前回收；左右命中交换这两个角色。连击重拳加大幅度，上勾拳则让双臂随腾空抬起，落地后下沉收回。光线命中使用独立的持续承力时钟，两只爪子以不同幅度抬起，光线收束后放下，后续普攻不会把正在持续的动作突然清空。

快速连打从上一次手部偏移继续衔接，旧偏移在 0.18 秒内释放。原有爪击、双爪砸地和头部光线出手时优先使用各自的攻击姿势；暂停、新局、胜利及角色预览退出受击层。

手臂求解保留两节骨长，肘部弯曲方向从原动画逐渐过渡，不在微小位移开始时突然切换。手掌随前臂旋转并继续沿用 35 度腕部约束。每次采样前移除上一帧附加姿势，防止暂停或重复渲染累积扭曲。没有修改源模型的手掌几何或贴图。

## 对照证据

基线为 `76df31bbbd6c4fb7cdf032b046a756a6eeadb34f`。左拳、右拳、上勾拳、光线各 4 秒，两侧共用相同输入；每组 240 个战斗状态逐字节一致。哥尔赞根节点、双脚及胸口命中点的逐帧位置差均为 0，变化仅来自双臂。

普通拳的最大手腕位置变化约 0.44 个场景单位，上勾拳约 0.53，光线约 0.50。新动作在 15／30／60 Hz 逻辑步长下均完成命中及回收；最大手腕弯曲约 35.0003 度，骨长误差小于 0.000002，重复零时间采样位置误差小于 0.000002。

额外 12 组骨骼回放覆盖原有怪兽爪击、连续普攻及必杀、暂停恢复和新局切换，全部通过。`scripts/check.sh` 通过 36 项 Python、355 项 C# 核心及包含跨进程协议的 358 项集成检查。

macOS 构建与本地开发签名通过。实际打包版 97.11 秒完成 32 次普攻、2 次大招、3 次格挡、1 次倒地、暂停恢复与胜利；四种双爪受击截图均取自该次运行，同时保留连续拳、砸地、头部光线和必杀反应镜头的既有检查。

同一构建又完成 140.2 秒无键鼠体感协议回放：96 帧防御噪声、11 帧大招噪声期间误触普攻为 0，防御和大招各成功 2 次；自动合照两次、重拍、照片流／姿势流中断恢复、举手续局并重新进入战斗均通过。预览和保存照片中心区域颜色差 P99 为 0。使用合成 TEST 人像，没有开启真人摄像头或调用联网合照 AI。

程序集 SHA-256 为 `46536539f1239ea64978bf8eb096ceb136ea9e1b7bd73755c72489a70298c393`，资源 SHA-256 为 `804335bea41031d66d5b5fa997e068d82586891d6a5ac1d053ab551e365f3403`。对照生成程序核对这两个摘要与完整战斗、合照回放前后记录一致。

## 复现

先在基线运行 `ClawReactionReview.Before`，保留 `before` 目录，然后在当前代码运行：

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ClawReactionReview.After \
  -quit -logFile "$PWD/logs/claw-reaction-after.log"
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ClawPoseReview.Stability \
  --claw-output "$PWD/artifacts/claw-reaction/stability" \
  -quit -logFile "$PWD/logs/claw-reaction-stability.log"
bash scripts/check.sh
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --output artifacts/claw-reaction/guided --log logs/claw-reaction-guided.log
.venv/bin/python scripts/encode_claw_reaction_review.py
```

这些检查不能代替孩子的真实摄像头体验。源模型的手掌轮廓与贴图精度仍限制近景，完整角色动作和画面层次尚未达到参考街机效果；本轮不把受力层改进宣称为完成了全部美术目标。
