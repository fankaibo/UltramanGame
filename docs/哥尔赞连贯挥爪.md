# 哥尔赞连贯挥爪与手部切换

改动 A-20261009-56；实现 `ad530bc`；2026-10-09。此前版本为 `7cfac78`，总体任务与进度见 [开发任务看板](开发任务看板.md)。

## 画面与原因

复看本机街机录屏及上一轮发行画面，主攻爪仍接近向前推掌。新轨迹从身体侧后蓄力，斜向扫过身前，再沿低弧线收回；支撑手在胸前随动作折起。前冲使用短加速、均匀接近和短减速，将远站位的距离分散到整个接近过程，仍在原来的 0.4 秒命中。

检查还发现，增加投石、砸地和光线之后，第五次左爪攻击的准备仍按奇偶数选择右手，攻击才使用左手。准备动画和转肩现在与 `MonsterStepMotion.ClawLeft` 共用选手逻辑。旧左爪准备时比另一只手低约 0.442 个场景单位，新版高约 0.480；右爪也保持同侧准备。

手部切换过去在撤销程序化姿势后读取位置，投石从蓄力转攻击时会短暂跳到待机手位。现在提前保存画面实际显示的双手位置和朝向；语音延长投石预警时，持石手臂也逐渐回落。腕部 35° 约束和已有起身膝盖修复保留。

## 复现

```bash
UNITY='/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity'
# Before 采用 7cfac78 的 Runtime 与本次 ClawArcReview；保存基线后恢复新 Runtime。
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ClawArcReview.Release -quit \
  -logFile "$PWD/logs/claw-arc-final.log" \
  --claw-output "$PWD/artifacts/claw-arc-20261009/stability"
cp artifacts/monster-anticipation/flow-validation.txt artifacts/claw-arc-20261009/anticipation.txt
bash scripts/check.sh
bash scripts/build_macos.sh --release
.venv/bin/python scripts/cinematic_player_check.py --ray --linked
# 将 player-validation.json 保存到 claw-arc-20261009/native/，与本次发行包绑定。
.venv/bin/python scripts/guided_player_check.py --hero Tiga --tempo-skills \
  --gesture-wobble --gesture-entry-noise --output artifacts/claw-arc-20261009/guided \
  --log logs/guided-claw-arc.log
.venv/bin/python scripts/encode_claw_arc_review.py
```
