# 高位收拳与连击镜头（A-20261012-136）

基线 `a5c6e9f`，2026-10-12。上一用户问答仅解释既有高位识别修正，本轮继续改善实际战斗演出，整体街机验收不变。

## 原因与行为

A-127 已解决高位出拳被高度门槛过滤的问题，但镜头测试仍主要用出招间无防御的输入。`RangedCameraMotion` 原来把任何 `Shield` 都当作退出连击镜头的理由；孩子收手保持脸旁防御时，每一拳都重新开始小幅推进，无法保持连续中景。

新增同输入基线：五次左右远程出招，每次间隔 1.2 秒，间隙持续防御。15／30／60 Hz 的旧版角色尺度仅达到普通构图的 1.014 倍，连击焦点最低 0；新回归首先在旧代码上失败。

现在敌人休息／恢复期间的短暂防御保留既有连击镜头，不再清空出招计数。停止出招后自动回远景；敌人预警／进攻、近战、受击、必杀、暂停、追踪失效和新局继续优先。未改骨骼检测、动作分类、防御状态、命中或能量规则。

首候选保留原 1.45 秒等待窗口，在 1.6 秒慢出拳时仍失败：防御会提前结束收招，镜头少获得一段收招等待。最终窗口为 1.70 秒；对应完整收镜测试从 3 秒观察扩至 4 秒，持续防御的旧“立刻退出镜头”断言更新为“立即防御、过期收镜”，新增怪兽预警中持盾仍退出的用例。测试调整对应明确的视觉行为变化，没有改防御生效时间。
