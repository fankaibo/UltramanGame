# 真人失衡、倒地与起身（A-20261010-78）

在 A-77 `530e566` 的自然前伸与准备动作跟随上继续改进。原受击前半段靠程序把双腿和躯干摆向地面，本次接入真人失去支撑、伸腿、后仰和落地的连续动作，之后衔接 A-73 已有起身。不是新增伤害或姿态识别。

## 数据、转换与限制

CMU subject 90 / trial 18（RugPullFall），Bruce Hahne 2010 BVH 转换版，镜像为 `github.com/una-dinosauria/cmu-mocap`。原始文件已在本机 `.cache/mocap-cmu/90_18.bvh`；SHA-256 `32a6bcf85820af466fb141f7e05a7131fbb7d0b76a4f7d407379c6f9457cac10`。沿用取得素材时的来源及使用说明；本轮重访 CMU 页面超时／502，没有把失败请求当作新的授权核验。

取第 50–185 帧，排除第 0 帧的校准姿势；120 Hz 原数据按两帧采样并保留末帧，共 69 个样本、1.125 秒。跌倒以站立首帧为位置／朝向锚点；原起身仍以末帧站立为锚点。五套角色专用衍生数据总计 499,572 字节，来源与逐文件哈希见 `Resources/Motions/Fall/manifest.json` 和 `ATTRIBUTION.txt`。原始 BVH 未作为公共数据集重新分发，角色模型的来源要求不变。

修正了源骨架两处共点节点：`Hips/LowerBack`、`Spine1/Neck` 的位置可以相同，不能把零方向当成躯干朝向。现在查找下一段有效方向，避免迪迦倒下后胸口仍竖起。短小但有效的模型骨骼仍保留真实方向，并对零方向和短骨段加入审查。

跌倒时鞋底不再强制保持水平；按源脚掌和小腿计算脚部朝向，再以实际蒙皮鞋底校正倾斜脚跟／脚尖高度。骨骼权重索引只在离线审查初始化时计算，运行时只读取烘焙数据，不逐帧遍历网格。数据不包含真实手指动作，不宣称等同影视动作库。

## 接入时序

- 真人跌倒在受击后 0.10 秒内接管，约 0.68 秒完成；落地 cue 从 0.30 秒改为 0.40 秒，与臀背下落时刻同步。
- 0.62–1.02 秒从倒地逐步过渡至已有起身，保证两套动作重叠期间不露出底下的程序姿势。
- 受击恢复总时长从 2.55 秒延至 2.97 秒。站稳后仍立即允许防御与下一次出拳；倒地期间不能得分，落地只发一次。
- 两层动作按相反顺序恢复底层骨骼，覆盖暂停、追踪丢失、再开一局；按键和体感共用相同动画。起身数据文件沿用此前已发行版本，没有悄悄重烘焙。

## 证据

本机 `artifacts/mocap-fall-20261010/index.html` / `fall-comparison.mp4`：同一受击起点，左为此前程序倒地，右为真人跌倒，均是实际 Unity 模型渲染；各 120 帧，4 秒、30 FPS。左右保留不同恢复时长，编码帧率不代表实机帧率。

五英雄离线烘焙各 69 帧；最低蒙皮 Y 约 0.00198–0.00200，脚目标误差低于日志精度。源／目标躯干方向最小余弦 0.988–1.000，确认实际身体随源动作倒下。15/30/60 Hz 运行时均通过，零时间重复采样误差为 0；五英雄在失衡、落地及衔接阶段的 15 组暂停／恢复防御／反击／新局边界通过。捷德在受击最初约 0.04 秒的过渡仍有约 -0.0144 的脚尖最低点，处于既有 -0.05 容差内；没有宣称全部过渡帧完全消除穿地。

46 项 Python 与 1253 项核心及桥接检查通过。由于受击时长改变，不宣称前后逐帧玩法轨迹相同；默认 50 血量、15 拳蓄能和姿势识别没有改变。

初版、诊断和失败证据保留：`initial-sequence/`（上身映射／脚尖问题）、`zero-segment-diagnostic/`、`short-reference-diagnostic/`（短骨段误拒绝）；`uncached-boots-interrupted/` 为经进程确认后主动停止的低效离线查询，随后改成缓存静态权重。该过程没有因观察超时重启任务。最终离线数据为 `baked-sequence/`、首轮运行时 `runtime-first/`、回退时钟修改前 `before-fallback-clock/`，最终时钟复核及对照 `after/`。两次 CSV 未逐字节相同，逐字段复核仅有不超过 0.000002 的骨骼／地面浮点差异，时序字段相同；报告保存在 `fallback-clock-comparison.json`，最终视频已使用修改后的全部帧重新编码。

`1a3e072` 已完成 Release 构建及本地签名。实际 1080P 按键回放 96.89 秒通过，32 普攻、2 必杀、1 格挡、1 受击、暂停与胜利；失衡、背部落地、倒地停留、起身，以及延迟暂停后的自然前伸手位已目视复核。本机证据 `artifacts/cinematic-combat/player/20261009T235006177380Z/`。该轮 Unity 计时日志出现超过 1000 秒的跳变，与外部进程总耗时不符，因此 0.1 / 0.3 的 FPS 聚合不能用作有效性能验收；原始日志保留，性能专项仍后置。同包 178.3 秒合成体感回放通过：32 次远程命中、4 次格挡、2 次必杀；左右手准备跟随、自动合照 2 次、重拍、断流恢复、重新选择梦比优斯并进入下一局均通过。持姿误出拳、键鼠操作和真人照片均为 0；预览 p99 误差 0。源码、动作资产、最终对照与两次实际回放由 `artifacts/mocap-fall-20261010/release-identity.json` 绑定。
