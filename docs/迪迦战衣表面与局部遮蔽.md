# 迪迦战衣表面与局部遮蔽（2026-09-29）

当前角色近景中的红紫战衣几乎由纯色贴图组成。即使场景灯光和反射已经存在，纯红与高饱和蓝紫仍显得像塑料；身体凹处也缺少局部环境遮蔽。这一轮保持原模型、动作和图案分界，改进迪迦身体的材质反应。

## 实现

- 原 `TigaBody.png` 继续决定图案位置；着色器只给 `TigaSuit` 启用红紫染色与银色涂层的表面参数。胸甲、头盔、眼睛、计时器及另外四位英雄不启用这组染色。
- 将原来的高饱和纯色映射为较柔和的红和紫，按实际渲染色彩空间转换后参与照明。银色图案仍有独立金属度与高光，不把整件战衣改成金属。
- 增加附着于原 UV 的细微织纹法线和粗糙度变化；屏幕导数在纹理小于像素时淡出织纹，避免远景高频纹理闪烁。它不使用时间或世界位置，因此不会在动画中穿过身体。
- 从作者原模型的静止网格烘焙 `TigaBodyOcclusion.png`，2K、线性数据、带 mipmap。局部遮蔽只影响环境照明，不在皮肤上添加静止的方向性投影。使用同一个模型自身的短距离遮挡，避免把当前手臂姿势的远距离影子烘焙进躯干。
- 遮蔽烘焙保留原始 UV。BODY 写入目标图；装甲使用独立的临时输出，避免不同材质重叠的 UV 覆盖战衣数据。源文件、原彩色贴图、FBX 和动画均未改写。

烘焙用到 Blender 的 Only Local 环境遮蔽节点；其定义为只检测对象自身的遮挡，见 [Blender 官方说明](https://developer.blender.org/docs/release_notes/2.80/cycles/)。烘焙脚本关闭下载文件中的内嵌脚本，派生贴图沿用源模型的署名和非商业限制。
