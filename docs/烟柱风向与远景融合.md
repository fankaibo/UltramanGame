# 烟柱风向与远景融合（A-20261011-116）

源码基线 `a654207`。上轮已完成本机／GitHub 同步及两项 CI。复看参考录屏和当前实际包，背景效果应支持人物动作；现有两根明亮直立烟柱在夜间画面中过于突出。本轮保留火山场景，改善烟团随高度向同一风向偏移、上部稀释和冷灰明暗。

## 实现

- 低处热烟仍从原喷口升起，越高的烟团越向侧面偏移，两个喷口共用风向，各自涡流错位保留。
- 将体积容器横向从 3.8 扩到 6，密度坐标与半径同步补偿，原喷口位置和物理烟团宽度不因容器变宽而放大。纹理噪声与短程自遮光采样也按原世界尺度计算。
- 上部逐渐变薄，亮部改为更暗的冷灰，底部熔岩热光保持。仍为 36 个步进、每次密度计算三次缓存纹理采样；没有增加烟团数量。
- 不改角色、手势、英雄选择、战斗时钟、伤害、防御和合照规则。
