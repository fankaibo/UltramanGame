# 迪迦受击倒地姿态迭代

增量：A-20261015-147  
日期：2026-10-15  
范围：迪迦主线的未防御受击演出；不改变伤害、倒地时钟、输入锁定或起身规则。

## 问题

发行回放的 `hero-fall-unbalanced.png` 仍呈现“坐着滑行”：倒地捕捉片段把根节点压低，双腿同时朝镜头伸展，45° 战斗镜头下看不出失去支撑的方向。

## 实现

- 倒地阶段改由 `RiggedActor.PoseKnockdown` 负责：髋部向后并向一侧下沉，根节点以较缓的后仰配合更明显的肩侧滚转。
- 两条腿使用不同目标：一条向冲击方向伸展，另一条留在髋部下方作为折叠支撑，避免两腿同时抬起或伸直。
- 撑地手更接近地面并提前参与承重，另一只手留在胸前平衡；脚底仍以地面高度约束。
- `CapturedRecoveryPose` 继续用于起身捕捉，但停用当前不适配迪迦网格的 CMU 倒地根节点和双腿片段，避免恢复前出现穿地或坐滑；现有 `Resources/Motions/Fall/Tiga.bytes` 保留作为可追溯回退素材。
