# 格力乔射线与腕部交叉

改动 A-20261009-62；运行时 `335f5f0`，对照基线 `92f36f8`，2026-10-09。整体进度见 [开发任务看板](开发任务看板.md)。

## 官方依据

万代[格力乔官方商品页](https://tamashiiweb.com/item/14006/)与[官方介绍](https://tamashiiweb.com/topics/detail/tn_blog_8.html)明确标注 Grigio Shot；[说明书](https://tamashiiweb.com/storage/images/products/imported/item_0000014006_blfj7JDB_300.pdf)第二页展示右手竖直、左手横向放在右腕后方，从右手发射的姿势。[官方音声表](https://toy.bandai.co.jp/manuals/files/2727340.pdf)第 14 页将 Grigio Cheer Charge 和 Grigio Shot 分别列出。

圆谷角色页列出的 Cheer Charge 不能直接当作游戏伤害光线。该轮更正 A-20261003-29 的错误归类，攻击必杀统一显示“格力乔射线 / Grigio Shot / グリージョショット”。中文是项目中的对应译名；不把它宣称为经核实的官方中文本地化。官方图仅留本机参考，不作为游戏素材或提交到仓库。

## 动作处理

旧版使用通用 L 形动画，右手抬得过高。新动作双臂环形聚能后交叉于手腕，从右掌边缘发射并回到待机；环形过渡为游戏制作，不声称逐帧复刻原剧。沿用现有玫红色光线，聚能体积、丝线和局部照明统一配色，颜色不是从黑白说明书采样而来。

格力乔每只手只有两根中指驱动骨骼，不是梦比优斯的完整五指骨架。手掌朝向从原绑定网格的薄面标定，手指恢复到绑定姿势；动作层不改变原臂长。角色精度仍受低分辨率源贴图限制，本轮未替换模型。

## 复现

```bash
UNITY='/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity'
# before/ 由旧运行时生成，不要用新代码覆盖旧证据。
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.GrigioShotReview.After -quit \
  -logFile "$PWD/logs/grigio-shot-palms.log"
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.FinisherReview.After \
  --finisher-output "$PWD/artifacts/grigio-shot-20261009/beam-regression" \
  -quit -logFile "$PWD/logs/grigio-shot-regression.log"
bash scripts/check.sh
bash scripts/build_macos.sh --release
.venv/bin/python scripts/cinematic_player_check.py --hero Grigio --linked
mkdir -p artifacts/grigio-shot-20261009/native
cp artifacts/cinematic-combat/player-validation.json artifacts/grigio-shot-20261009/native/player-validation.json
.venv/bin/python scripts/guided_player_check.py --hero Grigio --tempo-skills \
  --gesture-wobble --gesture-entry-noise --output artifacts/grigio-shot-20261009/guided \
  --log logs/guided-grigio-shot.log
.venv/bin/python scripts/encode_grigio_shot_review.py
```

`front-*` 是审查骨骼的临时正面取景，会露出背景板边缘，不代表实际游戏镜头；`stage-*`、连续序列与实际播放器帧使用真实游戏镜头。孩子仍用已有的大招手势，规则和原声回退不变。格力乔本人原声、精细贴图、真人摄像头和小米电视体验仍未完成；总体进度保持 70.2%。
