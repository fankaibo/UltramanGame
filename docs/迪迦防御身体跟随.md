# 迪迦防御身体跟随（A-20261019-182）

基线 `1c418c7`。A-160 已让远程出招保留身体倾斜，但防御仍会清零身体输入并关闭跟随层。持续高位防御时角色会回正，解除防御后又开始跟随；这是本轮要修正的动作衔接缺口。

## 改动

只对迪迦，正式防御期间继续读取肩部斜度和肩胯相对侧倾，使用与准备／远程出招相同的有界幅度和滤波。正式防御手臂仍由原防御动画控制，关闭双手实时偏移；脚底位置保持，以腿部求解承接躯干重量。受击、必杀、暂停、新局及关闭体感保持原接管规则。

不改变防御／普攻／必杀识别门槛、持续时间、伤害或输入优先级，不增加手势选英雄。其他英雄保留原身体行为。

- 15／30／60 Hz 共 945 行战斗状态完全一致：一格挡、一反击、零受伤；每版 270 帧连续画面。
- 旧版持续防御时相对平直输入的平均头部侧移为 0；新版约 0.141 场景单位，证明防御期间不再关闭身体跟随。该数值不是准确率或整体自然度评分。
- 与平直输入相比脚底误差最大约 0.000001，蒙皮最低点约 -0.001，零时间重采样位移为 0。60 Hz 最大头部帧间变化约 0.095，未因恢复身体跟随新增大跳动。
- 五英雄 × 三帧率，覆盖左右手、快慢、发射前后防御接管、暂停、新局及远程转近战防御的 15 组检查通过。
- 新增 36 项核心检查，覆盖防御手位归属、尺度归一化、左右倾身、缺失胯部、过期帧、反击、暂停、新局与非迪迦保留行为。58 Python／2447 检查通过。
