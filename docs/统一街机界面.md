# 统一街机界面（2026-09-27）

根目录参考录屏的主要信息集中在边缘，角色、命中和前冲占据中央。此前体感已经使用这套布局，但按键模式仍走另一套训练界面：顶部通栏、底部三张动作卡和胜利面板重新遮住了角色，切换输入方式时也会更换整套画面。

本轮让两种输入方式都使用 `DrawArcadeHud`，移除不再使用的训练页绘制代码。双方头像、能量、血量、连击、评分、必杀字幕和胜利星级保持相同；分数条从正中移到左侧头像下方，避免遮挡哥尔赞前倾的脸。

## 提示和操作

- 按键模式的底部指令按阶段显示 A/D 出拳、按住 S 防御、按 J 必杀；胜利后提示 R 再玩，有合照服务时另有 F7 合照入口，不再提示一个不会自动打开的合照环节。
- 暂停和重开按钮位于右下角；左下角保留设置和双向模式切换，F2 仍在设置和合照内处理。角色展示继续使用 F5。
- 体感继续显示身体动作引导与实时取景。取景窗补回“收起”和“显示取景 · F3”，与 `showPreview` 状态一致；此前 F3 停止更新取景后，街机页仍会画出空取景框。
- 倒地与起身时暂时收起底部动作引导，恢复后按当前阶段继续提示。相机断流时明确提示进度保留，避免要求已经在镜头前的人反复站回去。
- 怪兽警示按实际阶段显示“怪兽正在蓄力”或“怪兽冲过来了！”，已展开护盾时提示继续保持。

这些改动不改变识别门槛、战斗规则、相机路径、角色动画、特效、语音或引导后的 3 秒准备时间。帧率专项继续后置。

## 本机验证

`logs/arcade-hud-controls.log` 记录了实际窗口操作：空格变身、A 命中一次、F2 切到体感再切回按键，在 F4 设置内再次往返切换；四次模式切换均保留 49/50 血量、1/15 能量和迪迦。返回战斗、Esc 暂停和 R 重开已在界面确认，重开记录回到 50 血量、0 能量。F3 收起后只剩“显示取景”入口，再按 F3 恢复取景框。

实际界面由电脑控制工具观察。自动鼠标点击暂停未触发 Unity 的按钮事件，本轮不将鼠标点击记为通过；同一入口对应的 Esc 操作已验证。没有打开真实摄像头或修改持久设置。

首遍完整攻防完成了 32 次普攻、2 次光线、格挡、受击、暂停和胜利，但 `scripts/cinematic_player_check.py` 因缺少 `monster-rush-right.png` 判定失败。原因是右爪接触与英雄受击可发生在同一帧，截图选择优先记录受击，漏掉爪击；`GuidedProof` 现优先保存接触窗口的爪击，再记录后续倒地阶段。该调整仅作用于显式启用的开发取证，不更改游戏时序，也没有删除检查项。失败证据保留在 `artifacts/cinematic-combat/player/20260926T234143713135Z`。

`logs/arcade-hud-check.log`：33 项 Python、300 项 C# 及额外回环通信检查通过。`logs/arcade-hud-build-release.log`：最终 macOS 构建与本地签名通过。

最终构建 `artifacts/cinematic-combat/player/20260927T000327289951Z/validation.json` 在 1920×1080 下完成完整攻防，121.88 秒、32 次普攻、2 次光线、2 次防御、1 次受击、暂停恢复和胜利均通过，29 张必需与阶段截图齐全。程序集 SHA-256 为 `15bbd9dfe022cca302d4294f403c56856f28aac18ee4e34a65dad50bc6f6d4a6`。已逐图检查普攻、大招就绪和胜利庆祝中的边缘布局、按键提示及重开入口。

同一构建 `artifacts/arcade-hud-guided-release/guided-validation.json` 在 164.5 秒内完成两张自动合照、定格预览、重拍、拍照和预览断流恢复，以及举手续局进入第二局战斗。键鼠事件为 0，真实人像保存为 0；两张 TEST 照片归档在对应证据目录。已查看定格预览及合照后第二局截图，体感引导流程保持可用。

## 画面对照范围

修改前截图保存于 `artifacts/arcade-hud/before`，来自 `357578f` 的实际玩家运行 `20260926T230127565198Z`；`sources.json` 保存原验证记录和源码摘要。对照应比较信息布局和角色遮挡，不把两个独立实时运行的动作时刻视为严格逐帧相同。

本机离线页面 `artifacts/arcade-hud/index.html` 可切换普攻、防御提示、倒地、必杀就绪、光线命中、胜利庆祝六个阶段，并排查看修改前后原始 1920×1080 截图。新版截图与源码摘要位于 `artifacts/arcade-hud/after`。

角色源素材及动作丰富度仍与参考街机有差距。这轮消除了输入模式间的视觉落差，并减少界面对战斗主体的遮挡，没有宣称完成全部街机演出目标。
