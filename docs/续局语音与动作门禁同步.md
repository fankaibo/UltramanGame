# 续局语音与动作门禁同步

任务 A-20261018-159；基线 `d1a9ea4`。承接 A-157 的放手确认与 A-158 的高位出招，聚焦第一条整局引导主线。

## 问题

A-157 已将合照后的等待画面分为“先放手”和“再举手”，但 `Restart()` 与等待重试仍直接播放 `arcade_ready`：“把双手举高”。这与仍需先放手的识别门禁冲突。基线的相关源码保留在 `artifacts/a159-replay-voice/before-restart.cs.txt`。

## 改动

- 尚未完成放手确认时，播放“先把双手放到胸前，停一下”。完成后立即切换为“准备好了！把双手举高，再出发”。首次开局保留原有欢迎语。
- 语音依据真实 `TransformNeedsRelease` 状态，和现有画面使用同一门禁；没有新增手势选英雄，没有改变放手／举手或战斗识别阈值。
- 状态变化会取消已过时的等待语音及排队语音。角色介绍和战斗音效不受这个定向取消影响；等待引导不占用战斗反应时钟。
- 体感／按键切换后按实际门禁重新提示。暂停、角色展示及音乐选择时不追加等待提示。
- 两段新语音使用已选定的“热血青年英雄”合成参考和本机模型生成；没有仿冒新演员原声，也没有上传音频。独立本地 ASR 转写与台词一致，音频与清单哈希随源码提交。
