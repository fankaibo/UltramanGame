# 合照续局与喷发复核（2026-09-17）

## 已定位并修复

1. 合照放手后，旧 `PhotoChoiceGesture` 会因超过 250 毫秒的帧间隔清除放手记录。孩子在语音期间重新举高手后，即使一直保持姿势，也可能无法续局。现在同一识别流内的短暂中断保留已确认的放手记录，清零举手保持时间；超过 1 秒断流、时间倒退或识别流更换仍要求重新放手。只改变合照选择，战斗识别阈值未改。
2. 实际玩家截图发现右上角姿势参考小窗遮住合照人物的脸和手臂。窗口已移入既有底部引导栏，并为主提示文字留出横向空间；仍属于 HUD，不会写入保存照片。新玩家截图 `artifacts/photo-release-final/native/photo-Framing-live.png` 已确认人物头部和举起的手臂无遮挡，参考窗位于底栏右侧。
3. 加强火山烟尘密度并降低地面熔岩缝的线条亮度与宽度。此前玩家包的新截图确认喷发主要表现为烟尘、火光及熔岩颗粒。

## 合照渲染优化（待新构建验收）

- 代码检查发现：合照全屏显示时，主战斗相机仍渲染被覆盖的角色、场景、阴影和后处理。现在在 `LateUpdate` 根据合照是否打开禁用／恢复主相机；合照离开后的同一帧恢复战斗相机，不改变战斗或手势逻辑。
- 合照抠像约每秒更新 8 次，原来同一张合照仍每帧重新渲染到 1080P／2K 纹理。现在只在人像、可见性或画面内容改变时更新预览；导出照片、背景底片和人物蒙版仍强制重新绘制，辅助导出后恢复的图层也会使预览失效并重新绘制。
