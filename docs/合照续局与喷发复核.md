# 合照续局、渲染与喷发复核（2026-09-17）

功能版本 `075bd55` 已提交并推送到 `codex/guided-arcade`。该版本的 macOS 包构建、临时签名、完整无键鼠合成流程和独立战斗回放均通过。这里的通过只覆盖下列验收项目，整体画面仍未达到参考街机的最终目标。

## 改动及验证

- **合照举手续局**：超过 250 毫秒的短暂帧间隔不再抹掉已确认的放手记录；缺失时间不计入举手保持时间。超过 1 秒断流、时间倒退或识别流更换仍要求重新放手。战斗识别阈值未改。
- **合照取景**：姿势参考窗从右上移到底栏，不再盖住人物脸和举起的手臂。玩家截图 `artifacts/photo-render-final/native/photo-Framing-live.png` 已检查。参考窗属于 HUD，不进入导出照片。
- **合照渲染**：全屏合照期间暂停主战斗相机，复用两次抠像更新之间的合成纹理；离开合照后恢复战场相机。照片、AI 底片和蒙版导出仍强制重新绘制，并在恢复图层后使预览失效。已检查 `battle-entry-after-photo.png`，新一局场景、双方角色、HUD 和预览均正常显示。
- **英雄比例**：构建中的全身／半身两项比例检查通过，英雄位置、缩放和裁切固定，只调整人物。合成流程导出两张 1920×1080 照片，先保存到 Downloads，测试完成后移入忽略目录。此次没有拍摄真实儿童或调用合照 AI。
- **火山表现**：提高烟尘密度，降低地面熔岩缝的亮度与宽度。左右爪的截图改在接触时刻分别采集，便于检查手臂与护盾接触；本轮未替换怪兽模型或新增骨骼动画。

## 保留的失败证据

- 修复前的流程分别在战斗、第二次合照举手续局时超时：`logs/eruption-polish-guided.log`、`logs/eruption-polish-guided-retry.log`。
- 首次修复后验证在第二次拍照倒数时多次因图像流过期重置，240 秒超时：`logs/photo-release-final-guided.log`。图像处理一度耗时 6402 毫秒，同期 1 分钟系统负载为 58.30；不能确认具体负载来源，也不能只凭之后成功将原因全部归于渲染优化。
- 构建、签名、测试和提交曾多次被自动审批服务以容量不足拒绝。之后成功执行了对应操作；拒绝期间未启动的测试不计入通过次数。
