# 火山烟团层次（A-20261011-91）

基线 `c736531`，优先迪迦＋哥尔赞。复看参考机台与当前发行画面，当前火山烟柱在普通镜头中呈连续光滑灰柱。本轮改善灰烬烟团的翻卷与受光层次；没有修改动作识别、战斗时钟、血量、能量或镜头规则。

## 实现与可见变化

- 上升烟团增大横向错位、减少竖向重叠，半径变化更明显，避免整列连成粗管。
- 密度原有的 0.55 最低值会填平内部空隙；现在允许局部侵蚀形成较薄的透光区域，并收窄烟团边界的过渡。
- 调整灰烬的冷色受光与暗面，保留底部热光。仍使用每次密度计算三次缓存纹理采样、36 个步进，没有增加体积渲染采样数。
- `VolcanoStageReview` 支持 `--review-jpeg`，旧默认 PNG 保持；新序列在编码后只保留代表帧。

## 验证和限制

- 基线与后版各 240 张普通战斗帧、120 张喷口近景帧，480 个玩法采样逐字节相同。渲染源哈希核对通过：基线运行时来自 `c736531`，编辑器仅新增输出格式选项。
- 已查看同镜头前后烟柱近景与战斗截图。前景遮挡泄漏像素 0、冻结时钟图像一致、烟团缓存循环交界变化像素 1（256×256 画面、RGB 合计变化超过 3 的像素）；动态像素 16964，摄像机进入体积时仍可见。数字只证明动态与遮挡机制，不代表写实质量已经达标。
- 三视角和战斗画面见本机 `artifacts/plume-billows-20261011/`；`battle-comparison.mp4` 为 8 秒、`vent-comparison.mp4` 为 4 秒，均左旧右新。来源与验证记录保留，完整战斗与最终包验证追加在下方。
- 仍是程序体积烟雾，尚不等于影视级流体模拟；整体街机效果、真人孩子和小米电视未验收，不增加 70.2% 总进度。

## 复现

```sh
Unity -batchmode -projectPath unity -executeMethod UltramanGame.Editor.VolcanoStageReview.Before --volcano-output /absolute/path/to/proof --review-jpeg -quit
Unity -batchmode -projectPath unity -executeMethod UltramanGame.Editor.VolcanoStageReview.Release --volcano-output /absolute/path/to/proof --review-jpeg -quit
Unity -batchmode -projectPath unity -executeMethod UltramanGame.Editor.CinematicReview.Render --review-linked --review-jpeg --review-output plume-billows-20261011/full-after -quit
bash scripts/check.sh
bash scripts/build_macos.sh --release
```

基线复现需先使用上述基线运行时源码；`Before` 只是输出目录名，不会自动切换历史代码。日志位于 `logs/plume-billows-*.log`。
