# 捷德机敏型蓝银过渡外观（A-20261015-143）

用户要求优先迭代任务列表第 1 条：捷德改用机敏型观感。当前本地 FBX 仍是 Dandit Truth 红黑变体，且没有经过验证的 Acro Smasher 三维网格，因此本轮没有把旧网格冒充成正确模型，也没有改变骨骼、动作、碰撞或识别规则。

本轮用 `scripts/prepare_geed_acro_palette.py` 从原始 `Geed_Tex_dandittruth.png` 与 `Photo.png` 派生蓝银色材质与选角立绘：红色区域映射为钴蓝，黑色区域提升为冷银／石墨，原始眼灯、UV、透明度和局部明暗保留。`RiggedActor`、`HeroSelection` 与 `HudPainter` 只在捷德加载这两张派生图；其他英雄和原始输入文件不变。派生文件和来源限制记录在 `Characters/Geed/ATTRIBUTION.txt`。

这是一项可回退的**视觉过渡**，不是正确的 Acro Smasher 模型替换：头盔轮廓、网格比例和动作仍来自 Dandit Truth。拿到有许可的机敏型 FBX／GLB／PMX 后，只需替换派生贴图加载和角色资源，再重新做近景、动作与合照验收。
