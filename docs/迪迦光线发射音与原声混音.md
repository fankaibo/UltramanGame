# 迪迦光线发射音与原声混音（A-20261018-165）

基线 `7f3f177`。上一轮强化蓝白聚能，这一轮让发射声与可见光线同步，避免画面已经命中、声音还在慢慢变响。

## 发现与处理

旧 `Audio/beam.wav` 是 1.5 秒渐强音，25 毫秒均方根窗口的峰值在起播后约 0.749 秒。实际光线发射后约 0.17 秒就命中，所以最强的发射声落在命中之后。另一个问题是只要项目里存在迪迦原声，发射音就一直使用 0.4 增益；已确认的战吼长度约 0.888 秒，通常在 1.35 秒特写期间播完，发射时已不需要如此压低。

- 迪迦改用原创合成的短促压力冲击和持续气流能量声，发射即有清楚起音；没有替换或生成角色原声。
- 无语音播放时使用 0.65 发射增益；若当时仍在播语音，则维持 0.4，并继续应用既有 0.42 音效压低。
- 迪迦发射声按当前屏幕中的角色方向做轻度声像定位；怪兽接触音仍按目标位置播放。其他英雄保留原发射样本、增益和居中声像。
- 触发仍来自 `GameWorld.BeamStarted`。没有修改必杀识别、特写时长、动作、伤害或音乐文件。

## 对照与复现

`artifacts/a165-beam-audio/before`／`after` 是 Unity Play Mode 中 `AudioListener` 的实际输出，没有录麦克风。测试建立真实 `Battle`、`GameWorld` 和双方角色，按现有特写／发射／接触时钟播放音频。关闭音乐以单独比较战斗混音；完整发行包流程另行验证。

`old-then-new.wav`：先旧后新，中间 0.7 秒静音，两段均包含战吼、聚能、发射、命中和尾声。播放音量没有分别归一化。首轮记录包含初始化静音，保留于 `before-with-startup-silence`；正式比较在初始化完成后开始记录。

- 事件帧相同：第 12 帧战吼，第 109 帧光线发射，第 119 帧命中。
- 发射样本 25 毫秒 RMS 窗口峰值：0.7492 → 0.0022 秒。该数字描述样本包络，不是设备／电视延迟。
- 最终混音峰值：旧约 0.5323，新约 0.5392；无非有限值或削波。新样本开头、结尾平滑回到零。
- 原声保护、无语音时增益、固定音效通道池、暂停与静音清理、其他英雄样本保留通过。
- 58 Python 测试与累计 2324 核心／通信检查通过；正常源码 Release 构建签名通过。
- 实际发行包高位合成体感全流程 164.2 秒通过：2072 帧普通战斗输入中 0 低手位，32 次左右快慢拳光弹发射／命中、2 次必杀、4 次防御，两次自动合照、重拍、短暂断流和语音续局进入第二局；0 键鼠事件、0 手势选角，两照预览差 0。
- 源码、资源／程序集哈希与签名核对后整包更新 `unity/Builds/TigaTraining.app`，上一版保留于 `TigaTraining-pre-a165.app`；记录见 `build.json`／`promotion.json`。原始混音、试听、日志与原生截图保留。

执行 Unity `UltramanGame.Editor.AudioMixReview.Run --audio-finisher --audio-version before|after --audio-output <目录>`，不要加 `-quit`，录音工具完成后自动退出。基线使用旧运行时代码及本轮兼容反射调用的录音工具。运行 `.venv/bin/python scripts/review_beam_audio.py --folder <目录>` 会核对运行时代码哈希、事件帧、样本包络和最终混音，再导出试听文件。
