- 相机动作触发现有战斗规则，画面播放对应姿势，并叠加呼吸、前冲、回收和受击位移。当前不做逐关节身体跟随。
- 迪迦与哥尔赞沿 45° 对角线站位：迪迦近、哥尔赞远，镜头能看到迪迦背侧和哥尔赞正面。前冲、回收、退场沿两人连线移动；护盾面向对手，光线从前臂位置射向怪兽上身。
- 图集自身绘制背面或正面角度，承载图集的平面保持朝向镜头，场景以城市广场为背景，保留变身与蓄能光圈、光线、护盾和粒子；移除深色训练圆盘及常驻地面装饰。插画由本项目生成，并非官方录像或官方游戏角色素材，也不能像完整三维模型一样任意旋转查看。
- `F5` 进入动作展示；`←`、`→` 或按钮切换姿势，`F5`、`Esc` 返回；展示时暂停战斗，不显示摄像头画面。

## 资源与实现

- [TigaRear45Actions.png](../unity/Assets/Resources/Art/TigaRear45Actions.png)、[GolzaActions.png](../unity/Assets/Resources/Art/GolzaActions.png)：每张图集 4 列、2 行。原正面迪迦图集保留在 Git 历史中。
- 生成方式：内置 image_gen；完整最终提示词与修改提示词见 [角色图集提示词](角色图集提示词.md)。没有使用 CLI/API fallback。
- 首轮生成了画在 RGB 图中的棋盘格，不能当作真实透明图。最终素材使用纯绿色底色，由 `CharacterSprite.shader` 在渲染时消除绿色；源图仍是 RGB。
- `AnimatedActor.cs`：动作选择、时序、位移和图集 UV，不改变伤害或输入判断。
- `CharacterReview.cs`：使用实际游戏的透视镜头、站位、shader 和 16 个姿势，输出 `artifacts/animation-review/pose-0.png` 至 `pose-7.png`；另外通过真实战斗规则进入出拳、护盾和光线状态，输出 `battle-punch.png`、`battle-shield.png`、`battle-beam.png`，检查前冲朝向对手；不读取摄像头。

这是 8 姿势的战斗动画原型，尚不是逐帧手绘的长篇动画，也没有影视级变身演出。造型和动作衔接以实际试玩为准。
