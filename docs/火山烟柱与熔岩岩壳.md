# 火山烟柱与熔岩岩壳（2026-09-28）

本轮优先改善街机场景观感。原来的熔岩是三条细线，烟柱由朝向镜头的平面贴片叠加；现在使用带宽度和冷却岩壳的熔岩沟、实体玄武岩喷口，以及世界空间的体积烟柱。富士山远景、角色站位、战斗和识别规则未改。

熔岩沟顺着地形弯曲，边缘较暗，中间露出缓慢流动的高温裂口；喷口内有熔融池，保留既有熔岩弹和火星。地面增加被火山灰打断的浅裂纹，避免规则铺石的外观。

两股烟柱各自使用三维密度，内部明暗随密度差形成，底部受喷口暖光影响。沿相机视线积累颜色并用场景深度终止采样，因此角色和岩石可以挡住后方烟雾。噪声采用共享的 32³ 单通道纹理缓存，体积、熔岩与灯光继续使用原有演出时钟。该实现是风格化实时体积效果，并非流体模拟。

## 对照与复现

本机 `artifacts/volcano-volume/index.html` 提供 8 秒连续对照、喷口检查机位和打包版 1080P 截图。左侧基准为 `53f690c4cb24029ed0ae8315c7e5a644efa67db3`，右侧为本轮修改；两侧各 240 帧。离线 30 FPS 不代表游戏运行帧率。

1. Unity 执行 `UltramanGame.Editor.VolcanoStageReview.Release`，得到同一段攻防的渲染和 GPU 检查结果。
2. 执行 `bash scripts/build_macos.sh` 与 `.venv/bin/python scripts/cinematic_player_check.py --hero Tiga`，保存实际打包版回放。
3. 执行 `.venv/bin/python scripts/encode_volcano_review.py --player <本次回放目录>`。脚本核对前后源码摘要、480 条战斗状态和当前程序／资源包摘要，再生成对照页面。

`VolumeChecks` 检查烟柱实际出现在画面中、时钟推进后形态改变、冻结时间后像素一致、前景实物完全遮挡，以及相机进入体积后的可见性。

## 本轮验证

`logs/volcano-volume-release.log` 中连续渲染通过：两侧各 240 帧、480 条战斗状态，均完成一次格挡，怪兽血量仍为 50，未受伤。256×256 的独立 GPU 检查中，烟柱改变 17,664 个像素，推进时间后改变 13,784 个像素；前景遮挡泄漏为 0，重复渲染完全一致，相机进入体积后仍能看见烟雾。检查图位于 `artifacts/volcano-volume/inspection`。

macOS 构建及本地签名通过。最终打包版在 135.19 秒内完成 32 次普攻、2 次必杀、1 次格挡、1 次受击、暂停恢复和胜利，保存 33 张 1920×1080 原生截图，未使用摄像头。证据目录为 `artifacts/cinematic-combat/player/20260927T222943647662Z`；程序集 SHA-256 为 `0ad1449903d961c3f695598e60d6d76258cefac19d6238193102516b06f2d77e`，资源包为 `3993863cd28c4d611b18f63747e2d92fbb5fbf70a71e96ac2bd3153bd884edd2`。

同一构建用合成体感输入在 177.0 秒内完成两次自动合照、重拍、照片流中断恢复、合照预览姿势流中断恢复和举手再开局，已经重新进入第二局战斗。键鼠事件为 0，未保存真人照片；两张 TEST 照片已移入 `artifacts/volcano-volume/guided`。该目录的 `build.json` 记录前后相同的程序与资源摘要，验证结果为 `guided-validation.json`，日志为 `logs/volcano-volume-guided.log`。

烟雾缓存前的中间构建也通过战斗，但耗时 148.16 秒；最终版本不再逐采样计算大量噪声哈希。两次运行不能当作严格性能基准，当前仍未达到 60 FPS。本轮未改动分辨率设置或宣称解决帧率问题。

这一轮改进了环境层次，角色原始贴图、动画种类和整体演出仍未达到参考街机的丰富度；60 FPS 专项继续后置。
