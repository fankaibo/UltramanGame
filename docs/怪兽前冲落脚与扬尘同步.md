# 怪兽前冲落脚与扬尘同步

参考录屏强调连续的攻击、身体位移和接触反馈。本轮针对当前哥尔赞前冲的实际问题：旧动画与根节点前进曲线不完全一致，支撑脚在蓄力到前冲期间偏离原落点最多 0.1600 Unity 单位；落地扬尘还使用了爪击左右侧，恰好与跨步脚相反。

新版按实际动作时钟约束双腿：后腿支撑，跨步脚抬起、前移，在 0.36 秒落地；攻击仍在原来的 0.40 秒判定。0.60 秒开始提脚回撤，0.99 秒重新落地。双侧攻击互为镜像，落地灰尘使用同一组时点和脚侧，起步灰尘则来自蹬地的支撑脚。

膝盖根据腿长屈曲，身体适当降低重心，两爪重新求解到原接触目标。每帧先移除上一帧的附加修正再采样动画，避免修正反馈进入动画混合；这也消除了回身切到受击时短暂的脚趾下陷。原有手腕 35° 约束继续生效。伤害、血量、蓄能、提示等待和动作识别未调整。

## 复现

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.MonsterStepReview.Release \
  --exchange-output "$PWD/artifacts/combat-flow" \
  -quit -logFile "$PWD/logs/monster-step-release.log"
```

这轮提高了前冲的支撑感和动作、特效一致性。参考街机的动作种类、场景互动和整体演出丰富度仍需继续完善，不能据此认定整体目标完成。帧率专项继续后置。
