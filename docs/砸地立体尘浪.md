# 砸地立体尘浪（A-20261019-183）

基线 `414dd0d`。对照参考街机的接触烟尘和当前实际 `slam-ground`／`slam-wave` 截图，当前碎石虽有空间轨迹，但尘土仍是朝镜头转动的烟片，形成贴地黄灰色带。本轮替换砸地尘浪的表现层，不改变识别或战斗规则。

## 改动与对照

新增单个世界空间体积，沿哥尔赞双手落地点到英雄接触位置，分六段扬起、翻滚、扩散和消散。密度在三维空间取样，有内部明暗和场景深度遮挡；摄像机绕到侧面仍能看见烟团厚度。尘浪使用原碎石的 0.12 秒分段启动窗口，普通踏步／落地烟尘和 48 块砸地碎石保持原路径。

体积使用显式游戏时钟、固定网格／材质／噪声，无每次攻击新建对象；暂停、新局通过原地面效果清理入口关闭。保留原随机采样顺序，避免替换烟片后改变下一次碎石随机轨迹。

[十二秒连续前后对照：左旧右新](../artifacts/a183-slam-dust/continuous-before-after.mp4)，前六秒成功防御，后六秒不防御受击；为脚本确认输入，不能代替真人识别验收。

首稿体积过低，仍像平铺薄雾；已提高烟团上升幅度、调整内部明暗并增加采样，再重做完整对照。首稿视频和源码保存在 `draft-low-cloud/`。第二稿虽在 165.7 秒内通过整局合照续局，但实际 1080P 近景仍有条纹；提高为 64 步采样并跳过空密度区后，重新完成画面／GPU 审查和源码构建。第二稿的源码、视频、原生截图及流程结果保存在 `draft-sampling-32/`，不冒充最终结果。

## 复现与证据

Unity 方法 `UltramanGame.Editor.SlamDustReview.Before`／`After` 和 `UltramanGame.Editor.SlamDustVolumeReview.Run` 均要求显式 `--slam-dust-output` 输出目录；Before 还校验基线源码哈希。`python3 scripts/review_slam_dust.py` 核验源码、攻防记录并生成视频；精简中间帧后使用 `--verify-only`。第二稿之后基线中间 JPEG 已精简，最终视频左侧取自保留的第二稿对照视频左半，右侧来自最终重新渲染的完整帧；编码通过 `--baseline-video` 显式指定来源，`comparison.json` 记录输入视频哈希。原始基线代表图与状态记录仍保留，不把重新编码误称重新渲染。

证据目录 `artifacts/a183-slam-dust/`。原 `GroundImpact.cs`、前后源码哈希、连续帧／视频、攻防 CSV、GPU 截图、构建与整局日志均独立保存。

这轮只改善砸地接触烟尘，不代表已经达到参考街机的整体演出水平，也不是稳定帧率测试。真人儿童、小米电视、完整连续动画和整体音画效果仍待验，总体进度 70.2% 保持。
