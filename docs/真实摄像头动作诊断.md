# 真实摄像头动作诊断（A-20261012-139）

源码基线 `859aa87`，2026-10-12。用户指出合成展示的低手位与孩子持续高位玩法不一致。前一轮读取了默认演示、高位用例和 A-137 日志，确认了两层验证的差别，改变后续排查路径，属于 Progress。本轮补齐文件画面进入真实识别模型后的诊断工具，不宣称已修复真人误判。

## 已确认与尚未确认

默认 `vision/demo.py` 的出拳轨迹确有低位收手；它不是训练数据，也没有训练摄像头模型。A-127 已修正过真实的高位出拳规则门槛，并增加持续高位输入；A-137 的 1,871 个普通战斗合成帧没有低手位。这证明规则能接收相应坐标，不能证明真实摄像头一定提取出相同坐标。

合成测试把坐标直接送进 C#，绕过 MediaPipe。因此手腕遮挡、手臂交叉、前伸时的深度估计以及原画面中的左右手混淆，需要从真实画面验证，不能通过不断修改合成轨迹宣布修复。此前三张儿童剪贴板照片的原路径已失效；没有用成人参考图替代儿童准确率证明。当前没有读取或上传儿童照片，也没有自动开启摄像头录像。

## 工具和输出

`scripts/review_camera_pose.py` 仅读取明确提供的本地文件，输出限定在被 Git 忽略的 `artifacts/` 新目录，拒绝覆盖已有证据。使用生产 `create_landmarker` 和同一 `camera_model_image`，每一帧骨骼由真正的 MediaPipe 提取；随后通过 `tests/CoreChecks/PoseReplayAudit.cs` 调用生产 `GestureRecognizer`，没有重写一份识别规则。

- `review.mp4`：原画面镜像预览、同帧骨骼、中文判定、左右手置信度、相对肩膀高度／深度、大招与护盾进度、最近触发事件。L／R 表示人物自身左右手。
- `poses.jsonl`：原媒体时间、源帧序号、真实提取的坐标、上下文与手位测量。
- `decisions.jsonl`：同媒体时间的生产判定，包含动作输入权、实际触发事件和释放要求。
- `report.json`：源文件／模型／源码哈希、上下文配置、事件数量、时间戳回退数量与验证局限；始终标明 `accuracy_assessed=false`。

先区分**原画面姿势正确、骨骼明显偏离**，以及**骨骼基本正确、游戏判定不符合动作**。前者排查检测与遮挡，后者再定位几何门槛、动作竞争或持姿释放。绿色线只表示所用端点置信度至少 0.55；橙线不等同“所有技能均拒绝”，因为生产的大招路径有自己的容错。

高度以肩宽归一化，正值代表手腕高于各自肩膀。低置信度／画外／没有人时，高位状态输出未知，而不是伪装为低位。镜像只影响展示；已经镜像的录像需加 `--input-mirrored`，先还原后再推理，避免人为颠倒左右手。

## 使用

```bash
.venv/bin/python scripts/review_camera_pose.py \
  --input "/本机路径/摄像头录像.mp4" \
  --output artifacts/camera-pose-session-01 \
  --kind camera-recording --context charged --seconds 30 --difficulty 0
```

输入必须是已有文件，不接受摄像头设备编号或网络地址。默认最多取 20 秒，单次上限 120 秒；`--start` 可选取问题片段。请保留收拳准备、两次左右出拳、交叉防御、转入 L 形和释放的过程。重放开始时没有先前手势历史，直接从大招静止画面截入，不能据此判断真人整局中的释放门槛有问题。静态图片需 `--kind reference-image --seconds 2`，最多重复 5 秒，仅用于观察提取几何，不能证明动态出拳或真实持姿稳定性。

固定上下文：`battle` 为未满能量，`charged` 为满能量，`warning` 为怪兽预警，`charged-warning` 同时满能量／预警，`waiting` 为允许举手开始。默认上下文必须显式指定；不同时把变身、必杀和预警全部打开。

需要按录像中的提示切换时，可加 `--segments artifacts/session-context.json`，示例：

```json
[
  {"start": 8, "end": 12, "context": "warning"},
  {"start": 15, "end": 30, "context": "charged"}
]
```

时间是原视频的绝对秒数；区间左闭右开，未列区间采用 `--context`。区间必须有序且不重叠。该工具不模拟战斗血量或能量变化，因此上下文应据实际提示标注，不能把任意固定状态下的结果当整局结论。
