# 迪迦普通光弹音效（A-20261011-105）

基线 `86a0915`。本轮继续迪迦整局街机体验，重点让普通远程攻击具有清晰的单次碰撞节奏；不修改动作识别、角色动画、命中时钟、音乐或迪迦原声战吼。

## 发现与实现

`ArenaController` 已分别在弹体开始、实际扣血时调用发射／命中音效，未发现触发时序错位。问题是 `ProjectileImpact` 复用了必杀的 `beamContact`，以 1.22 倍音高播放后仍长约 0.984 秒。连续普通光弹每 0.5 秒一次，低频尾音相互重叠，普通攻击与必杀也缺乏音色区别。

为迪迦增加 0.36 秒的能量碰撞声：短促脆响、下降的能量音、低频接触和很短的碎响。三个确定性变体轮换，启动时生成并由现有资源生命周期管理；沿用 10 路固定音效池、原 0.48 增益和语音优先混音。新增单声道 PCM 总量约 186 KiB，没有每次攻击创建音源。其他英雄暂保留原音效，遵循迪迦优先安排。没有下载或复制新的角色原声。

## 实际 Unity 混音对照

`AudioMixReview` 增加独立输出目录及 `--audio-projectiles`，以正式 `Battle` 驱动六次左右快慢攻击，另包含播报期间的光弹和必杀碰撞参考。通过 Unity `AudioListener.OnAudioFilterRead` 录制最终混音，不录制麦克风。

- 修改前／后录音约 10 秒，六次输入、发射、扣血事件逐行相同。攻击速度分别覆盖 0.65、1.0、1.7。
- 旧普通命中 95% 能量时间约 **0.337 秒**；新版三个变体为 **0.090–0.091 秒**。200 ms 后剩余能量由 **17.28% → 约 0.175%**。这是短尾节奏的客观证据，不等同于真人对音色的主观验收。
- 最终混音峰值：旧 **0.3418**、新 **0.3392**，均无数字削波；各源音效起止点无突跳、无 NaN／Inf。
- 连续 40 次调用未扩大音源池；迪迦使用专属普通碰撞、其他英雄仍使用旧碰撞。静音拒绝新音效、暂停清理正在播放的音效、高优先级保护检查通过；语音优先混音逻辑保持原实现。
- `scripts/review_projectile_audio.py` 校验旧录音对应 Git 基线、新录音对应当前源码，比较事件，并导出各 2.5 秒的三连发片段。完整数据：`artifacts/projectile-audio-20261011/comparison.json`。

对照音频：`artifacts/projectile-audio-20261011/before/fast-burst.wav`、`after/fast-burst.wav`；完整录音为同目录 `mix.wav`。隔离源音效与检查报告也保留，无需大量逐帧图片。

## 复现

```sh
# 修改前在记录的基线源码运行，不能用新源码伪造 before
Unity -projectPath "$PWD/unity" -executeMethod UltramanGame.Editor.AudioMixReview.Run \
  --audio-projectiles --audio-version after \
  --audio-output "$PWD/artifacts/projectile-audio-20261011" \
  -logFile "$PWD/logs/a105-audio-after.log"
.venv/bin/python scripts/review_projectile_audio.py
bash scripts/check.sh
bash scripts/build_macos.sh --release
```

录音检查会自动退出，命令不要加 `-quit`。此次没有改变画面，视觉连续动作沿用 A-103，普通光弹尾焰沿用 A-102；整体画面与参考街机的差距仍需继续处理。
