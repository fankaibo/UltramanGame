# 必杀命中近景与回位

原来必杀蓄力使用英雄特写，光线发射后一直保持普通对战镜头。哥尔赞虽然后仰、后撤并受到持续光照，但在全景中不够突出。

现在光线命中后切到短暂的哥尔赞受击近景。镜头保持在原战斗轴的一侧，前景保留发射方向，突出胸口接触、头部后仰与烟尘；光线收束时回到双方站位。近景中收起连击数字，避免遮挡怪兽身体；大招期间不叠加之前的怪兽攻击提示。

镜头直接采样战斗的动作时间：0.56 秒开始，1.28 秒结束，持续约 0.72 秒。实际命中仍在 0.45 秒，伤害仍为 9，蓄力演出与动作识别的计时没有改变。暂停、等待、胜利及展示状态都不会保留该近景。较广的近景镜头单独放大背景覆盖范围，避免画面上方出现黑边。

## 同步对照

基线为 `a905408189be3140f310101c697ff162ca1bdab5`。`FinisherReview` 使用相同输入运行 252 个 60 Hz 逻辑步，每两个步长保存一帧，输出修改前后各 126 帧。前后 CSV 逐字一致，均一次发射、一次命中、扣血 9 后恢复；这是 4.2 秒的离线渲染对照，不是游戏实测帧率。

检查包含迪迦 15／30／60 Hz 和其余四位英雄 60 Hz，共 7 组完整必杀。每帧近景检查胸口在有效构图内，背景覆盖四角，零时间重复更新不会使机位漂移，镜头只有一次进入并按时回位。另在发射、命中近景和光线收束三个时点中断，检查暂停和重开清除光线、灯光与近景。

本机入口：`artifacts/beam-reaction-camera/index.html`。对照脚本校验渲染源码、基线提交和实际程序摘要，防止把旧截图当作新版本。相应视频、实际应用画面与验证记录保留在忽略目录中。
