# 火山岩层与地面材质

本轮按“帧率后置、优先街机观感”的方向，改善富士山战场的近景。原先均匀噪声地面、圆滑石块和直接铺在地上的熔岩带，改成具有碎石细节的地面、带断面的岩块与相连的冷却岩壳。角色脚下仍是平整的战斗区域，周边才有起伏和碎石堆。

使用 Poly Haven 的两组 2048×2048 PBR 材质：

- [Rocks Ground 02](https://polyhaven.com/a/rocks_ground_02)，Rob Tuytel。
- [Rock Face 03](https://polyhaven.com/a/rock_face_03)，Dario Barresi、Rico Cilliers。

两组均为 [CC0](https://polyhaven.com/license)。原始 JPEG 保留，下载 URL、作者和 SHA-256 记录在 `unity/Assets/Resources/Art/Basalt/sources.json`。这是通用岩面素材经过着色器降低饱和度、调整色调后的火山场景美术，并非富士山地貌的扫描复原。

地面通过两个尺度和不同方向的纹理混合减轻平铺重复；岩石采用世界空间三向投射，侧面不会因原有平面 UV 而拉伸。颜色使用 sRGB，法线和粗糙度／环境遮蔽数据使用线性空间，开启 mipmap 和各向异性过滤。岩块增加两处非平行断面、局部崩裂和不同大小的周边碎石；熔岩沟两侧的岩壳直接沿同一路径生成，与地形相接。

## 验证

本机对照页面：`artifacts/basalt-stage/index.html`。修改前基准为 `e41a07deb10bca0d9166fe9f4b527f4a44766960`；左右各 240 帧，8 秒攻防的 480 条战斗状态完全一致。离线视频为 30 FPS，仅用于对照，不代表游戏运行帧率。

Unity `UltramanGame.Editor.VolcanoStageReview.Release --volcano-output <绝对输出目录>` 检查材质导入、着色器、连续场景、烟柱前景遮挡和冻结时钟。日志为 `logs/basalt-release.log`。所有检查通过：前景遮挡泄漏 0 像素，冻结时钟后画面完全一致。

`bash scripts/build_macos.sh` 构建及本地签名通过。随后 `.venv/bin/python scripts/cinematic_player_check.py --hero Tiga` 在实际打包版完成 32 次普攻、2 次必杀、1 次格挡、1 次受击、暂停恢复和胜利，保存 47 张 1920×1080 截图；使用合成输入，未开启真人摄像头。检查出拳、连击、必杀和倒地镜头，新增碎石没有遮住战斗主体。

打包版证据：`artifacts/cinematic-combat/player/20260928T121202687401Z`。程序集 SHA-256 为 `16dd313cdaaa6089d3ecb613b84a9a74d07706747eeac49259de5c3698e7d022`；资源包为 `1883be46e7fb1a2c46a88c0b4e08bc965f7cce6d9033810aa569b5e8798ee59d`。对照页生成时核对了源码与这两个摘要。

本轮没有修改动作识别、战斗参数或合照流程，也没有重新验证真人体感与合照。本轮提升的是环境材质和层次；角色动画丰富度、场景破坏和整体演出仍有明显提升空间，尚未达到参考街机的最终效果。
