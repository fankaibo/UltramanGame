# 局部命中光与角色出拳校准（2026-09-27）

继续优先改善街机战斗的动作与质感，帧率专项后置。上一版普通命中会让哥尔赞整身变成亮红色，遮住皮肤层次；五英雄复核又发现，梦比优斯、赛罗、捷德、格力乔的旧出拳映射偏向上方，拳头与怪兽之间仍有明显空隙。

## 改动

普通命中改为接触部位的短促暖光，大招使用蓝白色局部光。位置来自当前采样的拳头或光线接触点，存入哥尔赞胸部骨骼空间，随反冲移动。着色器按距离、皮肤朝向和原贴图亮度衰减，普通光约 0.24 秒收束，大招约 1.02 秒收束；腿和尾巴不再因全身自发光变红。环境光、点光、阴影和眼睛的独立发光继续保留。

另外四位英雄沿用各自原动作和脚步，在实际出拳阶段加入上身前倾及攻击手的肩肘约束，手掌随前臂保持朝向，另一只手保留原护手动作。纠正层在下次动画采样前移除，避免连续出拳时累积。迪迦已单独烘焙的拳击不使用这层修正；F5 静态动作展示也不套用实际战斗的瞄准。

动作识别、普攻伤害、50 次默认血量、15 次普攻蓄满、引导后 3 秒准备时间和输入切换逻辑均未修改。

## 复现

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.SurfaceImpactReview.Release \
  --contact-output "$PWD/artifacts/surface-impact" \
  -quit -logFile "$PWD/logs/surface-release.log"
```

此命令只重建 `after` 与检查结果，不会覆盖已保存的 `before`。实际玩家验证使用 `scripts/cinematic_player_check.py` 和 `scripts/guided_player_check.py`，不使用真实摄像头。

## 仍有差距

这轮改善了接触朝向及受击材质，不等于重新制作了五套完整拳击动画。四位英雄仍有约 0.16–0.23 单位的接触空隙，脚部继续使用原素材，动作展示页也未重新校准。哥尔赞的源模型、角色动画丰富度及长段攻防编排仍未达到参考街机的最终品质。自动化输入不替代孩子真人试玩或电视投屏验证。
