## 改动

旧版已经使用三维体积烟，但包络是一条连续的渐宽轮廓，近景像倾斜的雾管。新版以持续上升的烟团定义外形：从喷口出现、随高度扩大、左右偏移并在顶部逐渐消散。每团保留自己的编号，避免整柱定时重置；中间过渡重叠，喷口保留较窄的热气流。

光照增加近、远两次沿光方向的密度采样，压暗被烟团遮住的内部褶皱。高处保持冷灰色，橙色自发光局限于喷口。继续使用既有 32³ 缓存噪声、36 步射线采样和场景深度遮挡，不增加纹理。烟团位置、半径、存活权重由 `VolcanicPlumeMotion` 在舞台更新时统一计算，并用两组可复用数组上传；像素内只查询附近四团，移除逐像素的三角函数与幂运算。稳定帧率专项仍后置，不能按纹理采样数断言整体 GPU 成本。

角色、怪兽、真实火山岩、熔岩、战斗构图及手势和伤害规则均未修改。运行时修改 `VolcanicPlume.shader`、`VolcanoStage.cs` 并新增参数缓存类；编辑器取证入口增加 4 秒火山口近景序列，避免仅用静态截图判断动画。

## 复现

```bash
UNITY='/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity'
# before 已由旧代码产生；勿用当前源码覆盖旧对照。
"$UNITY" -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.VolcanoStageReview.Release \
  --volcano-output "$PWD/artifacts/volcano-billows-20261009" \
  -quit -logFile "$PWD/logs/volcano-billows-final.log"
bash scripts/check.sh
bash scripts/build_macos.sh --release
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --linked
.venv/bin/python scripts/guided_player_check.py --hero Tiga --tempo-skills \
  --gesture-wobble --gesture-entry-noise \
  --output artifacts/volcano-billows-20261009/guided \
  --log logs/guided-volcano-billows.log
# player 目录取自 cinematic_player_check.py 的 evidence_directory。
.venv/bin/python scripts/encode_plume_billows_review.py --player /实际发行回放目录
```

编码脚本核对旧版源码提交、新版所有取证文件的 SHA-256、战斗状态，以及两个回放与当前发行包的 assembly/resources 哈希。左右对照各 1280×720，合成 2560×720，离线 30 FPS；不能当作单幅 2K 或游戏稳定 60 FPS 的证据。总体进度见 [开发任务看板](开发任务看板.md)，仍为 70.2%，真人儿童和小米电视现场尚未验收。
