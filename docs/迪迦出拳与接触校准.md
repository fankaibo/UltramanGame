# 迪迦出拳与接触校准（2026-09-21）

目标是让普通攻击看起来由身体带动、真正接近怪兽，并连续收回。参考根目录的街机录屏；本轮不调整体感识别阈值、默认血量、蓄能要求或帧率参数。

## 修改后的行为

- 重烘焙迪迦的非对称待机：前手稍伸，后手高位保护；呼吸和重心变化在 3.2 秒内循环。左拳采用短促前手刺拳，右拳采用转髋更明显的后手直拳，分别编排胸部跟随与肘部回收。
- 迪迦的前进步幅从 0.75 调整为 1.25 场景单位，胸前落点、屈膝和脚部补偿一起烘焙。`Characters/Tiga/motion.json` 与 FBX 成对保存，运行时读取对应步幅；其他角色没有该配置，继续使用原来的 0.75。
- 普攻仍在动作时间 0.12 秒结算、0.38 秒结束。入拳混合从 55 毫秒缩至 25 毫秒，避免根位置已经前移，而脚部补偿仍在与上一姿势混合。
- 删除 `ArenaController` 的独立渲染冻结。先更新英雄与怪兽的骨骼，再在当前攻击手位置生成火花；由 `ImpactTiming` 统一控制接触保持与缓释，动作年龄不会在画面冻结时独自前进。
- 普攻保持 65 毫秒后缓释 55 毫秒，大招保持 140 毫秒后缓释 85 毫秒。保持的是战斗动作时钟；特效、光照、体感接收、暂停判断继续每帧运行。墙钟下的攻防会因此稍延长，不能把它描述为完全不改变战斗计时。
- 连击节点音效从“下一拳开始时检查已有拳数”改为“本拳实际命中后检查拳数”，第 5、10、15 次命中与音效、节点特效对应。

## 画面对照与测量

本机 `artifacts/hero-motion-20260921/review.html` 提供同输入、同镜头的 4 秒左右对照，可半速播放。左侧来自修改前的实际素材；右侧使用 `final/` 的新版。两侧各 120 张图，离线输出 30 fps，不是游戏性能测试；不叠加命中闪光或停顿，以便直接看姿势、拳路和脚步。

`HeroMotionReview` 通过真实 `Battle` 输入左右交替四拳，采样实际骨骼，检查手部相邻帧变化、支撑脚平面漂移，以及拳端至哥尔赞当前蒙皮顶点的最近距离。源文件哈希位于各目录 `sources.txt`，逐帧位置位于 `motion.csv`。蒙皮顶点距离是接触近似，不是精确的物理碰撞检测。

## 复现

通过 `scripts/prepare_tiga.py --live-combat --export` 烘焙，复制输出的 `Tiga.fbx` 与 `motion.json` 到 `unity/Assets/Resources/Characters/Tiga/`。保留原模型作者与许可文件；源模型仍为用户下载的 Extrazhang 迪迦模型。

Unity 执行 `UltramanGame.Editor.HeroMotionReview.Render --motion-output <输出目录>`，然后使用 `scripts/encode_hero_motion_review.py <对照根目录> --after final` 输出同步对照。完整回归入口仍为 `scripts/verify_guard_impact.sh`；截图来自本次实际播放器，不使用历史编辑器截图替代。

## 仍有差距

本轮改善的是迪迦常规拳击及命中衔接，没有重做哥尔赞的源网格，也没有把另外四位英雄替换成新的动画素材。更多连续步法、身体闪避、丰富的怪兽动作和更精细材质仍需继续制作。合成输入和逐帧检查不能代替孩子真人试玩或电视投屏延迟测试。
