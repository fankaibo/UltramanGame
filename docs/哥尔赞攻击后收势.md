# 哥尔赞攻击后收势

此前哥尔赞在爪击、砸地和头部光线之后直接回到重复待机，双爪仍向前伸、嘴一直张开。现在利用已有的两秒恢复阶段，加入放低双爪、轻微收颌、转头喘息和回正；没有延长怪兽恢复时间、修改伤害或要求孩子等待。

`MonsterRecoveryMotion` 给出收势权重、转头与胸部呼吸曲线，`RiggedActor` 在已有动画和受力层之后叠加。双爪向下、向后并略向外错开；手腕仍受既有 35 度限制。下颌在等待和休息时保留小幅呼吸开口，攻击与受击会撤回该修正。每次采样先还原骨骼基础旋转，避免重复叠加。

孩子打中怪兽时，收势层立即让位于受击；暂停、新局和新的语音引导也会退出收势。能量、动作识别阈值、攻击判定和战斗时钟未变。

## 复现

```sh
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.MonsterFaceReview.After \
  -quit -logFile "$PWD/logs/monster-recovery-after.log"
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.MonsterFaceReview.Flow \
  -quit -logFile "$PWD/logs/monster-recovery-flow.log"
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.ClawPoseReview.Stability \
  --claw-output "$PWD/artifacts/monster-recovery/claw-stability" \
  -quit -logFile "$PWD/logs/monster-recovery-claws.log"
bash scripts/check.sh
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
.venv/bin/python scripts/guided_player_check.py --gesture-wobble \
  --output artifacts/monster-recovery/guided --log logs/monster-recovery-guided.log
.venv/bin/python scripts/encode_monster_recovery_review.py
```

`Before` 必须使用基准运行时代码渲染，不能用当前代码覆盖后再称为修改前；编码脚本核对双方源码摘要与最终程序验证摘要。

这一轮改善攻击后的衔接，未重做源模型手掌或贴图。完整动作丰富度、真人照片融合和整体街机演出仍未达到最终目标。
