# 英雄模型资源审计

2026-10-03 对 `unity/Assets/Resources/Characters` 做了本地资源盘点。迪迦使用独立的 21MB FBX、4096×4096 身体贴图和 2048×2048 遮罩；赛罗有多张 2048×2048 贴图；梦比优斯是 5MB FBX、身体贴图为 256×1024；捷德和格力乔分别是约 3.7MB FBX、约 2792/2970 顶点，身体图集均为 256×256。后两者的近景清晰度受源贴图限制，这解释了迪迦和其他角色的明显差异。

本轮没有在 `/Users/fankaibo/Downloads` 找到泽塔或德凯的 FBX、GLB、OBJ 或 Blender 文件，因此只登记了两个角色的官方资料和选择卡，不把赛罗/梦比优斯复制成假模型。拿到可再分发、带许可的模型后，应放入 `Resources/Characters/Zeta` 与 `Resources/Characters/DeckerStrong`，补齐 `source.json`、`ATTRIBUTION.txt`、`Photo.png` 和八段动作，再把本表 A-20261003-01 状态改为完成。

招式资料依据圆谷官方角色页：[泽塔](https://tsuburaya-prod.com/heroes/ultraman-z) 使用 Zestium Beam；[德凯](https://tsuburaya-prod.com/heroes/ultraman-decker) 的形态包含 Strong Type，官方介绍的强劲型必杀是 [Dolnade Breaker](https://tsuburaya-prod.com/news/4192)。圆谷资料将[捷德](https://tsuburaya-prod.com/news/9)的 Acro Smasher 标为机敏、擅长多种光线，因此选择卡改用该形态对应的“阿克洛斯梅舍 / Acron Smasher”，不再把 Primitive 的 Wrecking Burst 显示在机敏型卡片上；[格力乔官方页](https://tsuburaya-prod.com/heroes/ultrawoman-grigio)的 Special Moves 为 Grigio Cheer Charge，中文卡片同步采用“格力乔欢呼充能”。游戏没有伪造其他英雄的影视原声：缺少 `Voice/beam_<hero>` 时会回退到通用光线音效，并在日志和设置页显示实际来源。
