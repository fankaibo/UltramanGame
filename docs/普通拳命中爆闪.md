# 普通拳命中爆闪（2026-09-28）

参考视频里的命中以短促爆闪、飞散火花和全身受力配合，旧版普通拳则主要显示细圆环。本轮将普通拳和连击命中的圆环、均匀射线替换为有方向的白橙色爆闪：中心先亮起，长短不一的尖芒展开，中心淡出后外侧残光散去。

爆闪沿出拳方向在镜头平面上展开，同时参与场景深度遮挡，因此位于前面的角色手臂能够挡住它。普通拳持续 0.23 秒，第五拳等连击持续 0.29 秒且范围更大。表面受光、既有烟尘、飞散火花、音效与骨骼受击继续衔接。该效果是实时着色器绘制的街机风格爆闪，不是物理爆炸模拟。

使用 6 个循环复用的显示对象；连续命中不会不断创建新对象。暂停和新局清除它，光线、防御及英雄受击保持各自的特效类型，避免所有动作都显示同一种暖色爆闪。
