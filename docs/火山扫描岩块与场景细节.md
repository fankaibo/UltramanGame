# 火山扫描岩块与场景细节

对照参考录屏和当前游戏，火山背景已经有景深层次，但主要岩石仍是重复的程序化圆滑块体，与写实远景不够一致。本轮更换环境中的主要岩块，保留现有战斗构图和动作识别。

## 素材与接入

13 处较大岩块使用两款真实扫描模型及各自原始的颜色、法线、AO／粗糙度贴图；小碎石仍使用原场景几何。运行时只显示源文件中最高细节的一份网格，避免不同 LOD 重叠，13 处合计 178,404 个三角形。模型保持原比例，按水平尺寸缩放、旋转并稍微埋入地面；表面统一为偏冷的灰色，沿用月光与熔岩照明。

来源为 Jenelle van Heerden 的 [Rock 07](https://polyhaven.com/a/rock_07) 与 [Rock 09](https://polyhaven.com/a/rock_09)，遵循 Poly Haven 的 [CC0 许可](https://polyhaven.com/license)。它们是风化石块扫描，不是富士山实地扫描。FBX 和六张 2K JPEG 原文件未修改，官方文件 MD5、实际大小、SHA-256 与来源位于 `unity/Assets/Resources/Environment/ScannedRocks/sources.json`。`scripts/fetch_scanned_outcrops.py` 可重新获取并核对素材。法线与 ARM 数据按线性导入，颜色按 sRGB 导入，全部启用缩小纹理。

最初试用的开放背面岩壁扫描不适合战斗镜头，未纳入最终游戏资源；最终使用两款完整石块。没有修改角色模型、怪兽爪姿、血量、充能、姿势判断或合照处理。

## 可视化验证

基准为 `bc16278e60d0a796e5dc34260ca4171fff2b5701`。`VolcanoStageReview` 保存前后各 240 张 1280×720 画面，覆盖 8 秒蓄力、扑击、格挡和恢复。480 条战斗状态逐项一致；静止时钟重复渲染一致。该段内扫描模型与英雄／怪兽蒙皮网格的包围盒没有相交；这是该段输入的空间检查，不代表任意姿势和视角都已验收。

五位英雄的大招发射、命中、回位和镜头覆盖均通过。迪迦额外完成 15／30／60 Hz 逻辑步长以及三个时点的暂停／重置检查。记录在 `artifacts/scanned-outcrops/finisher/after/flow-validation.txt`，日志为 `logs/scanned-outcrops-finisher.log`。

`scripts/encode_scanned_outcrop_review.py` 核对 before 源码摘要与基准提交、after 摘要与当前工作区，再核对素材和实际安装包，生成 `artifacts/scanned-outcrops/index.html`。页面包含 2560×720 并排视频、同位置切换、岩块局部和原生游戏截图。30 FPS 是离线视频导出设置，不是运行帧率。

## 当前打包版

`logs/scanned-outcrops-build.log` 记录 macOS 构建与本地签名成功。实际程序用时 97.31 秒，完成 32 次普攻、2 次必杀、3 次格挡、1 次未防御受击、暂停恢复和胜利；包括连击、重踏和远程光线。已查看普通命中与正面庆祝截图，主要岩石在舞台两侧，没有遮住角色。证据目录为 `artifacts/cinematic-combat/player/20260930T002006885711Z`。

程序集 SHA-256：`d35bace30da93e28aa4c2cb16003268f6f680e5f1367a330d6726bf52b918e13`；资源包 SHA-256：`98df566cd29ac85798a65b2afdf3c1084a6c2d80e6e9c6c42c8c1774f15670b6`。

同一安装包完成 136.9 秒无键鼠流程：自动合照两次、重拍、照片流与预览姿态流中断恢复、举手续局并重新进入战斗。96 帧防御深度噪声（含 44 帧手腕遮挡）、13 帧大招起始噪声和 15 帧后续噪声下，受保护期间识别器普攻误触为 0，格挡与必杀各成功 2 次。照片预览与导出中央区域 P99 像素误差为 0；运行前后安装包摘要一致。记录在 `artifacts/scanned-outcrops/guided/`。全部输入及人物像素均为合成 TEST 数据，没有拍摄或上传真人照片，不代表孩子和电视投屏已重新验收。

本轮是环境几何和表面的局部升级。角色近景质感、动画丰富度、整体演出以及真人照片融合仍有差距，不能据此宣称最终街机目标完成；帧率专项仍按用户要求后置。

## 复现

```sh
.venv/bin/python scripts/fetch_scanned_outcrops.py
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.VolcanoStageReview.After \
  --volcano-output "$PWD/artifacts/scanned-outcrops" \
  -quit -logFile "$PWD/logs/scanned-outcrops-refined.log"
Unity -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.FinisherReview.After \
  --finisher-output "$PWD/artifacts/scanned-outcrops/finisher" \
  -quit -logFile "$PWD/logs/scanned-outcrops-finisher.log"
bash scripts/build_macos.sh
.venv/bin/python scripts/cinematic_player_check.py --hero Tiga --slam --ray --linked
.venv/bin/python scripts/guided_player_check.py --gesture-wobble --gesture-entry-noise \
  --output artifacts/scanned-outcrops/guided --log logs/scanned-outcrops-guided.log
.venv/bin/python scripts/encode_scanned_outcrop_review.py
```

before 必须在基准提交下生成，不能用最新代码重绘并称为旧画面。
