# 格力乔与捷德网格裂缝修复（2026-09-27）

近景中格力乔的肩甲、面罩与胸饰像碎片，捷德的嘴部、胸口和腹部也有黑缝。问题不只来自低清贴图：DragonFF 导入器添加了 `EdgeSplit`，后续细分把已经断开的表面分别向内收缩，形成原模型没有的大量裂缝。

`scripts/prepare_roster.py` 的 GTA 模型导入现在移除这项拆边操作，在连续网格上做一级细分，并将细分移到蒙皮之前，使 Blender 预览与 FBX 在变形前处理网格的顺序一致。本轮用保存的动画工程重新导出格力乔和捷德，保留原始 UV、256×256 贴图及八段已有动画；合照立绘同步重绘，角色大小与合照定位参数不变。下载原件未修改。

## 复现

在资产修改前运行 `UltramanGame.Editor.HeroMeshReview.Before`；修改后运行 `UltramanGame.Editor.HeroMeshReview.Release`。后者会比较动画曲线、输出相同角度的画面，并调用已有的出拳、护盾和合照检查：

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.HeroMeshReview.Release \
  --roster-output "$PWD/artifacts/hero-mesh-review/combat" \
  -quit -logFile "$PWD/logs/hero-mesh-release.log"
```

本轮修复网格裂缝，没有重绘高清贴图。原始 256×256 图案仍限制近景质量，整体尚未达到参考街机的角色精度。继续优先画面、动作和打击感，帧率专项后置；输入识别、血量与充能规则、引导等待时间及无键鼠续局流程没有修改。
