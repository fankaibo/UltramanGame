# 起身膝盖方向修复

改动索引：A-20261008-54；实现 `4e1614a`。开始于 2026-10-08，2026-10-09 汇总验证。整体目标和进度以 [开发任务看板](开发任务看板.md) 为准。

## 截图对应的真实问题

用户截图精确对应本机旧录像 `artifacts/battle-variety-20261008/rock-hurt/0104.png`，是哥尔赞投石击中后，迪迦由倒地转为站立的阶段。它不是出拳或踢腿帧。

`PoseKnockdown` 起身时的左腿求解方向为 `side + forward`，右腿为 `-forward`。当脚收回到臀部下方，左膝被导向侧面、右膝被导向身体后方，出现脚掌着地但膝盖反折的异常。旧验收只检查接地、画面范围、恢复状态和重复采样；这些可以通过，却不能证明腿部姿势自然。

修复让双膝在收脚支撑的 0.56–0.92 秒逐步转向脚尖方向，并保留小幅外开。倒地、伤害、落地提示、起身总时长和输入规则保持不变。实际播放器增加 `hero-rise-support` 取证点，覆盖用户截图对应的起身中段。
