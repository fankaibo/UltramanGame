# 格挡承重与反击衔接（2026-09-28）

原版格挡已经有胸口后仰、怪兽反弹、护盾闪光和局部蓝色受光，但角色腰腿基本不动。本次让防御成功后的冲击传递到全身：胸口先吸收冲击，骨盆稍后后移、下沉，双膝屈曲，再恢复站姿。

动作只由成功格挡事件触发，持续约 0.64 秒，最大后移 0.15、下沉 0.14 个场景单位。腿部求解保留当前动画的双脚位置、脚掌角度及膝盖弯曲方向。它也保留下一次出拳自带的踏步；松开护盾或发起普攻、必杀时，剩余承重动作继续退去，不等待这段演出结束才处理输入。暂停、新局、受击倒地和角色预览不叠加这段格挡动作。

每帧先还原上次的附加位移与腿部旋转，再采样动画，避免同一姿态重复求解造成累积。未改动姿势识别、战斗伤害、动作触发阈值、提示等待时间或帧率策略。

- 3 秒格挡后立即左拳反击的连续动画。

## 验证范围

`GuardBraceReview.Release` 共 57 组：五位英雄在 15、30、60 Hz 下持续格挡；五位英雄在 30 Hz 下接触后松手、左拳、右拳、必杀、暂停、新局，迪迦额外覆盖 15 和 60 Hz。新动作输入当帧被接受，左右反击各命中一次；重复零时间采样保持脚、膝、根节点和手部位置稳定。

相对预备站姿，持续格挡的最大脚部偏移约 0.0106 个场景单位，结束后根节点回归原位。迪迦左膝弯曲增量由基准约 4.4° 增至约 23.9°，其余角色约 29°。这些数值用于约束动画，不代表真人测量或动作识别精度。

另执行 `RosterPunchReview.CheckGuardTransitions` 和 `GuardImpactReview.Render`：五位英雄原有护盾切换通过；成功格挡的胸口后仰约 10.49°，格尔赞回弹约 12.04°；护盾局部反光可见，腿部未出现反光泄漏，动画与受光按时恢复。

重复采样验证必须在怪兽更新前进行：英雄的拳头会追踪怪兽皮肤目标；若先移动怪兽再验证英雄，输入已变化，不能据此认定英雄姿态累积。

复现顺序：

1. 基准版本执行 `UltramanGame.Editor.GuardBraceReview.Before`，保存当时的审阅脚本到 `artifacts/guard-brace/before/GuardBraceReview.cs`。
2. 当前版本执行 `UltramanGame.Editor.GuardBraceReview.Release`。
3. 执行 `UltramanGame.Editor.GuardImpactReview.Render --guard-output <仓库>/artifacts/guard-brace/shield-regression`。
4. `bash scripts/build_macos.sh`，随后执行 `scripts/cinematic_player_check.py --hero Tiga`。
5. 执行 `scripts/guided_player_check.py --output artifacts/guard-brace/guided --log logs/guard-brace-guided.log`，保存运行前后构建摘要到同目录 `build.json`。
6. `scripts/encode_guard_brace_review.py --player <本轮实战证据目录> --guided artifacts/guard-brace/guided`。

本轮改善的是格挡重量感和反击衔接。现有模型的细节、动作种类与场景丰富度仍有明显提升空间，不能视为达到参考街机的最终效果；帧率专项继续后置。
