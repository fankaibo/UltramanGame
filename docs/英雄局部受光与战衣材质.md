# 英雄局部受光与战衣材质（2026-09-27）

连续攻防对照显示，迪迦成功防御后的亮光覆盖了整件战衣，背部、腿和鞋子一起泛蓝。原实现向 Suit / Gold 材质添加统一自发光，还遗漏了材质名称不同的四位新增英雄。

本轮新增 `HeroSurface.shader`，五位英雄的非发光表面共用它。护盾接触事件把真实撞击位置传给角色，局部亮光依据距离、表面朝向和原贴图颜色衰减，沿用防御接触的短暂脉冲。银色、红紫色和金色图案不再被整身蓝光覆盖。独立的眼睛、计时器与水晶继续发光；EyeRim 不再被当成眼睛发光材质。

贴图中明亮、低饱和度的区域使用较高金属度与平滑度，以区分银色部分和彩色战衣。这是根据原图颜色估算的材质分离，没有重做模型或新增美术贴图，也没有把颜色边界伪造成法线凹凸。暂停、续局与新局会清除局部反光状态。

本轮改变材质、局部亮光及触发位置；识别、身体动作、伤害、50 次默认血量、15 次蓄满、语音后 3 秒反应时间、声音与合照交互规则保持不变。帧率专项仍后置。

## 复现

```sh
/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD/unity" \
  -executeMethod UltramanGame.Editor.GuardImpactReview.Render \
  --guard-output "$PWD/artifacts/hero-guard-light/after/guards" \
  -quit -logFile "$PWD/logs/hero-guard-light-guards-after.log"
```

中断验证使用 `GuardImpactReview.LightInterruptions`；连续画面使用 `ExchangeReview.After --exchange-output "$PWD/artifacts/hero-guard-light"`。重新生成 after 不覆盖 before。

当前源模型的轮廓、网格和原贴图细节仍限制近景表现，材质分离不等于重新制作高精度角色；整体尚未达到参考街机的最终目标。
