# 连击转肩与怪兽受力（2026-09-28）

参考根目录街机录屏中的连续攻防，本轮减少普攻反复使用同一伸手动作的感觉。每第 5 次普攻增加外侧挥入、转肩及收势，另一只手留在胸前；哥尔赞随左、右命中产生更明显的侧转和后仰。梦比优斯、赛罗、捷德、格力乔在这类出拳中增加短跨步，迪迦保留已有步幅。

`ComboStrikeMotion` 用普攻序号与动作时钟选择演出，不新增输入或伤害。命中仍在 0.12 秒、出拳结束仍在 0.38 秒，一拳扣 1 点、充能 1 次。手部目标绑定哥尔赞实际胸部蒙皮位置。连击中切入护盾时，防御规则立即生效，上身从当前姿势用 0.14 秒过渡，避免手臂跳回隐藏的直拳片段。

## 本机画面对照

`artifacts/combo-strike/index.html` 包含十次交替出拳的连续左右对照、五英雄的左／右连击接触帧，以及当前 macOS 游戏截图。视频左侧来自 `621c4f153f9aed255f53d1dda6b2a630f76a6e17`，右侧为新版，各 210 帧、7 秒。双方 420 个动作时钟、血量和能量样本完全一致；离线 30 FPS 不表示游戏帧率。

`scripts/encode_combo_review.py` 核对修改前源码与基准提交、新版源码与工作区的摘要，确认输入采样一致，再核对玩家程序集与资源包摘要后附加实机图。来源保存于同目录 `provenance.json`。

## 复现

1. Unity 执行 `UltramanGame.Editor.ComboStrikeReview.Release`，输出新版连续帧、接触和中断检查。
2. `bash scripts/build_macos.sh`。
3. 依次运行 `.venv/bin/python scripts/cinematic_player_check.py --hero Tiga` 和 `--hero Mebius`。
4. `.venv/bin/python scripts/encode_combo_review.py --player <迪迦证据目录> --player <梦比优斯证据目录>`。修改前帧与采样脚本快照保存在本机 `artifacts/combo-strike/before`，未纳入 Git。
