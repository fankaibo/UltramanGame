# 光弹命中余烟与空间层次（A-20261019-171）

基线 `f4f5a42`。迪迦普通远程光弹已有出手、飞行、接触闪光和火花，但闪光结束后接触点迅速消失。当前增量补上短暂的冷却余烟，延续命中后的空间层次；仍以迪迦整局为主线。

## 改动

- 命中点产生灰蓝色体积余烟，向来袭方向外散并轻微上浮，0.72 秒内消散；初始保留少量能量色。
- 非对称烟团和两层密度扰动避免规则圆球外形。按场景深度裁剪，前景人物和场景可遮住烟团。
- 固定四个可复用烟团，连续快拳复用最早槽位；暂停、大招切入、新局和换英雄均清理。
- 只在迪迦原有柔和光弹样式启用。伤害、攻速、左右拳、识别阈值和引导时间没有变化。
- 增加实际发行程序的 `ranged-impact-smoke` 截图取证点，检查闪光后的余烟阶段。

## 可复现证据

目录 `artifacts/a171-ranged-smoke/`，源码与构建身份见 `build.json`。

1. `RangedSmokeReview.Before/After` 同输入四秒连拳：新版 15／30／60 Hz 均恰好命中三次，怪兽血量 47、能量 3，对象数量固定，特效按时消失，暂停清理通过。
2. `scripts/review_ranged_smoke.py` 对照基线源码与 240 行玩法记录，状态、动作年龄、命中、血量及能量完全一致。特效可见尾段是本轮有意延长的项目，不纳入玩法相等断言。
3. 三视角 GPU 验证：烟团可见、零时间重绘一致、到期恢复空画面。前景不透明遮挡泄漏像素为 0；三种更新频率的烟团位置和尺寸一致；连续触发 40 次仍只有四个复用对象。
4. 既有光弹五视角、火花、其他英雄样式与三帧率出手／接触交接通过；迪迦／赛罗 × 三帧率 × 快慢攻速共 12 组生命周期通过。
5. 深度特效加入后，隔离验证场景改用透视相机、开启深度纹理并用支持深度的不透明材质作为遮挡物，匹配实际舞台条件；游戏相机不受此工具修改影响。
6. `bash scripts/check.sh`：58 Python 测试、累计 2363 核心／桥接检查通过。

`continuous-before-after.mp4` 为完整四秒、左旧右新对照，2560×720、120 帧。离线编码 30 FPS 不是实际游戏帧率。
